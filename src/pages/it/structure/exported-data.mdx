OpenReplay Enterprise Edition include diversi connettori per esportare i dati acquisiti (comportamento degli utenti e problemi tecnici) nel tuo data warehouse. Supportiamo:
- Amazon Redshift
- Google BigQuery
- PostgreSQL
- Snowflake
- ClickHouse
