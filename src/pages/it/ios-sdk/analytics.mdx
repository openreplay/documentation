Il tracker rimane in ascolto degli eventi di comparsa e scomparsa delle view.

## Aggiungere view tracciate

### SwiftUI

Usa `.observeView(title:viewName:)` per osservare gli eventi delle view,

- `title: String` - titolo della schermata o della funzionalità
- `viewName: String` - nome della view del tracker

```swift
import ORTracker

TextField("Input", text: $text)
 .observeView(title: "Screen title", viewName: "test input name")
```

### UIKit
```swift
import ORTracker

Analytics.shared.addObservedView(view: inputEl, title: "Screen title", viewName: "test input name")
```
