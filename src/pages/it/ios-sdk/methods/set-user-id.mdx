Questo metodo ti consente di impostare un ID utente sulla sessione attualmente attiva. In questo modo puoi associare un utente al replay, così da poter filtrare e cercare le sessioni di un particolare utente.

## Firma
```swift
ORTracker.shared.setUserID(_ userID: String)
```

## Parametri

- `userID: String`: l'ID dell'utente. È una stringa e può essere qualsiasi valore, purché sia una stringa e permetta di identificare in modo univoco un utente all'interno del tuo sistema (ad es. email, ID del database, ecc.).

## Valore restituito

Questo metodo non restituisce alcun valore; i risultati saranno visibili nella piattaforma OpenReplay.
