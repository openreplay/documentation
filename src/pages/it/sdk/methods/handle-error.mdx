Se le informazioni tracciate di default dal nostro tracker quando si verifica un errore JS non bastano, puoi usare questo metodo. Il metodo `handleError` segnala manualmente eccezioni intercettate, promise rifiutate o eventi di errore. Consulta la [segnalazione degli errori](/session-replay/error-reporting#manually-logging-exceptions) per maggiori dettagli.

## Firma

```js 
handleError: (e: Error | ErrorEvent | PromiseRejectionEvent, metadata?: Record<string, any>) => void
```

## Parametri

- `e: Error | ErrorEvent | PromiseRejectionEvent`: L'oggetto errore effettivamente intercettato.
- `metadata: Record<string, any>`: **[Facoltativo]** Una struttura simile a un dizionario con tutte le informazioni aggiuntive che vuoi salvare in associazione a questo errore.

## Valore restituito

Questo metodo non restituisce alcun valore: le informazioni salvate sono visibili nella piattaforma OpenReplay.
