Questa funzione può essere usata per determinare se una particolare istanza del tracker è attiva e sta registrando oppure no.

## Firma

```js
isActive(): boolean
```

### Valore restituito

Restituisce `true` se il tracker è attivo e la sessione è in fase di registrazione, altrimenti `false`.
