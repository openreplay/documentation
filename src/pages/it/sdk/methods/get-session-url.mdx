Questo metodo ti permette di ottenere l'URL della sessione attiva. L'URL punta alla dashboard di OpenReplay e il metodo è utile se vuoi integrare OpenReplay nel tuo stack.

## Firma

```js
getSessionURL({ withCurrentTime?: boolean }): string | undefined
```

## Parametri

- `withCurrentTime: boolean`: Parametro facoltativo, per impostazione predefinita è `false`. Se è `true`, l'URL conterrà il timestamp del momento della replay in cui è stato chiamato il metodo.

## Valore restituito

Questo metodo restituisce l'URL della sessione attiva da riprodurre sulla piattaforma di OpenReplay. Facoltativamente, l'URL può contenere il timestamp del momento in cui il metodo viene chiamato, per saltare direttamente a quel punto della replay.
