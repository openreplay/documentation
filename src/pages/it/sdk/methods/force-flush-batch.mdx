Forza il tracker a svuotare (flush) il batch di messaggi corrente senza attendere che sia completo. Utile quando devi chiudere la scheda o la finestra al termine di una sessione. Questo metodo invia inoltre un messaggio al web worker, che avvierà una richiesta di rete con il batch di messaggi corrente.

## Firma

```ts
forceFlushBatch(): void
```
