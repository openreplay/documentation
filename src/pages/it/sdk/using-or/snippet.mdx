Se vuoi aggiungere il tracker alla tua applicazione web e usi un framework che non supportiamo oppure se usi semplicemente
VanillaJS, puoi aggiungere direttamente il nostro snippet JavaScript.

## Ottenere lo snippet

Lo snippet JavaScript che ti serve ti viene fornito quando configuri il progetto nel portale OpenReplay.
Una volta aggiunto il nuovo progetto, vedrai qualcosa di simile a questo:

![Nuovo progetto pronto](/using-or/snippet/new-project-ready.png)

Quando lo vedi, fai clic sul pulsante "Complete Project Setup". 
Verrai portato a una pagina in cui ti viene mostrato lo snippet JS:


![Ottenere lo snippet JS](/using-or/snippet/getting-snippet.png)

Ora fai semplicemente clic sulla scheda "Script" e vedrai lo snippet JavaScript vero e proprio:

![Lo snippet è visibile](/using-or/snippet/snippet-visible.png)

Prendi lo script e aggiungilo direttamente all'interno del tag `<head>`: il tracker inizierà a funzionare automaticamente.

<Aside type="tip">
Tieni presente che se modifichi una qualsiasi delle opzioni di registrazione dei dati nel passaggio 1 dello screenshot qui sopra, lo snippet finale cambierà.
Quindi assicurati di configurare prima le opzioni di registrazione e di copiare solo dopo lo snippet vero e proprio.
</Aside>
