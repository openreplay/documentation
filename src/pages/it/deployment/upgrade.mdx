Per aggiornare il tuo deployment di OpenReplay all'ultima versione è necessario aggiornare sia il backend (istanza) sia il tracker.

## Aggiornare il backend (installazione standard)

1. Scarica la CLI più recente

```bash
# Download the latest CLI
sudo wget https://raw.githubusercontent.com/openreplay/openreplay/main/scripts/helmcharts/openreplay-cli -O /bin/openreplay 
sudo chmod +x /bin/openreplay
export PATH=/var/lib/openreplay:$PATH
```

1. Controlla la versione del tuo cluster Kubernetes e aggiornalo se è precedente alla `1.31` (**obbligatorio**)

```bash
# Check Kubernetes version
kubectl version --short 2>/dev/null | grep -i server | awk '{print $NF}'
```

```bash
# Update Kubernetes
k3s-killall.sh
curl -sL https://get.k3s.io | sudo K3S_KUBECONFIG_MODE="644" INSTALL_K3S_VERSION='v1.31.5+k3s1' INSTALL_K3S_EXEC="--disable=traefik" sh -
	
# Restart Kubernetes cluster
sudo systemctl restart k3s.service

# Update Kubernetes deprecated apis
helm plugin install https://github.com/helm/helm-mapkubeapis
helm mapkubeapis -n app openreplay
```

3. Aggiorna OpenReplay

```bash
RELEASE_UPGRADE=1 openreplay --upgrade
```
> Nota: il file di configurazione aggiornato di OpenReplay verrà salvato in `/var/lib/openreplay/vars.yaml`.

## Aggiornare il backend (solo Docker)

```bash
git clone https://github.com/openreplay/openreplay --depth 1
cd openreplay/scripts/docker-compose
bash upgrade.sh /path/to/old/common.env
eg: bash upgrade.sh ~/openreplay-docker-compose/common.env
```
> Nota: il file di configurazione aggiornato di OpenReplay verrà salvato in `common.env` insieme al file docker-compose.
