Iniziare a usare OpenReplay è semplice. 

Se vuoi guardare un breve tutorial su come iniziare, usa [questo video su YouTube](https://www.youtube.com/watch?v=EWbtMK3qK30), altrimenti continua a leggere per maggiori dettagli.

Ci sono 2 modi per mettere in funzione OpenReplay: usare lo script o il pacchetto npm.

## Usare lo script

Copia e incolla lo snippet di codice direttamente nel `</head>` della tua web app. Lo script si trova nella dashboard di OpenReplay in 'Preferences > Projects' ed è univoco per ogni progetto.

Se il tuo sito supporta Google Tag Manager, puoi seguire la [guida passo passo per GTM](/integrations/google-tag-manager).

## Usare NPM

Per prima cosa installa il pacchetto npm.

```bash
npm i @openreplay/tracker
```

Poi inizializza il pacchetto dal punto di ingresso del tuo codice e avvia il tracker. Devi impostare l'opzione `projectKey` nel costruttore. Il suo valore si trova nella dashboard di OpenReplay in 'Preferences > Projects'.

### Se il tuo sito è una Single Page Application (SPA)

Puoi usare il tracker come istanza singleton, che è il modo consigliato per usarlo. 
In questo modo puoi accedere al tracker da qualsiasi punto della tua app:

```js
import { tracker } from '@openreplay/tracker'

tracker.configure({
	projectKey: PROJECT_KEY,
  ingestPoint: "https://openreplay.mydomain.com/ingest", // when dealing with the self-hosted version of OpenReplay
})

tracker.start() // returns a promise with session info (sessionID, sessionHash, userUUID)
```

Oppure puoi usare direttamente la classe `Tracker` per gestirne manualmente l'istanza:

```js
import OpenReplay from '@openreplay/tracker';
//...
const tracker = new OpenReplay({
  projectKey: PROJECT_KEY,
  ingestPoint: "https://openreplay.mydomain.com/ingest" // only required if using the self-hosted version of OpenReplay
});

tracker.start();
```

### Se la tua web app è Server-Side-Rendered (SSR)

Usa lo snippet seguente se la tua web app è Server-Side-Rendered (SSR) (ad es. NextJS, NuxtJS). 
Assicurati che il tracker venga eseguito in un ambiente browser e che `tracker.start()` venga chiamato una volta che l'app è stata servita al client (ad es. in `useEffect` o `componentDidMount`).

```js
import OpenReplay from '@openreplay/tracker/cjs';
//...
const tracker = new OpenReplay({
      projectKey: PROJECT_KEY
});
//...
function MyApp() {
  useEffect(() => { // use componentDidMount in case of React Class Component
    tracker.start();
  }, []);
}
```

Se vuoi approfondire la configurazione del tracker, consulta [JavaScript SDK](/sdk/constructor#initialization-options) per l'elenco delle opzioni disponibili.
