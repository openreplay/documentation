Se vuoi aggiornare la tua istanza di OpenReplay all'ultima versione, assicurati di eseguire una versione uguale o successiva a `v1.4.0`. In caso contrario, stai usando una versione obsoleta e devi prima aggiornare alla `v1.4.0` prima di poter passare a una versione più recente (v1.8.0+).

## Aggiornare il Backend (dalla v1.3.6 o precedente) alla v1.4.0

Per prima cosa, assicurati di essere sulla `v1.3.6` o precedente. Se è già così, ignora i comandi qui sotto e passa al punto 1). In caso contrario, aggiorna la tua installazione di OpenReplay alla `v1.3.6`:
   
```bash 
# Copy/backup the current openreplay folder to _version-number
mv openreplay openreplay_v1.3.5
git clone https://github.com/openreplay/openreplay -b v1.3.6
cd openreplay/scripts/helm
# bash upgrade.sh <old openreplay path>
bash upgrade.sh ~/openreplay_v1.3.5
```

Una volta sulla `v1.3.6`, procedi con i passaggi seguenti:

1. Copia/esegui il backup della cartella openreplay attuale in `_version-number`, come qui sotto:
   
  ```bash 
  mv openreplay openreplay_v1.3.6
  ```

2. Clona la nuova versione di OpenReplay. In questo esempio stiamo aggiornando alla v1.4.0:
   
  ```bash 
  git clone https://github.com/openreplay/openreplay -b v1.4.0
  ```

3. Esegui lo script seguente per aggiornare automaticamente il tuo `vars.yaml` al nuovo formato:
  
  ```bash
  cd openreplay/scripts/helmcharts
  ansible localhost -m template -a "src=vars_template.yaml dest=vars.yaml" -e @~/openreplay_v1.3.6/scripts/helm/vars.yaml
  ```

4. Aggiorna OpenReplay:

  ```bash
  cd openreplay/scripts/helmcharts
  helm ls -n app | tail -n +2 | awk '{print $1}' | xargs -I{} helm uninstall {} -n app
  helm uninstall nginx-ingress -n nginx-ingress
  helm upgrade --install openreplay ./openreplay -n app -f vars.yaml --atomic --set forceMigration=true
  ```
  
5. Se non utilizzi un load balancer e hai generato il certificato SSL tramite lo script `certmanager.sh`:

  ```
  cd /var/lib/openreplay/openreplay/scripts/helmcharts && bash certmanager.sh
  ```

6. Aggiorna la variabile `fromVersion` in `/openreplay/scripts/helmcharts/vars.yaml` in modo che rifletta la nuova versione. Ad esempio, se passi dalla `v1.3.6` alla `v1.4.0`, aggiorna `fromVersion` come segue:
  
  ```yaml
  fromVersion: "v1.4.0"
  ```

> **Nota:** 
Le modifiche manuali apportate a qualsiasi file di configurazione dei servizi (ad es. `openreplay/scripts/helm/app/<app>.yaml`) verranno reimpostate. Quindi, se hai override personalizzati, come l'uso di un [servizio di object storage esterno](/configuration/external-storage) per le tue registrazioni, o una maggiore capacità dei servizi (cpu/memoria), assicurati di applicarli alla nuova versione (in `/openreplay/scripts/helmcharts/vars.yaml`) prima di eseguire lo script di aggiornamento (passaggio 4).
