Dopo aver [configurato](/mcp/setup) l'app MCP ed effettuato l'accesso, puoi chiedere a Claude (o a un altro host MCP) di interrogare i tuoi dati di OpenReplay in linguaggio naturale. Questa pagina elenca ciò che l'MCP espone attualmente, con prompt di esempio per ciascuna funzione.

<Aside type="tip" title="Suggerimento" >
  Tutti i prompt funzionano sia che tu faccia riferimento al progetto per **nome** (ad es. *"MyApp"*) sia per **ID del sito** (ad es. *"site 1"*). Se non specifichi nulla, l'MCP usa il progetto più recente che hai menzionato.
</Aside>

## Cercare e filtrare le sessioni

L'MCP supporta gli stessi filtri disponibili nell'interfaccia di OpenReplay: browser, sistema operativo, dispositivo, paese, percorsi URL, clic, input, richieste di rete, errori, metadati, ID utente e durata.

```
Show me 20 recent sessions in MyApp
```

```
Sessions from Chrome users in France or Tunisia
```

```
Sessions with failed requests to /api/users in MyApp
```

```
Sessions where the user visited the signup page then clicked "Subscribe"
```

```
Sessions longer than 20 minutes for user tahay@asayer.io
```

Il risultato viene mostrato come elenco interattivo all'interno della chat, così puoi fare clic su qualsiasi sessione.

## Funnel

I funnel misurano la conversione lungo una serie di URL, clic, input o eventi personalizzati. Il drop-off viene mostrato passo per passo.

```
Show me the checkout funnel last week: /cart → /checkout → /confirm
```

```
Conversion from /pricing to /signup this month
```

```
Visited /pricing then clicked Subscribe
```

```
Page view /checkout followed by a JS exception
```

## Classifiche Top X

Trova le pagine più visitate, i browser, i paesi, i sistemi operativi, i dispositivi o le richieste di rete più frequenti.

```
What are the top visited pages this week?
```

```
Show browser distribution this month
```

```
Most popular countries last 30 days
```

```
Top 5 network requests today in MyApp
```

## Percorsi utente

Scopri come gli utenti navigano nel tuo prodotto: su quali pagine arrivano, dove vanno dopo, dove abbandonano.

```
Show me user journeys this month
```

```
Where do users drop off after the pricing page last week?
```

```
What pages do users visit after /signup?
```

```
Navigation paths for mobile users from France this week
```

## Web vitals e prestazioni

Core web vitals (LCP, FID, CLS) e metriche di prestazione, suddivisi per segmento.

```

Core web vitals for mobile users
```

```
Performance metrics for Chrome on Windows for user tahay@asayer.io
```

## Guardare un session replay

I replay vengono mostrati in un player incorporato nella chat. Puoi scorrere la timeline, mettere in pausa e ispezionare proprio come nell'interfaccia di OpenReplay.

```
Show me the replay of session 7891234567890
```

```
Replay the last session in the list above
```

## Combina e abbina

Il vero valore sta nel concatenare più strumenti. Ecco alcuni esempi:

- *"Trova le sessioni in cui gli utenti hanno incontrato un'eccezione JS su /checkout questa settimana, poi mostrami il replay della più recente e dimmi cosa è successo."*
- *"Estrai il funnel /pricing → /signup → /dashboard, poi per il passaggio con il maggior drop-off mostrami 5 sessioni che hanno abbandonato proprio lì."*
- *"Traccia la serie temporale delle sessioni dalla Francia di questo mese. Se c'è un picco, trova alcune sessioni di quel giorno e riassumi cosa hanno fatto."*

Poiché Claude può ragionare sui risultati tra una chiamata e l'altra agli strumenti, puoi restare a livello di conversazione invece di saltare da una dashboard all'altra.
