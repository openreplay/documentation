Con questo metodo puoi impostare il valore di uno dei campi di metadati configurati sulla piattaforma OpenReplay.

<Aside type="note">
	Puoi chiamare questo metodo quante volte vuoi, ma tieni presente che, se usi lo stesso attributo `key`, sulla piattaforma verrà salvato l'ultimo valore passato. Tutti i valori precedenti andranno persi.
</Aside>

Consulta i [metadati](/session-replay/metadata) per maggiori dettagli.

## Firma
```dart
OpenReplay.instance.setMetadata(String key, String value)
```

## Parametri

- `key: String`: la chiave dei metadati da salvare.
- `value: String`: il valore da salvare come metadato.

## Valore restituito

Questo metodo non restituisce alcun valore. Le informazioni vengono salvate direttamente come parte del replay e sono visibili all'interno della piattaforma OpenReplay.
