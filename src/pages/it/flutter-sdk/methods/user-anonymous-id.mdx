Associa uno userID anonimo alla sessione in corso di registrazione.

## Firma
```dart
OpenReplay.instance.userAnonymousID(String userId)
```

## Parametri

- `userId: String`: l'ID anonimo dell'utente. È una stringa e può essere qualsiasi valore, purché sia una stringa e ti permetta di identificare in modo univoco un utente all'interno del tuo sistema (ad es. email, ID del database, ecc.).

## Valore restituito

Questo metodo non restituisce alcun valore: i risultati saranno visibili nella piattaforma OpenReplay.
