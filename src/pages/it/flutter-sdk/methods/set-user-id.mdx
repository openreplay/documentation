Questo metodo ti permette di impostare un ID utente sulla sessione attualmente attiva. In questo modo puoi associare un utente al replay, e quindi filtrare e cercare le sessioni di un particolare utente.

## Firma
```dart
OpenReplay.instance.setUserID(String userId)
```

## Parametri

- `userId: String`: l'ID dell'utente. È una stringa e può essere qualsiasi valore, purché sia una stringa e ti permetta di identificare in modo univoco un utente all'interno del tuo sistema (ad es. email, ID del database, ecc.).

## Valore restituito

Questo metodo non restituisce alcun valore: i risultati saranno visibili nella piattaforma OpenReplay.
