Il tracker rimane in ascolto degli eventi di comparsa e scomparsa delle viste sullo schermo del telefono.

## Aggiungere le viste da tracciare

Lo SDK esporta `ORAnalyticsView`, che puoi usare per contrassegnare le viste e i componenti importanti.

```js
import OR from '@openreplay/react-native'

// ... your app UI

  <OR.ORAnalyticsView
    screenName="Pay confirmation page"
    viewName="New fancy button"
  >
    <ImportantRedButton />
  </OR.ORAnalyticsView>

// ...
```
