## Componenti UI

Le view sanificate verranno sfocate nel replay risultante. Puoi aggiungere qualsiasi componente UI: verrà rimosso automaticamente (per risparmiare memoria) non appena non sarà più sullo schermo.

### ORSanitizedView

Lo SDK esporta `ORSanitizedView`, che puoi usare per racchiudere i tuoi componenti sensibili e sfocarli.

```js
import OR from '@openreplay/react-native'

// ... your app UI

  <OR.ORSanitizedView>
    <SensitiveComponent />
  </OR.ORSanitizedView>

// ...
```
