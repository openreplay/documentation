Il tracker rimane in ascolto dell'evento di modifica del valore (con debounce) e invia il valore risultante al backend di OpenReplay.

## Aggiungere gli input da tracciare

Lo SDK esporta `ORTrackedInput`, che puoi usare come i normali componenti TextInput.

```js
import OR from '@openreplay/react-native'

// ... your app UI

  <OR.ORTrackedInput
    style={styles.input}
    onChangeText={onChangeNumber}
    value={number}
    placeholder="important placeholder"
  />

// ...
```
