## Installazione

La riga seguente installa il tracker e, insieme a esso, lo SDK, così potrai sfruttare tutte le funzionalità del tracker.

```bash
npm i @openreplay/react-native
```

## Inizializzazione

Quando istanzi il tracker di OpenReplay, puoi fornire diverse opzioni di configurazione per personalizzare molti aspetti della registrazione e della relativa esperienza. Devi impostare l'opzione `projectKey` nel costruttore. Puoi ottenere questo valore dalla tua dashboard di OpenReplay, in 'Preferences > Projects'.

<Aside type="tip">
	Tieni presente che, se hai più progetti, devi fare attenzione a scegliere la chiave del progetto corretta.
</Aside>


### Aggiungere il codice di tracciamento

Aggiungi il seguente codice al tuo file root:

```js
import Openreplay from '@openreplay/react-native';

// ...
useEffect(() => {
	Openreplay.tracker.startSession(
		'yourProjectKey',
		options, // explained below, set {} if empty
		'https://local.openreplay.instance/ingest' // if you're using our Serverless/SaaS plan then 'https://api.openreplay.com/ingest'
	);
}, [])
```

### Aggiungere i componenti avanzati

Per tracciare le interazioni degli utenti all'interno dell'app, dovrai aggiungere alla tua applicazione i seguenti componenti:

- `ORTouchTrackingView` - aggiunto a livello root per tracciare le interazioni touch
- `ORTrackedInput` - wrapper attorno all'Input di React-Native che invia segnali ogni volta che l'utente termina l'inserimento
- `ORSanitizedView` - sfoca il contenuto al suo interno

```js
// App.tsx
import Openreplay from '@openreplay/react-native';

function App() {
	const start = () => {
	    Openreplay.tracker.startSession(
	      process.env.REACT_APP_KEY!,
	      {},
	      process.env.REACT_APP_INGEST
	    );
	    Openreplay.tracker.setMetadata('key', 'value');
	    Openreplay.tracker.setUserID('user-id');
	    Openreplay.patchNetwork(global, () => false, {});
	};
	
	React.useEffect(() => start(), []);
	
	return (
		// this top-level view is required to track touch interactions
		<Openreplay.ORTouchTrackingView style={styles.container}> 
		      <View style={styles.container}>
		         <Openreplay.ORTrackedInput
		          style={styles.input}
		          onChangeText={onChangeNumber}
		          value={number}
		          placeholder="Trackable input"
		          numberOfLines={1}
		        />
		
		        <Openreplay.ORSanitizedView style={styles.sanitizedView}>
		          <Text>Contents of this view are sanitized and invisible on the recording</Text>
		        </Openreplay.ORSanitizedView>
		      </View>
		</Openreplay.ORTouchTrackingView>
	)
}
```

## Opzioni di inizializzazione

Per impostazione predefinita, tutte le opzioni sono impostate su `true`:

- `crashes: Bool` Abilita crashlytics.
- `analytics: Bool` Abilita il tracciamento analytics delle viste contrassegnate.
- `performances: Bool` Abilita il listener delle prestazioni.
- `logs: Bool` Abilita il listener dei log.
- `screen: Bool` Abilita la registrazione dello schermo.
