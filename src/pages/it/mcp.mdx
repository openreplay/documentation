L'app **OpenReplay MCP** collega la tua istanza di OpenReplay a un host di chat con supporto MCP (Claude Desktop, Claude Code, ChatGPT, Codex), così puoi esplorare la product analytics e i session replay in linguaggio naturale. Chiedi un grafico, approfondisci un funnel, trova una sessione e aprine il replay: tutto direttamente dalla chat.

Funziona sia con **OpenReplay Cloud** sia con le istanze **self-hosted**.

<Aside type="tip" title="Cosa ottieni" >
  - Cerca le sessioni con gli stessi filtri che usi nell'interfaccia di OpenReplay.
  - Visualizza direttamente nella chat serie temporali, funnel, percorsi utente, web vitals e classifiche top X.
  - Guarda i session replay direttamente nella chat.
  - Combina tutto: cerca → scegli una sessione → apri il replay → chiedi a Claude di riassumerla.
</Aside>

## Compatibilità

L'app usa il protocollo MCP standard su stdio, quindi funziona con:

- **Claude Desktop** (macOS, Windows)
- **Claude Code**
- **ChatGPT** (tramite il connettore MCP)
- **Codex**
- Qualsiasi altro host che supporti MCP
