Associa un userID anonimo alla sessione in corso di registrazione.

## Firma
```kotlin
OpenReplay.userAnonymousID(userID: String)
```

## Parametri

- `userID: String`: l'ID anonimo dell'utente. È una stringa e può essere qualsiasi valore, purché sia una stringa e permetta di identificare in modo univoco un utente all'interno del tuo sistema (ad es. email, ID del database, ecc.).

## Valore restituito

Questo metodo non restituisce alcun valore; i risultati saranno visibili nella piattaforma OpenReplay.
