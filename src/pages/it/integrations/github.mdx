Integra GitHub con OpenReplay e crea issue direttamente dalla pagina della registrazione.

## Usare OpenReplay open source 

#### 1. Crea un token di accesso personale

1. Accedi a GitHub, poi vai su [Settings > Developers Settings > Personal access tokens](https://github.com/settings/tokens)
2. Fai clic su 'Generate a new token'
3. Seleziona gli scope `repo:status`, `repo_deployment`,`public_repo`, `read:user` e `user:email`
4. Premi 'Generate token', poi copia il token

#### 2. Abilita GitHub in OpenReplay

1. Vai alla dashboard di OpenReplay, poi su 'Preferences > Integration'
2. Seleziona GitHub. Se non lo vedi, significa che hai abilitato Jira (non è possibile usarli entrambi contemporaneamente, quindi assicurati di disattivare prima l'integrazione con Jira).
3. Incolla il `token` generato in precedenza

A quel punto in tutte le registrazioni comparirà un pulsante 'Create Issue', per creare e assegnare rapidamente le issue in GitHub.

## Usare OpenReplay Cloud

Vai su 'Preferences > Integration' e fai clic su GitHub. Verrai reindirizzato a GitHub per l'autenticazione. Non devi fare altro. A quel punto in tutte le registrazioni comparirà un pulsante 'Create Issue', per creare e assegnare rapidamente le issue in GitHub.
