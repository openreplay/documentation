Come integrare Jira Cloud con OpenReplay.

## 1. Crea un nuovo token API

1. Accedi alla pagina dei [token JIRA](https://id.atlassian.com/manage/api-tokens).
2. Fai clic su *Create API token*.
3. In label, inserisci "openreplay" e fai clic su *Create*.
4. Fai clic su *Copy to clipboard*.

## 2. Abilita JIRA Cloud in OpenReplay

1. Vai alla dashboard di OpenReplay, in 'Preferences > Integration'
2. Seleziona Jira. Se non lo vedi, significa che hai abilitato GitHub (non è possibile usarli entrambi contemporaneamente, quindi assicurati di disattivare prima l'integrazione con GitHub).
3. Inserisci il tuo `Username` e il tuo `API token`, poi digita l'URL della tua istanza di Jira Cloud

A quel punto in tutte le registrazioni comparirà un pulsante 'Create Issue', per creare e assegnare rapidamente le issue in Jira.
