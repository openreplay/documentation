Jira Cloud を OpenReplay と連携する方法を紹介します。

## 1. 新しい API トークンを作成する

1. [JIRA トークン](https://id.atlassian.com/manage/api-tokens) のページにログインします。
2. *Create API token* をクリックします。
3. ラベルに「openreplay」と入力し、*Create* をクリックします。
4. *Copy to clipboard* をクリックします。

## 2. OpenReplay で JIRA Cloud を有効にする

1. OpenReplay ダッシュボードで「Preferences > Integration」に移動します。
2. Jira を選択します。表示されない場合は、GitHub が有効になっている可能性があります（両方を同時に使用することはできないため、先に GitHub インテグレーションを無効にしてください）。
3. `Username` と `API token` を入力し、Jira Cloud インスタンスの URL を入力します。

すると、すべての録画に「Create Issue」ボタンが表示され、Jira で Issue をすばやく作成して担当者を割り当てられるようになります。
