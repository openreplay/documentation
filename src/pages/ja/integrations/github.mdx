GitHub を OpenReplay と連携し、録画ページから直接 Issue を作成できます。

## オープンソース版 OpenReplay を使用する場合

#### 1. パーソナルアクセストークンを作成する

1. GitHub にログインし、[Settings > Developers Settings > Personal access tokens](https://github.com/settings/tokens) に移動します。
2. 「Generate a new token」をクリックします。
3. `repo:status`、`repo_deployment`、`public_repo`、`read:user`、`user:email` のスコープを選択します。
4. 「Generate token」を押し、トークンをコピーします。

#### 2. OpenReplay で GitHub を有効にする

1. OpenReplay ダッシュボードで「Preferences > Integration」に移動します。
2. GitHub を選択します。表示されない場合は、Jira が有効になっている可能性があります（両方を同時に使用することはできないため、先に Jira インテグレーションを無効にしてください）。
3. 先ほど生成した `token` を貼り付けます。

すると、すべての録画に「Create Issue」ボタンが表示され、GitHub で Issue をすばやく作成して担当者を割り当てられるようになります。

## OpenReplay Cloud を使用する場合

「Preferences > Integration」に移動し、GitHub をクリックします。認証のために GitHub にリダイレクトされます。必要な操作はこれだけです。すると、すべての録画に「Create Issue」ボタンが表示され、GitHub で Issue をすばやく作成して担当者を割り当てられるようになります。
