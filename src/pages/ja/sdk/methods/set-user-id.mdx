このメソッドを使用すると、現在アクティブなセッションにユーザー ID を設定できます。これにより、ユーザーをリプレイに関連付けられるため、特定のユーザーのセッションをフィルタリングして検索できるようになります。

## シグネチャ
```js
setUserID(id: string): void
```

## パラメーター

- `id: string`: ユーザーの ID。文字列であり、システム内でユーザーを一意に識別できるものであれば何でも構いません（メールアドレス、データベース ID など）。

## 戻り値

このメソッドは値を返しません。結果は OpenReplay プラットフォームで確認できます。
