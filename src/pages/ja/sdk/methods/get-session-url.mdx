このメソッドを使用すると、アクティブなセッションの URL を取得できます。この URL は OpenReplay のダッシュボード用で、OpenReplay を自社のスタックに統合したい場合に便利です。

## シグネチャ

```js
getSessionURL({ withCurrentTime?: boolean }): string | undefined
```

## パラメーター

- `withCurrentTime: boolean`: オプションのパラメーターで、デフォルトは `false` です。`true` の場合、URL にはメソッドが呼び出された時点のリプレイ内のタイムスタンプが含まれます。

## 戻り値

このメソッドは、OpenReplay のプラットフォームで再生されるアクティブなセッションの URL を返します。オプションで、URL にメソッドが呼び出された時点のタイムスタンプを含めることで、リプレイ内のその位置に直接ジャンプできます。
