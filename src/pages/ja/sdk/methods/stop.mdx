このメソッドは、トラッカーとアクティブなセッションを停止します。このメソッドを使用しない場合、タブを閉じるか、サイトから移動してから数分後に、セッションは自動的に停止されます。

## シグネチャ

```js
stop(): string | undefined
```

## 戻り値

停止したセッションの `sessionHash` を返します。
