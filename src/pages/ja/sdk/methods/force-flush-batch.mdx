現在のメッセージのバッチを、完了を待たずにフラッシュするようトラッカーに強制します。セッション後にタブやウィンドウを閉じる必要がある場合に便利です。このメソッドは Web ワーカーにもメッセージを送信し、Web ワーカーが現在のメッセージのバッチを使ってネットワークリクエストを開始します。

## シグネチャ

```ts
forceFlushBatch(): void
```
