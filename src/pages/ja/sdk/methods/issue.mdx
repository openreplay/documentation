このメソッドは、「テクニカルイベント」（別名「イシュー」）を報告するために使用できます。これらのイシューを使用すると、トラッカーがデフォルトでは検出できない問題に関する追加情報を報告できます。たとえば、ユーザーが EC サイトで購入の支払いを試み、決済ゲートウェイからエラーを受け取る場合が挙げられます。トラッカーはエラーを含むペイロードを記録できますが、それを問題として識別することはできません。このメソッドを使えば、この挙動をイシューとしてフラグ付けし、セッションをさらにフィルタリングできます。

<Aside type="tip">
  カスタムイベントのトラッキング方法については、詳しいチュートリアルもあります。[こちら](/tutorials/custom-events)からご覧ください。
</Aside>

## シグネチャ

```js
issue(key: string, payload?: any): void
```

## パラメーター

- `key: string`: イベントのデータが保存されるキーの名前。この値は、OpenReplay プラットフォーム内のフィルターフィールドで使用できます。
- `payload: any`: トラッキングしたイベントに関連するデータ。シリアライズ可能な任意のオブジェクトを保存できます。

## 戻り値

このメソッドは値を返しません。トラッキングした情報は OpenReplay プラットフォーム内で確認できます。
