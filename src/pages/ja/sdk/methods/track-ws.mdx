このメソッドを使用すると、個々の WebSocket チャネルと、メッセージの方向（受信/送信）をトラッキングできます。

## シグネチャ

```ts 
trackWs: (channelName: string) => (msgType: string, data: string, dir: 'up' | 'down') => void
```

## パラメーター

- `channelName: string`: WS チャネルの名前。

## 戻り値

メッセージタイプ（または名前）、データ、メッセージの方向（up/down === 送信/受信）をパラメーターとして受け取る、ws メッセージに適用するフックを返します。
