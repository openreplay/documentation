トラッカーが JS エラー発生時にデフォルトで記録する情報では不十分な場合に、このメソッドを使用できます。`handleError` メソッドは、キャッチした例外、拒否された Promise、またはエラーイベントを手動で報告します。詳細は[エラーレポート](/session-replay/error-reporting#manually-logging-exceptions)を参照してください。

## シグネチャ

```js 
handleError: (e: Error | ErrorEvent | PromiseRejectionEvent, metadata?: Record<string, any>) => void
```

## パラメーター

- `e: Error | ErrorEvent | PromiseRejectionEvent`: キャッチした実際のエラーオブジェクト。
- `metadata: Record<string, any>`: **[オプション]** このエラーに関連付けて保存したい追加情報をすべて含む、辞書形式の構造。

## 戻り値

このメソッドは値を返しません。保存された情報は OpenReplay プラットフォーム内で確認できます。
