このメソッドを使用すると、ユーザーのセッション中の重要なイベントやインシデントをマークできます。インシデントは通常、エラー、クラッシュ、その他の注意を要する注目すべき出来事など、重要な事象を強調するために使用されます。これらのインシデントをマークしておくと、セッションリプレイ内で簡単に特定して分析できます。

## シグネチャ

```js
// call incident function and pass label, startTime, and endTime (label and endTime are optional)
incident({ label: 'incident', startTime: Date.now() - 1000, endTime: Date.now() })
```

## パラメーター

- `label: string`: マークするイベントの名前。
- `startTime: number`: イベントの開始を示すタイムスタンプ。
- `endTime: number` : イベントの終了のタイムスタンプ。
