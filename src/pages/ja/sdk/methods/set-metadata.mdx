このメソッドを使用すると、OpenReplay プラットフォームで設定されたメタデータフィールドの 1 つに値を設定できます。

<Aside type="note">
このメソッドは何度でも呼び出せますが、同じ `key` 属性を使用した場合、最後に渡した値のみがプラットフォームに保存される点に注意してください。それ以前の値はすべて失われます。
</Aside>

詳細については、[メタデータ](/session-replay/metadata)を参照してください。

## シグネチャ
```js
setMetadata(key: string, value: string): void
```

## パラメーター

- `key: string`: 保存するメタデータのキー。
- `value: string`: メタデータとして保存する値。

## 戻り値

このメソッドは値を返しません。情報はリプレイの一部として直接保存され、OpenReplay プラットフォーム内で確認できます。
