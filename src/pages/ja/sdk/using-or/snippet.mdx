トラッカーを Web アプリケーションに追加したいが、使用しているフレームワークが弊社でサポートされていない場合や、VanillaJS のみを使用している場合は、
JavaScript スニペットを直接追加できます。

## スニペットの取得

必要な JavaScript スニペットは、OpenReplay ポータルでプロジェクトをセットアップする際に提供されます。
新しいプロジェクトを追加すると、次のような画面が表示されます。

![プロジェクトの準備完了](/using-or/snippet/new-project-ready.png)

この画面が表示されたら、「Complete Project Setup」ボタンをクリックします。
JS スニペットが表示されるページに移動します。


![JS スニペットの取得](/using-or/snippet/getting-snippet.png)

次に、「Script」タブをクリックすると、実際の JavaScript スニペットが表示されます。

![スニペットの表示](/using-or/snippet/snippet-visible.png)

スクリプトを取得し、`<head>` タグ内に直接追加すれば、トラッカーは自動的に動作を開始します。

<Aside type="tip">
上のスクリーンショットのステップ 1 でデータ記録オプションを変更すると、最終的なスニペットも変わる点にご注意ください。
そのため、まず記録オプションを設定してから、実際のスニペットをコピーしてください。
</Aside>
