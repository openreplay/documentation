React アプリケーションでトラッカーを動作させるのは非常に簡単です。

## トラッキングコードの追加

SPA（シングルページアプリケーション）を構築している場合は、エントリーポイントに次のコードを追加するだけです。

```jsx
import { tracker } from '@openreplay/tracker';

tracker.configure({
  projectKey: "<your project key>", 
  ingestPoint: "https://openreplay.mydomain.com/ingest" // only required if using the self-hosted version of OpenReplay
});

function YourMainComponent({props}) {
    //some code here...

    useEffect(() => {
        tracker.start();
    }, [])

    return //....
}
```

または、`Tracker` クラスを直接使用して、インスタンスを手動で管理することもできます。

```jsx
import Tracker from '@openreplay/tracker';

const tracker = new Tracker({
  projectKey: "<your project key>",  
  ingestPoint: "https://openreplay.mydomain.com/ingest" // only required if using the self-hosted version of OpenReplay
});

function YourMainComponent({props}) {
    //some code here...

    useEffect(() => {
        tracker.start();
    }, [])

    return //....
}
```

つまり、スクリプトの先頭でトラッカーをインスタンス化し、ページの読み込み後に `useEffect` フックを使って開始できます。

<Aside type="tip">
新しいプロジェクトを作成するときに、CDN からトラッカーの [JS スニペット版](/sdk/using-or/snippet#getting-the-snippet)を直接取得することもできますが、そのコードは最小限すぎるため、カスタマイズや追加プラグインの導入が難しくなります。
</Aside>

### コード内での "projectKey" の扱い

セキュリティ上の理由から、`projectKey` をアプリケーションコードに直接ハードコーディングするのは避けてください。代わりに、設定ファイルや環境管理の仕組みに保存してください。

プロジェクトの構成に応じて、いくつかの方法があります。
- **環境変数**: Create React App を使用している場合は、その[環境変数の組み込みサポート](https://create-react-app.dev/docs/adding-custom-environment-variables/)を活用できます
- **設定ファイル**: バージョン管理から除外した専用の設定ファイルを使用します
- **環境管理**: `dotenv` などのツールを使うと、環境ごとに異なるキーを管理しやすくなります

以下に例を示します。
```javascript
// Access the key from environment variables
const openReplayKey = process.env.REACT_APP_OPENREPLAY_KEY;
```

## より複雑なものを構築していますか？

React で複雑なアプリケーションを構築している場合は、[Next](/sdk/using-or/next)、[Remix](/sdk/using-or/remix)、または同様のフレームワークを使用している可能性が高いでしょう。お使いのフレームワークを見つけるには、[トラッカーのセットアップ](/sdk/using-or)セクションをご確認ください。

## ご質問はありますか？
