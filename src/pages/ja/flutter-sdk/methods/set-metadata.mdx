このメソッドを使用すると、OpenReplay プラットフォームで設定されているメタデータフィールドのいずれかの値を設定できます。

<Aside type="note">
	このメソッドは何度でも呼び出せますが、同じ `key` 属性を使用した場合は、最後に渡した値がプラットフォームに保存され、それ以前の値はすべて失われる点にご注意ください。
</Aside>

詳細については、[メタデータ](/session-replay/metadata)をご覧ください。

## シグネチャ
```dart
OpenReplay.instance.setMetadata(String key, String value)
```

## パラメーター

- `key: String`: 保存するメタデータのキー。
- `value: String`: メタデータとして保存する値。

## 戻り値

このメソッドは値を返しません。情報はリプレイの一部として直接保存され、OpenReplay プラットフォーム内で確認できます。
