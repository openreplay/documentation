このメソッドを使用すると、現在アクティブなセッションにユーザー ID を設定できます。これによりユーザーをリプレイに関連付けられるため、特定のユーザーのセッションをフィルタリングおよび検索できるようになります。

## シグネチャ
```dart
OpenReplay.instance.setUserID(String userId)
```

## パラメーター

- `userId: String`: ユーザーの ID。文字列であれば何でもかまいませんが、システム内でユーザーを一意に識別できるもの（メールアドレス、データベース ID など）である必要があります。

## 戻り値

このメソッドは値を返しません。結果は OpenReplay プラットフォームで確認できます。
