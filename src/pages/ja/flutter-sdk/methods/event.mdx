このメソッドを使用すると、「機能イベント」を報告できます。機能イベントを使うと、機能面で重要であるにもかかわらず、トラッカーがデフォルトでは自動的に検出・フラグ付けできない、ユーザーセッション内の瞬間を通知できます。機能イベントの例として、ユーザーがショッピングカートに商品を追加する操作があります。トラッカーはこの操作自体を記録できますが、セッションのタイムライン上で重要なイベントとしてフラグ付けすることまでは認識できません。しかし、このメソッドを使えば、手動でそれを行えます。

詳細については、[カスタムイベント](/product-analytics/data-management)をご覧ください。

## シグネチャ

```dart
OpenReplay.instance.event(String name, [Object? payload])
```

## パラメーター

- `name: String`: イベントの名前。この名前は、OpenReplay プラットフォーム内でのフィルタリングや検索に使用できます。
- `payload: Object?`: イベントの内容。`String` はそのまま送信され、それ以外は JSON エンコードされます。エンコードできない場合は `toString()` にフォールバックします。省略すると空のペイロードが送信されます。

## 例

```dart
OpenReplay.instance.event('checkout_started', {'cart': 3, 'currency': 'EUR'});
OpenReplay.instance.event('promo_banner_dismissed');
```
