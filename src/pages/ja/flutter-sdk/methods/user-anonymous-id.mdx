記録中のセッションに匿名の userID を関連付けます。

## シグネチャ
```dart
OpenReplay.instance.userAnonymousID(String userId)
```

## パラメーター

- `userId: String`: ユーザーの匿名 ID。文字列であれば何でもかまいませんが、システム内でユーザーを一意に識別できるもの（メールアドレス、データベース ID など）である必要があります。

## 戻り値

このメソッドは値を返しません。結果は OpenReplay プラットフォームで確認できます。
