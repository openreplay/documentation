OpenReplay インスタンスを最新バージョンにアップグレードする場合は、`v1.4.0` 以上のバージョンを実行していることを確認してください。そうでない場合は非推奨バージョンを使用していることになるため、最近のバージョン（v1.8.0 以降）にアップグレードする前に、まず `v1.4.0` にアップグレードする必要があります。

## バックエンドを v1.4.0 にアップグレードする（v1.3.6 以前から）

まず、`v1.3.6` 以前のバージョンを使用していることを確認してください。すでにそうである場合は、以下のコマンドは無視してステップ 1) に進みます。そうでない場合は、OpenReplay のインストールを `v1.3.6` に更新します。
   
```bash 
# Copy/backup the current openreplay folder to _version-number
mv openreplay openreplay_v1.3.5
git clone https://github.com/openreplay/openreplay -b v1.3.6
cd openreplay/scripts/helm
# bash upgrade.sh <old openreplay path>
bash upgrade.sh ~/openreplay_v1.3.5
```

`v1.3.6` になったら、以下の手順に進みます。

1. 現在の openreplay フォルダーを、次のように `_version-number` へコピー／バックアップします。
   
  ```bash 
  mv openreplay openreplay_v1.3.6
  ```

2. 新しいバージョンの OpenReplay をクローンします。この例では v1.4.0 にアップグレードします。
   
  ```bash 
  git clone https://github.com/openreplay/openreplay -b v1.4.0
  ```

3. 以下のスクリプトを実行して、`vars.yaml` を新しい形式に自動的にアップグレードします。
  
  ```bash
  cd openreplay/scripts/helmcharts
  ansible localhost -m template -a "src=vars_template.yaml dest=vars.yaml" -e @~/openreplay_v1.3.6/scripts/helm/vars.yaml
  ```

4. OpenReplay をアップグレードします。

  ```bash
  cd openreplay/scripts/helmcharts
  helm ls -n app | tail -n +2 | awk '{print $1}' | xargs -I{} helm uninstall {} -n app
  helm uninstall nginx-ingress -n nginx-ingress
  helm upgrade --install openreplay ./openreplay -n app -f vars.yaml --atomic --set forceMigration=true
  ```
  
5. ロードバランサーを使用しておらず、`certmanager.sh` スクリプトで SSL 証明書を生成した場合は、次を実行します。

  ```
  cd /var/lib/openreplay/openreplay/scripts/helmcharts && bash certmanager.sh
  ```

6. `/openreplay/scripts/helmcharts/vars.yaml` の `fromVersion` 変数を、新しいバージョンを反映するように更新します。たとえば `v1.3.6` から `v1.4.0` に移行する場合は、`fromVersion` を次のように更新します。
  
  ```yaml
  fromVersion: "v1.4.0"
  ```

> **注記**：
サービス設定ファイル（例: `openreplay/scripts/helm/app/<app>.yaml`）に手動で加えた上書き設定はリセットされます。そのため、レコーディング用の[外部オブジェクトストレージサービス](/configuration/external-storage)の利用や、サービス容量（CPU／メモリ）の増強といったカスタムの上書き設定がある場合は、アップグレードスクリプトを実行する前（ステップ 4）に、新しいバージョンの `/openreplay/scripts/helmcharts/vars.yaml` に必ず適用してください。
