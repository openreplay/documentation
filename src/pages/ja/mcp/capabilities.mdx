MCP アプリを [セットアップ](/mcp/setup) してログインすると、Claude（または他の MCP ホスト）に、平易な言葉で OpenReplay のデータへのクエリを依頼できます。このページでは、MCP が現在提供している機能を、それぞれのプロンプト例とともに紹介します。

<Aside type="tip" title="ヒント" >
  プロジェクトを **名前**（例：*"MyApp"*）で指定しても、**サイト ID**（例：*"site 1"*）で指定しても、すべてのプロンプトが動作します。指定しない場合、MCP は最後に言及したプロジェクトを使用します。
</Aside>

## セッションの検索とフィルター

MCP は、OpenReplay の UI で利用できるものと同じフィルターをサポートしています。ブラウザー、OS、デバイス、国、URL パス、クリック、入力、ネットワークリクエスト、エラー、メタデータ、ユーザー ID、継続時間です。

```
Show me 20 recent sessions in MyApp
```

```
Sessions from Chrome users in France or Tunisia
```

```
Sessions with failed requests to /api/users in MyApp
```

```
Sessions where the user visited the signup page then clicked "Subscribe"
```

```
Sessions longer than 20 minutes for user tahay@asayer.io
```

結果はチャット内にインタラクティブなリストとして表示されるため、任意のセッションをクリックして開けます。

## ファネル

ファネルは、一連の URL、クリック、入力、またはカスタムイベントにわたるコンバージョンを測定します。離脱はステップごとに表示されます。

```
Show me the checkout funnel last week: /cart → /checkout → /confirm
```

```
Conversion from /pricing to /signup this month
```

```
Visited /pricing then clicked Subscribe
```

```
Page view /checkout followed by a JS exception
```

## トップ X

最も閲覧されているページ、上位のブラウザー、国、OS、デバイス、ネットワークリクエストを確認できます。

```

```

```
Show browser distribution this month
```

```
Most popular countries last 30 days
```

```
Top 5 network requests today in MyApp
```

## ユーザージャーニー

ユーザーがプロダクト内をどのように移動するか（どのページに到達し、次にどこへ進み、どこで離脱するか）を確認できます。

```
Show me user journeys this month
```

```
Where do users drop off after the pricing page last week?
```

```
What pages do users visit after /signup?
```

```
Navigation paths for mobile users from France this week
```

## Web バイタルとパフォーマンス

コア Web バイタル（LCP、FID、CLS）とパフォーマンスメトリクスを、セグメント別に分析できます。

```
Show me web vitals for this week
```

```
How is my site performance past month?
```

```
Core web vitals for mobile users
```

```
Performance metrics for Chrome on Windows for user tahay@asayer.io
```

## セッションリプレイを視聴する

リプレイは、チャット内の埋め込みプレーヤーで表示されます。OpenReplay の UI と同じように、シークや一時停止、詳細な確認ができます。

```
Show me the replay of session 7891234567890
```

```
Replay the last session in the list above
```

## 組み合わせて使う

本当の価値は、ツールを連鎖させることで生まれます。いくつか例を示します。

- *"今週 /checkout で JS 例外が発生したセッションを探し、最新のもののリプレイを表示して、何が起きたのか教えて。"*
- *"/pricing → /signup → /dashboard のファネルを取得し、離脱が最も大きいステップについて、そこで離脱したセッションを 5 件表示して。"*
- *"今月のフランスからのセッションの時系列をプロットして。スパイクがあれば、その日のセッションをいくつか探して、何をしていたか要約して。"*

Claude はツール呼び出しの間で結果を踏まえて推論できるため、ダッシュボードを行き来することなく、会話のレベルで作業を進められます。
