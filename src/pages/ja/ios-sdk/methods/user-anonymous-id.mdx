記録中のセッションに匿名のユーザー ID を関連付けます。

## シグネチャ
```swift
ORTracker.shared.userAnonymousID(_ userID: String)
```

## パラメーター

- `userID: String`：ユーザーの匿名 ID です。文字列であれば何でもかまいませんが、システム内でユーザーを一意に識別できるもの（メールアドレス、データベース ID など）にしてください。

## 戻り値

このメソッドは値を返しません。結果は OpenReplay プラットフォームで確認できます。
