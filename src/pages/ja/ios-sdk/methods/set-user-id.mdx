このメソッドを使用すると、現在アクティブなセッションにユーザー ID を設定できます。これによりユーザーをリプレイに関連付けられるため、特定のユーザーのセッションをフィルターしたり検索したりできるようになります。

## シグネチャ
```swift
ORTracker.shared.setUserID(_ userID: String)
```

## パラメーター

- `userID: String`：ユーザーの ID です。文字列であれば何でもかまいませんが、システム内でユーザーを一意に識別できるもの（メールアドレス、データベース ID など）にしてください。

## 戻り値

このメソッドは値を返しません。結果は OpenReplay プラットフォームで確認できます。
