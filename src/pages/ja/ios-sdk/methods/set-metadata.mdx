このメソッドを使用すると、OpenReplay プラットフォームで設定されたメタデータフィールドのいずれかの値を設定できます。

<Aside type="note">
	このメソッドは何度でも呼び出せますが、同じ `key` 属性を使用した場合、最後に渡した値がプラットフォームに保存され、以前の値はすべて失われる点に注意してください。
</Aside>

詳細については、[メタデータ](/session-replay/metadata) を参照してください。

## シグネチャ
```swift
ORTracker.shared.setMetadata(key: String, value: String)
```

## パラメーター

- `key: string`：保存するメタデータのキー。
- `value: string`：メタデータとして保存する値。

## 戻り値

このメソッドは値を返しません。情報はリプレイの一部として直接保存され、OpenReplay プラットフォーム内で確認できます。
