このメソッドはトラッカーを開始するために使用します。トラッカーを開始すると、セッションの録画が始まります。

## シグネチャ

```swift
ORTracker.shared.start(projectKey: String, options: OROptions)
	```

### 初期化オプション

利用可能なオプション：

- `crashes: Bool` クラッシュ解析（crashlytics）を有効にします。
- `analytics: Bool` ビューの分析を有効にします。
- `performances: Bool` パフォーマンスリスナーを有効にします。
- `logs: Bool` ログリスナーを有効にします。
- `screen: Bool` スクリーンレコーダーを有効にします。
- `wifiOnly: Bool` ユーザーが Wi-Fi に接続している場合にのみ、トラッカーを開始します。

デフォルトはすべて `true` です。
