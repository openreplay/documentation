このメソッドを使用すると、「機能イベント」を報告できます。機能イベントを使うと、機能的な観点から重要であり、かつデフォルトではトラッカーが自動的に検出してフラグを立てられない、ユーザーのセッション内の瞬間を知らせることができます。機能イベントの例として、ユーザーがショッピングカートに商品を追加する操作が挙げられます。トラッカーはこの操作を記録できますが、セッションのタイムライン上で重要なイベントとしてフラグを立てるべきかどうかは判断できません。しかし、このメソッドを使えば、手動でフラグを立てることができます。

詳細については、[カスタムイベント](/product-analytics/data-management) を参照してください。

## シグネチャ

```swift
ORTracker.shared.event(name: String, payload: Encodable?)
```

## パラメーター

- `key: string`：情報を保存するキーの名前です。このキーは、OpenReplay プラットフォーム内でのフィルタリングや検索に使用できます。
- `payload: Encodable`：イベントの内容です。エンコード可能な（JSON）任意のデータを指定できます。
