トラッカーは、ビューの表示・非表示イベントをリッスンします。

## トラッキング対象のビューを追加する

### SwiftUI

`.observeView(title:viewName:)` を使用して、ビューを監視します。

- `title: String` - 画面または機能のタイトル
- `viewName: String` - トラッカーに登録するビューの名前

```swift
import ORTracker

TextField("Input", text: $text)
 .observeView(title: "Screen title", viewName: "test input name")
```

### UIKit
```swift
import ORTracker

Analytics.shared.addObservedView(view: inputEl, title: "Screen title", viewName: "test input name")
```
