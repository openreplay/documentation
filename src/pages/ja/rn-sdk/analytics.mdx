トラッカーは、スマートフォンの画面上でビューが表示されたとき、および非表示になったときのイベントを監視します。

## トラッキング対象ビューの追加

SDK は `ORAnalyticsView` をエクスポートしており、重要なビューやコンポーネントにマークを付けるために使用できます。

```js
import OR from '@openreplay/react-native'

// ... your app UI

  <OR.ORAnalyticsView
    screenName="Pay confirmation page"
    viewName="New fancy button"
  >
    <ImportantRedButton />
  </OR.ORAnalyticsView>

// ...
```
