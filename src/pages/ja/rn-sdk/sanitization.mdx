## UI コンポーネント

サニタイズされたビューは、生成されるリプレイ内でぼかし処理されます。任意の UI コンポーネントを追加でき、画面から外れると（メモリを節約するため）自動的に削除されます。

### ORSanitizedView

SDK は `ORSanitizedView` をエクスポートしており、機密性の高いコンポーネントをラップしてぼかし処理するために使用できます。

```js
import OR from '@openreplay/react-native'

// ... your app UI

  <OR.ORSanitizedView>
    <SensitiveComponent />
  </OR.ORSanitizedView>

// ...
```
