トラッカーは値の変更イベント（デバウンス処理済み）を監視し、その結果の値を OpenReplay バックエンドに送信します。

## トラッキング対象の入力の追加

SDK は `ORTrackedInput` をエクスポートしており、通常の TextInput コンポーネントと同じように使用できます。

```js
import OR from '@openreplay/react-native'

// ... your app UI

  <OR.ORTrackedInput
    style={styles.input}
    onChangeText={onChangeNumber}
    value={number}
    placeholder="important placeholder"
  />

// ...
```
