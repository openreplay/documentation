匿名の userID を、録画中のセッションに関連付けます。

## シグネチャ

```swift
ORTracker.userAnonymousID(userID: String)
```

## パラメーター

- `userID: String`：ユーザーの匿名 ID です。文字列であり、システム内でユーザーを一意に識別できるものであれば何でも構いません（メールアドレス、データベース ID など）。

## 戻り値

このメソッドは値を返しません。結果は OpenReplay プラットフォームで確認できます。
