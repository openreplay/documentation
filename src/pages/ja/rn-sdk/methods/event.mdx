このメソッドを使用すると、「機能イベント」を報告できます。機能イベントを使用すると、機能的な観点で重要であり、デフォルトではトラッカーが自動的に検出してフラグを付けることができない、ユーザーのセッション内の瞬間を知らせることができます。機能イベントの例としては、ユーザーがショッピングカートに商品を追加する操作が挙げられます。トラッカーはその操作自体を記録できますが、セッションのタイムライン内の重要なイベントとしてフラグを付けるべきかどうかは判断できません。しかし、このメソッドを使用すれば、手動でフラグを付けることができます。

詳細については、[カスタムイベント](/product-analytics/data-management)を参照してください。

## シグネチャ

```js
import OR from '@openreplay/react-native'

OR.tracker.event("name", JSON.stringify({ key: "value" }))
```

## パラメーター

- `key: string`：情報が保存されるキーの名前です。このキーは、OpenReplay プラットフォーム内でのフィルタリングや検索に使用できます。
- `payload: string`：イベントの内容です。文字列としてエンコードされた（JSON）任意のデータを指定できます。
