このメソッドは、トラッカーを開始するために使用します。トラッカーを開始すると、セッションの録画が始まります。

## シグネチャ

```swift
import OR from '@openreplay/react-native'

OR.tracker.startSession(options)
```

## 初期化オプション

デフォルトでは、すべてのオプションが `true` に設定されています：
- `crashes: Bool` クラッシュレポート機能（crashlytics）を有効にします。
- `analytics: Bool` マークされたビューのアナリティクストラッキングを有効にします。
- `performances: Bool` パフォーマンスリスナーを有効にします。
- `logs: Bool` ログリスナーを有効にします。
- `screen: Bool` 画面レコーダーを有効にします。

オプションを使用して特定の機能を無効にできます。無効にしない場合は、空のオブジェクト（`{}`）を渡します。
