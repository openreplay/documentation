このメソッドを使用すると、OpenReplay プラットフォームで設定されているメタデータフィールドの 1 つの値を設定できます。

<Aside type="note">
	このメソッドは何度でも呼び出すことができますが、同じ `key` 属性を使用した場合、最後に渡した値がプラットフォームに保存され、以前の値はすべて失われることに注意してください。
</Aside>

詳細については、[メタデータ](/session-replay/metadata)を参照してください。

## シグネチャ
```js
import OR from '@openreplay/react-native'

// ...
OR.tracker.metadata('key', 'value')
```

## パラメーター

- `key: string`：保存するメタデータのキーです。
- `value: string`：メタデータとして保存する値です。

## 戻り値

このメソッドは値を返しません。情報はリプレイの一部として直接保存され、OpenReplay プラットフォーム内で確認できます。
