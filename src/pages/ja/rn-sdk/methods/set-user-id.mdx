このメソッドを使用すると、現在アクティブなセッションにユーザー ID を設定できます。これにより、ユーザーをリプレイに関連付けることができ、特定の 1 人のユーザーのセッションをフィルタリングして検索できるようになります。

## シグネチャ

```js
import OR from '@openreplay/react-native'

// ...
OR.tracker.setUserID('id')
```


## パラメーター

- `userID: String`：ユーザーの ID です。文字列であり、システム内でユーザーを一意に識別できるものであれば何でも構いません（メールアドレス、データベース ID など）。

## 戻り値

このメソッドは値を返しません。結果は OpenReplay プラットフォームで確認できます。
