OpenReplay の **Monitors** は、アプリケーションの安定性とパフォーマンスに影響する重大な問題を集中的に確認できるビューを提供します。事前設定済みのカードを使用して、JavaScript エラー、ネットワークリクエスト、その他の主要なメトリクスを監視し、問題を素早く特定して対処できます。

## モニターからわかること

**Monitors** を使うと、次のような疑問に答えることができます：

- どの JavaScript エラーがユーザー体験に影響を与えていますか？
- アプリケーションで最も頻繁に発生しているネットワークリクエストはどれですか？
- 繰り返し発生しているクライアントサイド（4xx）またはサーバーサイド（5xx）のネットワークリクエストはありますか？
- 最も大きな遅延を引き起こしているネットワークリクエストはどれですか？

## Monitors ダッシュボードのセットアップ

専用の Monitors ダッシュボードを作成すると、主要なメトリクスを 1 か所に集約でき、技術的な問題を把握しやすくなります。手順は次のとおりです：

#### 1. **ダッシュボードを作成する**：
    1. **Dashboards** メニューに移動します。
    2. **Add Dashboard** をクリックし、**Monitors** という名前を付けます。

#### 2. **カードを追加する**：
    1. **Monitors** カテゴリに移動します。
    2. 次の各カードをダッシュボードに追加します：
        - **Table of JS Errors**：ユーザー体験に影響する JavaScript エラーを監視し、エラーの種類、頻度、影響を受けるユーザーを素早く特定します。
        - **Top Network Requests**：最も頻繁に発生しているネットワークリクエストを表示し、トラフィックの多い API エンドポイントを特定します。
        - **Sessions with 4xx/5xx Requests**：クライアントサイド（4xx）とサーバーサイド（5xx）のエラーを追跡します。
        - **Sessions with Slow Network Requests**：遅延の原因となっているネットワークリクエストを特定し、遅い API や過負荷のサービスの修正を優先します。

## モニターのドリルダウンインサイト

Monitors ダッシュボードの各カードはインタラクティブで、問題をより詳細に調べることができます：

### **Table of JS Errors**：

1. エラーをクリックすると、その**スタックトレース**を確認できます。
2. **‘Find all sessions with this error’** ボタンを使用して、影響を受けたすべてのセッションを検索します。
3. **overview** で傾向を分析します。過去 24 時間と過去 30 日間の発生状況が表示されます。


### 4xx/5xx リクエストと低速なネットワークリクエストを含むセッション：

1. チャート上のポイントを選択して、関連するセッションリプレイを表示します。
2. セッションリプレイ内の **Network** タブを開き、所要時間やステータスなど、リクエストの詳細を分析します。
3. ドロップダウンを使用してチャートの時間範囲を調整し、特定の期間に焦点を当てます。


### **Top Network Requests**：

- アプリケーションで最も頻繁に発生しているリクエストを確認します。
- 特定のリクエストをクリックすると、そのリクエストを含むセッションがフィルターされ、さらに分析できます。

### **時間範囲の調整**

ダッシュボードのデフォルトの時間範囲は**過去 24 時間**ですが、ニーズに合わせて変更できます：

1. ダッシュボード上部の**時間範囲のドロップダウン**をクリックします。
2. プリセット範囲（例："Last 7 days"）を選択するか、カスタムの期間を設定します。

## **カードの別の作成方法**

お好みで、**Cards View** から直接カードを作成して追加することもできます：

1. Analytics モジュールの **Cards View** に移動します。
2. 任意のモニターメトリクス（例：JS エラーや遅いネットワークリクエスト）のカードを作成します。
3. **Add to Dashboard** オプションを使用して、そのカードを Monitors ダッシュボードに追加します。

## **Monitors を最大限に活用する**

**Monitors** を使うと、JavaScript エラー、ネットワークパフォーマンス、遅いリクエストなどの重大な問題を追跡して対処できます。インタラクティブな機能、セッションリプレイ、Network タブを活用して問題を深く掘り下げ、根本原因を突き止め、アプリケーションの安定性とパフォーマンスを向上させましょう。
