**OpenReplay MCP** アプリは、OpenReplay インスタンスを MCP 対応のチャットホスト（Claude Desktop、Claude Code、ChatGPT、Codex）に接続し、プロダクト分析やセッションリプレイを平易な言葉で探索できるようにします。チャートを依頼したり、ファネルを掘り下げたり、セッションを見つけてそのリプレイを開いたりといった操作を、すべてチャット内で行えます。

**OpenReplay Cloud** と **セルフホスト** のインスタンスの両方で動作します。

<Aside type="tip" title="できること" >
  - OpenReplay の UI で使用するものと同じフィルターでセッションを検索できます。
  - 時系列、ファネル、ユーザージャーニー、Web バイタル、トップ X の内訳をインラインで表示できます。
  - セッションリプレイをチャット内で直接視聴できます。
  - すべてを組み合わせることも可能です。検索 → セッションを選択 → リプレイを開く → Claude に要約を依頼。
</Aside>

## 互換性

このアプリは stdio 上で標準の MCP を使用するため、次のホストで動作します。

- **Claude Desktop**（macOS、Windows）
- **Claude Code**
- **ChatGPT**（MCP コネクター経由）
- **Codex**
- MCP をサポートするその他のホスト
