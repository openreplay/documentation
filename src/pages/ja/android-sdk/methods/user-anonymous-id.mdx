録画中のセッションに匿名の userID を関連付けます。

## シグネチャ
```kotlin
OpenReplay.userAnonymousID(userID: String)
```

## パラメーター

- `userID: String`: ユーザーの匿名 ID です。文字列であり、システム内でユーザーを一意に識別できるものであれば何でも使用できます（メールアドレス、データベース ID など）。

## 戻り値

このメソッドは値を返しません。結果は OpenReplay プラットフォームで確認できます。
