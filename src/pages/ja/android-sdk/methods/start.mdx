このメソッドは、トラッカーを開始するために使用します。トラッカーを開始すると、セッションの録画が始まります。

## シグネチャ

```kotlin
OpenReplay.start(applicationContext: Context, projectKey: String, options: OROptions)
	```

### 初期化オプション

使用可能なオプション：

- `crashes: Bool` Crashlytics を有効にします。
- `analytics: Bool` ビューのアナリティクスを有効にします。
- `performances: Bool` パフォーマンスリスナーを有効にします
- `logs: Bool` ログリスナーを有効にします
- `screen: Bool` スクリーンレコーダーを有効にします
- `wifiOnly: Bool` ユーザーが Wi-Fi に接続している場合にのみトラッカーを開始するようにします

デフォルト: すべて `true`
