このメソッドを使用すると、現在アクティブなセッションにユーザー ID を設定できます。これにより、リプレイにユーザーを関連付けて、特定のユーザーのセッションをフィルターおよび検索できるようになります。

## シグネチャ
```swift
OpenReplay.setUserID(userID: String)
```

## パラメーター

- `userID: String`: ユーザーの ID です。文字列であり、システム内でユーザーを一意に識別できるものであれば何でも使用できます（メールアドレス、データベース ID など）。

## 戻り値

このメソッドは値を返しません。結果は OpenReplay プラットフォームで確認できます。
