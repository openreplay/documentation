このメソッドを使用すると、「機能イベント（functional event）」を報告できます。機能イベントを使用すると、ユーザーのセッション内で機能的な観点から重要であり、デフォルトではトラッカーが自動的に検出してフラグを付けることができない瞬間を通知できます。機能イベントの例としては、ユーザーが商品をショッピングカートに追加することが挙げられます。トラッカーはその操作自体を記録できますが、セッションのタイムライン上で重要なイベントとしてフラグを付けるべきかどうかは判断できません。しかし、このメソッドを使用すれば、手動でフラグを付けることができます。

詳細については、[カスタムイベント](/product-analytics/data-management)を参照してください。

## シグネチャ

```kotlin
data class User(val name: String, val age: Int)

OpenReplay.event("Test Event", User("John", 25))
```

## パラメーター

- `key: string`: 情報が保存されるキーの名前です。このキーは、OpenReplay プラットフォーム内でのフィルタリングや検索に使用できます。
- `payload: Encodable`: イベントの内容です。エンコード可能な（JSON）データであれば何でも指定できます。
