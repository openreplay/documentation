このメソッドを使用すると、OpenReplay プラットフォームで設定したメタデータフィールドの値を設定できます。

<Aside type="note">
	このメソッドは何度でも呼び出せますが、同じ `key` 属性を使用した場合は、最後に渡した値のみがプラットフォームに保存される点にご注意ください。以前の値はすべて失われます。
</Aside>

詳細については、[メタデータ](/session-replay/metadata)を参照してください。

## シグネチャ
```kotlin
OpenReplay.setMetadata(key: String, value: String)
```

## パラメーター

- `key: string`: 保存するメタデータのキーです。
- `value: string`: メタデータとして保存する値です。

## 戻り値

このメソッドは値を返しません。情報はリプレイの一部として直接保存され、OpenReplay プラットフォーム内で確認できます。
