トラッカーは、ビューの表示／非表示イベントをリッスンします。

## トラッキング対象ビューの追加

### 

`.observeView(title:viewName:)` を使用して、入力イベントを監視します。

- `title: String` - 画面または機能のタイトル
- `viewName: String` - トラッカービューの名前

```kotlin

TextField("Input", text: $text)
 .observeView(title: "Screen title", viewName: "test input name")
```
