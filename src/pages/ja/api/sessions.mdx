## ユーザーセッションの取得

`tracker.setUserID` JavaScript 関数で識別された特定のユーザーのセッションの一覧を返します。結果はページネーションされます。

### メソッド
`POST`

### URL
`/public/:projectKey/users/:userId/sessions`

### パラメーター

| 名前       | 型     | 説明                                                     |
|------------|--------|----------------------------------------------------------|
| projectKey | string | プロジェクトキー（必須）                                 |
| userId     | string | `tracker.setUserID` で設定された ID（必須、最大 256）    |

### ペイロード

| 名前           | 型         | 説明                                                       |
|----------------|------------|------------------------------------------------------------|
| startTimestamp | epoch (ms) | 時間枠の開始（必須、最小値 946684800000）                  |
| endTimestamp   | epoch (ms) | 時間枠の終了（必須、startTimestamp より後の値）            |
| limit          | integer    | ページサイズ、1〜200（任意、デフォルト: 50）               |
| page           | integer    | ページ番号、1 から開始（任意、デフォルト: 1）              |
| sortOrder      | string     | `asc` または `desc`（任意）                                |

### リクエストヘッダー

`Authorization: Bearer {YOUR_ORGANIZATION_API_KEY}`

### ステータスコード

`200`: レスポンスは JSON としてボディで送信されます  
`400`: 無効なボディ、または無効な `userId`（空、または 256 文字を超える）

### リクエスト例

```shell
curl -X POST \
  {BASE_URL}/public/3sWXSsqHgSKnE87YkNJK/users/mickael@openreplay.com/sessions \
  -H 'content-type: application/json' \
  -H 'Authorization: Bearer {YOUR_ORGANIZATION_API_KEY}' \
  --data-raw '{
    "startTimestamp": 1623440000000,
    "endTimestamp":   1623540000000,
    "limit": 50,
    "page": 1,
    "sortOrder": "desc"
  }'
```

### レスポンス例

```json
{
  "data": {
    "total": 2,
    "sessions": [
      { "sessionId": "4813018042986240", "eventsCount": 1, "startTs": 1623440822825, "endTs": 1623440835604 },
      { "sessionId": "4813023023591169", "eventsCount": 6, "startTs": 1623440902620, "endTs": 1623440920846 }
    ]
  }
}
```
