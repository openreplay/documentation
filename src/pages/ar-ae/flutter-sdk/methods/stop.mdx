تُستخدم هذه الدالة لإيقاف المتعقّب (tracker). عند إيقاف المتعقّب، يتوقف تسجيل الجلسة.

## التوقيع

```dart
Future<void> OpenReplay.instance.stop()
```

الدالة `stop()` عملية تفكيك (teardown): فهي توقف كل مستمع، وتُفرغ المخازن المؤقتة ثم **تتخلّص** منها، وتمسح الجلسة.

<Aside type="note">
	لا تحتاج إلى استدعاء هذه الدالة عند انتقال التطبيق إلى الخلفية. إذ يراقب الـ SDK دورة حياة التطبيق بنفسه، فيوقف الالتقاط مؤقتًا ويُفرغ البيانات عند الانتقال إلى الخلفية ويستأنف عند العودة إلى الواجهة، مع الاحتفاظ بالمخازن المؤقتة.
</Aside>
