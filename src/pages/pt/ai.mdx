O OpenReplay apresenta **Experiências Nativas de IA** para o session replay, facilitando como nunca a análise de sessões, a detecção de problemas e a obtenção de insights sem esforço manual. A IA acelera a detecção de problemas, a análise do comportamento dos usuários e a geração de insights ao utilizar diferentes modelos para tarefas específicas.

<Aside type="ai" title="Nota" >
  - Disponível apenas para usuários do **Cloud (Serverless)** no momento.
  - No futuro, o Private Cloud Compute permitirá que usuários **Self-hosted** e **Cloud (Dedicated)** acessem este conjunto de recursos de IA.
</Aside>
