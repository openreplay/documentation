Este método é usado para parar o tracker. Ao parar o tracker, a gravação da sessão é interrompida.

## Assinatura

```dart
Future<void> OpenReplay.instance.stop()
```

`stop()` é um teardown: ele interrompe todos os listeners, faz o flush e **descarta** os buffers e limpa a sessão.

<Aside type="note">
	Você não precisa chamar este método quando o app vai para segundo plano. O próprio SDK observa o ciclo de vida do app, pausando a captura e fazendo o flush ao ir para segundo plano e retomando ao voltar para o primeiro plano, mantendo os buffers.
</Aside>
