Este método é usado para iniciar o tracker. Ao iniciar o tracker, a gravação da sessão começa.

## Assinatura

```swift
ORTracker.shared.start(projectKey: String, options: OROptions)
	```

### Opções de inicialização

Opções disponíveis:

- `crashes: Bool` Ativa o crashlytics.
- `analytics: Bool` Ativa o analytics para views.
- `performances: Bool` Ativa o listener de performance
- `logs: Bool` Ativa o listener de logs
- `screen: Bool` Ativa o gravador de tela
- `wifiOnly: Bool` Força o tracker a iniciar somente se o usuário tiver uma conexão Wi-Fi

Padrão: todas `true`
