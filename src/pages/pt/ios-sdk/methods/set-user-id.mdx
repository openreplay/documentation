Este método permite definir um ID de usuário na sessão atualmente ativa. Isso permite associar um usuário ao replay, o que possibilita filtrar e buscar sessões de um usuário específico.

## Assinatura
```swift
ORTracker.shared.setUserID(_ userID: String)
```

## Parâmetros

- `userID: String`: o ID do usuário. É uma string e pode ser qualquer valor, desde que seja uma string e permita identificar um usuário de forma única no seu sistema (por exemplo, e-mail, ID do banco de dados etc.).

## Valor de retorno

Este método não retorna nenhum valor; os resultados ficarão visíveis na plataforma OpenReplay.
