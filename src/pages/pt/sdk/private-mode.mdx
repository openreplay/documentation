## Modo privado

O **Modo privado** é uma nova configuração que bloqueia a gravação de todo o texto e de dados sensíveis. Quando ativado, o tracker do OpenReplay não captura nenhum texto visível, dados de rede nem logs do console. Tudo é ofuscado na origem—portanto, nada sensível sai do navegador.

Isso é útil se você quer ter visibilidade total do comportamento da interface, mantendo o conteúdo e os dados dos usuários completamente privados.

## Como ativar o Modo privado

Você pode ativar o Modo privado no nível do tracker ao inicializar o OpenReplay.

#### Usando NPM

```js
import { tracker } from '@openreplay/tracker'

tracker.configure({
    projectKey: PROJECT_KEY,
    privateMode: true
})
tracker.start();
```

Quando `privateMode` é definido como `true`, o seguinte será ofuscado:

- Todo o texto visível na página  
- Atributos `alt` em imagens  
- Valores de `placeholder` em campos de entrada  
- Textos de labels

Nenhuma configuração adicional é necessária. Depois de ativado, a sessão gravará o layout e a interação—mas nenhum conteúdo.


## Quando usar

Use `privateMode` se:

- Você precisa garantir a privacidade completa dos dados dos usuários
- Você está testando o OpenReplay em um **ambiente cloud**, mas planeja **fazer a auto-hospedagem dele** mais tarde, e **não pode enviar nenhum dado real para fora**
- Você trabalha em setores regulamentados, onde **a privacidade vem em primeiro lugar**
