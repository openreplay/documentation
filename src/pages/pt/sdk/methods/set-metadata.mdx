Com este método, você pode definir o valor de um dos campos de metadados configurados na plataforma OpenReplay.

<Aside type="note">
Você pode chamar este método quantas vezes quiser, mas lembre-se de que, se usar o mesmo atributo `key`, o último valor passado será salvo na plataforma. Todos os valores anteriores serão perdidos.
</Aside>

Consulte [metadados](/session-replay/metadata) para mais detalhes. 

## Assinatura
```js
setMetadata(key: string, value: string): void
```

## Parâmetros

- `key: string`: A chave de metadados a ser salva. 
- `value: string`: O valor a ser salvo como metadados.

## Valor de retorno

Este método não retorna nenhum valor. As informações são salvas diretamente como parte do replay e podem ser vistas dentro da plataforma OpenReplay.
