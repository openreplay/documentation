Este método permite rastrear canais de websocket individuais e a direção da mensagem (entrada/saída).

## Assinatura

```ts 
trackWs: (channelName: string) => (msgType: string, data: string, dir: 'up' | 'down') => void
```

## Parâmetros

- `channelName: string`: Nome do canal WS.

## Valor de retorno

Retorna um hook para aplicar às mensagens de ws, que recebe como parâmetros o tipo da mensagem (ou nome), os dados e a direção da mensagem (up/down === enviada/recebida).
