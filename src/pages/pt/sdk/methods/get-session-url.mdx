Este método permite obter a URL da sessão ativa. A URL aponta para o dashboard do OpenReplay, e o método é útil se você pretende integrar o OpenReplay à sua própria stack.

## Assinatura

```js
getSessionURL({ withCurrentTime?: boolean }): string | undefined
```

## Parâmetros

- `withCurrentTime: boolean`: Parâmetro opcional; por padrão, é `false`. Se for `true`, a URL conterá o timestamp do momento dentro do replay em que o método foi chamado.

## Valor de retorno

Este método retorna a URL da sessão ativa para ser reproduzida na plataforma do OpenReplay. Opcionalmente, a URL pode conter o timestamp do momento em que o método é chamado, para pular diretamente para esse ponto do replay.
