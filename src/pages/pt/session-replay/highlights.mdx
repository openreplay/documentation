Os **Highlights** oferecem uma maneira estruturada de isolar e salvar trechos relevantes de um session replay. Seja uma ocorrência de erro, uma interação do usuário ou um evento notável, os Highlights garantem que esses momentos fiquem facilmente acessíveis para revisão, colaboração ou relatórios futuros.

## Casos de uso

Ao revisar um session replay, use os **Highlights** para: 

1. Isolar e salvar o trecho em que um usuário encontrou um bug (ex.: uma chamada de API com falha, um erro no console…).
2. Identificar momentos em que o comportamento do usuário revela problemas de usabilidade ou pontos de atrito.
3. Fornecer contexto para embasar melhorias de design ou futuras iterações.

## Como funciona: crie e salve um highlight

**Passo 1:** Abra um session replay, localize o trecho principal e selecione o botão **'Highlights'** na barra de menu.

## Gerenciando Highlights

#### Acesse os Highlights salvos

Abra a aba **Highlights** para ver todos os itens salvos. Os Highlights podem ser filtrados por:

- Tags (Issue, Design, Note).
- Criador (My Highlights ou Team Highlights).
- Termos de busca (ex.: conteúdo da nota).

<div style={{ display: 'flex', justifyContent: 'center', alignItems: 'center' }}>
  <img src="/images/products/session-replay/highlights/highlight_view.png" alt="highlights" style={{ width: '700px', height: 'auto' }} />
</div>

#### Reproduza o replay a partir do trecho destacado

Reproduza a sessão a partir do trecho salvo. Use o botão **Navigate to Full Session** para revisar a sessão completa a partir do timestamp relevante.

</div>

<Aside type="tip">
    Os highlights salvos são marcados na _**linha do tempo**_ do session replay e ficam acessíveis na aba _**Activity**_.
</Aside>

## Colaboração e compartilhamento

- **Ajuste a visibilidade:**

    Defina se um highlight fica visível apenas para você (Private) ou para sua equipe (Team).
    
- **Compartilhe Highlights:**
    
    Use a opção **Copy Link** para compartilhar um highlight específico com colegas.
    
- **Edite ou exclua Highlights:**
    
    Modifique as notas ou remova o highlight se ele não for mais relevante.

## **Aproveite ao máximo os Highlights**

1. Concentre-se em salvar apenas os trechos mais relevantes dos session replays.
2. Use notas e tags para fornecer contexto e categorizar os highlights, facilitando a consulta rápida.
3. Compartilhe os highlights com sua equipe para resolver problemas rapidamente ou embasar melhorias de design.
