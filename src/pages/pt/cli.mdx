A partir da v1.10.0, lançamos nosso utilitário de CLI. Com ele, as tarefas mais comuns que você precisaria executar para gerenciar sua versão auto-hospedada do OpenReplay agora podem ser feitas com um simples comando.


## Instalando a CLI

A CLI vem com todas as versões auto-hospedadas do OpenReplay.

## Usando a CLI

A CLI tem a seguinte sintaxe:

```bash 
openreplay [command] <service>
```

A lista de comandos disponíveis é:

- `-h or --help`: Este comando exibirá a lista de comandos e serviços disponíveis.
- `-s or --status`: Se você quiser saber qual é o status dos serviços implantados, este comando dirá tudo o que você precisa saber.
- `-u or --upgrade`: Usado para atualizar sua instalação para a versão mais recente disponível.
- `-U or --deprecated-upgrade /path/to/old_vars.yaml`
- `-r or --restart`: Permite reiniciar todos os serviços. Com isso, você pode corrigir serviços que não estão respondendo.
- `-R or --Reload`: Recarrega a configuração de um serviço, portanto use-o somente quando você alterar algo.
- `-p or --install-packages`: Atualiza todas as dependências de terceiros (como `kubectl`, `helm` etc.).
- `-i or --install domain.name.com`: Instala o OpenReplay na máquina.
- `-e or --edit`: Edita a configuração instalada do OpenReplay e a recarrega.
- `-l or --logs SERVICE`: Mostra os logs de um serviço específico.

## Exemplo

Para obter o status da implantação, execute o comando de CLI abaixo:

```bash 
openreplay -s 
```
