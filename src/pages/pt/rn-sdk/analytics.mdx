O tracker escuta os eventos de aparecimento e desaparecimento de views na tela do celular.

## Adicionando views rastreadas

O SDK exporta o `ORAnalyticsView`, que você pode usar para marcar as views/componentes importantes.

```js
import OR from '@openreplay/react-native'

// ... your app UI

  <OR.ORAnalyticsView
    screenName="Pay confirmation page"
    viewName="New fancy button"
  >
    <ImportantRedButton />
  </OR.ORAnalyticsView>

// ...
```
