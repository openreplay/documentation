metaDescription: "Lista de navegadores compatíveis com o OpenReplay para gravação de sessões."
---

O OpenReplay é compatível com os seguintes navegadores:
- Google Chrome 41+
- Firefox 17+
- Microsoft Edge 12+
- Internet Explorer 11+
- Safari 9+
- Safari no iOS 9+
- Opera 28+
- Opera Mobile 62+

Se você estiver gravando uma sessão em um navegador não compatível, o SDK lançará uma exceção.
