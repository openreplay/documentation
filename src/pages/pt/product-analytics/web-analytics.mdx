O Web Analytics, no módulo Analytics do OpenReplay, ajuda você a acompanhar métricas de alto nível sobre o uso do seu site ou aplicação. Depois que o tracker estiver configurado e as sessões estiverem sendo capturadas, você pode monitorar dados como as páginas mais visitadas, a localização dos usuários e as fontes de tráfego para entender melhor os padrões gerais de uso.

## **O que você pode aprender com o Web Analytics?**

Com o Web Analytics, você pode responder perguntas como:

- Quais páginas são as mais visitadas?
- Quais navegadores e dispositivos são os mais usados?
- Onde estão localizados os seus usuários?
- Quais são as principais fontes de tráfego para o seu site?
- Quem são os seus usuários mais ativos?

Esses insights ajudam você a identificar padrões, otimizar o conteúdo e priorizar melhorias.

## Configurando seu dashboard de Web Analytics

1. **Criar um Dashboard**:
    - Navegue até o menu **Dashboards**.
    - Clique em **Add Dashboard** e dê a ele o nome **Web Analytics**.

## Aprofundando-se nos insights do Web Analytics

Vamos usar o card **Top Browsers** como exemplo:

1. Abra o card **Top Browsers** no seu dashboard.
2. Suponha que você perceba que uma porcentagem significativa dos usuários usa o Chrome. Clique em **Chrome** para filtrar as sessões especificamente desses usuários.
3. Use o componente **Omnisearch** para se aprofundar:
    - Aplique filtros, como eventos específicos (por exemplo, cliques) ou atributos da sessão, para refinar ainda mais a sua visão.
    - Por exemplo, encontre sessões de usuários do Chrome que encontraram um erro específico.

Ao focar em dados específicos de navegadores, você pode descobrir tendências ou solucionar problemas relacionados a navegadores com mais eficácia.

**Ajuste o intervalo de tempo**

Por padrão, os dashboards exibem dados dos últimos 7 dias. Para ajustar isso:

1. Clique no **menu suspenso de intervalo de tempo** (com o rótulo **'Last 7 days'**).
2. Escolha um intervalo predefinido (por exemplo, ontem) ou defina um período personalizado.

## **Criação alternativa de cards**

Você também pode criar cards diretamente na **Cards View**:

1. Navegue até **Cards View** no módulo Analytics.
2. Crie um novo card para qualquer métrica de Web Analytics.
3. Clique em **Add to Dashboard** e selecione o dashboard **Web Analytics**.

## Aproveite ao máximo o Web Analytics

O Web Analytics oferece acesso rápido a métricas de alto nível que ajudam você a acompanhar as tendências de uso da aplicação. Combine-o com ferramentas como session replays e filtros para descobrir insights mais profundos e tomar medidas.
