Depois de [configurar](/mcp/setup) o app MCP e fazer login, você pode pedir ao Claude (ou a outro host MCP) que consulte os seus dados do OpenReplay em linguagem natural. Esta página lista o que o MCP expõe atualmente, com exemplos de prompts para cada recurso.

<Aside type="tip" title="Dica" >
  Todos os prompts funcionam independentemente de você se referir ao seu projeto pelo **nome** (por exemplo, *"MyApp"*) ou pelo **ID do site** (por exemplo, *"site 1"*). Se você não especificar, o MCP usa o projeto mais recente que você mencionou.
</Aside>

## Pesquise e filtre sessões

O MCP oferece suporte aos mesmos filtros disponíveis na interface do OpenReplay: navegador, SO, dispositivo, país, caminhos de URL, cliques, inputs, requisições de rede, erros, metadados, IDs de usuário e duração.

```
Show me 20 recent sessions in MyApp
```

```
Sessions from Chrome users in France or Tunisia
```

```
Sessions with failed requests to /api/users in MyApp
```

```
Sessions where the user visited the signup page then clicked "Subscribe"
```

```
Sessions longer than 20 minutes for user tahay@asayer.io
```

O resultado é renderizado como uma lista interativa dentro do chat, para que você possa clicar em qualquer sessão.

## Funis

Os funis medem a conversão em uma série de URLs, cliques, inputs ou eventos personalizados. O abandono é mostrado etapa por etapa.

```
Show me the checkout funnel last week: /cart → /checkout → /confirm
```

```
Conversion from /pricing to /signup this month
```

```
Visited /pricing then clicked Subscribe
```

```
Page view /checkout followed by a JS exception
```

## Top of X

```

```

```

```

```
Most popular countries last 30 days
```

```

```

## Jornadas de usuários

Veja como os usuários navegam pelo seu produto: em quais páginas eles chegam, para onde vão em seguida e onde abandonam.

```
Show me user journeys this month
```

```
Where do users drop off after the pricing page last week?
```

```
What pages do users visit after /signup?
```

```
Navigation paths for mobile users from France this week
```

## Assista a um session replay

Os replays são renderizados em um player incorporado dentro do chat. Você pode navegar pela linha do tempo, pausar e inspecionar, exatamente como na interface do OpenReplay.

```
Show me the replay of session 7891234567890
```

```
Replay the last session in the list above
```

## Combine recursos

O verdadeiro valor vem de encadear as ferramentas. Alguns exemplos:

- *"Encontre sessões em que os usuários tiveram uma exceção de JS em /checkout esta semana, depois mostre o replay da mais recente e me diga o que aconteceu."*
- *"Puxe o funil de /pricing → /signup → /dashboard e, na etapa com o maior abandono, mostre 5 sessões que abandonaram ali."*
- *"Plote a série temporal de sessões da França neste mês. Se houver um pico, encontre algumas sessões desse dia e resuma o que elas fizeram."*

Como o Claude consegue raciocinar sobre os resultados entre as chamadas de ferramentas, você pode permanecer no nível da conversa em vez de alternar entre dashboards.
