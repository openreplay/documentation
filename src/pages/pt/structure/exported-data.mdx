O OpenReplay Enterprise Edition vem com diversos conectores para exportar os dados capturados (comportamento do usuário e problemas técnicos) para o seu data warehouse. Oferecemos suporte a:
- Amazon Redshift
- Google BigQuery
- PostgreSQL
- Snowflake
- ClickHouse
