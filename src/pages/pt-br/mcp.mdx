O app **OpenReplay MCP** conecta a sua instância do OpenReplay a um host de chat com suporte a MCP (Claude Desktop, Claude Code, ChatGPT, Codex) para que você explore o product analytics e os session replays em linguagem natural. Peça um gráfico, aprofunde-se em um funil, encontre uma sessão e abra o replay dela, tudo de dentro do chat.

Ele funciona tanto com o **OpenReplay Cloud** quanto com instâncias **auto-hospedadas**.

<Aside type="tip" title="O que você recebe" >
  - Pesquise sessões com os mesmos filtros que você usa na interface do OpenReplay.
  - Renderize séries temporais, funis, jornadas de usuários, web vitals e detalhamentos top-of-X diretamente no chat.
  - Assista a session replays diretamente no chat.
  - Encadeie tudo: pesquisar → escolher uma sessão → abrir o replay → pedir ao Claude que faça um resumo.
</Aside>

## Compatibilidade

O app fala MCP padrão via stdio, portanto funciona com:

- **Claude Desktop** (macOS, Windows)
- **Claude Code**
- **ChatGPT** (via conector MCP)
- **Codex**
- Qualquer outro host com suporte a MCP
