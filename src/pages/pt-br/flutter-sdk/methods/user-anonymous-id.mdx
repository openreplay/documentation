Associe um userID anônimo à sessão que está sendo gravada.

## Assinatura
```dart
OpenReplay.instance.userAnonymousID(String userId)
```

## Parâmetros

- `userId: String`: o ID anônimo do usuário. É uma string e pode ser qualquer valor, desde que seja uma string e permita identificar de forma única um usuário no seu sistema (por exemplo, e-mail, ID do banco de dados etc.).

## Valor de retorno

Este método não retorna nenhum valor; os resultados ficarão visíveis na plataforma OpenReplay.
