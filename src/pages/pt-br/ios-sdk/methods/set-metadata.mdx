Com este método, você pode definir o valor de um dos campos de metadados configurados na plataforma OpenReplay.

<Aside type="note">
	Você pode chamar este método quantas vezes quiser, mas lembre-se de que, se você usar o mesmo atributo `key`, o último valor que você informou será salvo na plataforma. Todos os valores anteriores serão perdidos.
</Aside>

Veja [metadados](/session-replay/metadata) para mais detalhes. 

## Assinatura
```swift
ORTracker.shared.setMetadata(key: String, value: String)
```

## Parâmetros

- `key: string`: a chave de metadados a ser salva. 
- `value: string`: o valor a ser salvo como metadados.

## Valor de retorno

Este método não retorna nenhum valor. A informação é salva diretamente como parte do replay e pode ser vista dentro da plataforma OpenReplay.
