Este método é usado para iniciar o tracker. Ao iniciar o tracker, a gravação da sessão começa.

## Assinatura

```kotlin
OpenReplay.start(applicationContext: Context, projectKey: String, options: OROptions)
	```

### Opções de inicialização

Opções disponíveis:

- `crashes: Bool` Habilita o crashlytics.
- `analytics: Bool` Habilita o analytics para views.
- `performances: Bool` Habilita o listener de desempenho
- `logs: Bool` Habilita o listener de logs
- `screen: Bool` Habilita o gravador de tela
- `wifiOnly: Bool` Força o tracker a iniciar somente se o usuário tiver uma conexão Wi-Fi

Padrão: todas como `true`
