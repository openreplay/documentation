Se os seus source maps são públicos, mas não podem ser carregados, verifique se o CORS está habilitado para eles adicionando o cabeçalho `Access-Control-Allow-Origin: '*'` para que o OpenReplay possa acessá-los.

Caso contrário, siga este guia para [fazer upload de source maps](/deployment/upload-sourcemaps).

## Tem dúvidas?

Se você tiver alguma dúvida sobre este processo, fale conosco no nosso [Slack](https://slack.openreplay.com) .
