O recurso Converter eventos da sessão em teste E2E permite transformar sessões de usuários gravadas em código de teste end-to-end automatizado. Essa capacidade poderosa aproxima o comportamento real dos usuários da automação de testes, permitindo replicar rapidamente jornadas de usuários no framework de testes de sua preferência.

## Como funciona: converta sessões em código de teste E2E

1. Acesse a visualização **Sessions** no dashboard
2. Selecione qualquer sessão gravada para abrir a visualização **Session Replay**
3. Clique na aba **Activity** para ver a linha do tempo de eventos
4. Procure o ícone **Copy Events** ao lado da barra de busca
5. Clique no ícone para abrir o menu suspenso com as opções de exportação

## Usando Converter eventos da sessão em teste E2E

### Uso básico

1. Clique no ícone **Copy Events** na visualização Activity
2. No menu suspenso, selecione o framework de testes desejado (Cypress, Playwright ou Puppeteer)
3. Escolha entre **Events Only** ou **Complete Test**
4. Use "Select events on the timeline" para selecionar quais eventos incluir
5. Clique em **Copy** para copiar o código gerado para a área de transferência
6. Cole diretamente no seu arquivo de teste

### Opções de exportação

#### Frameworks de teste

O recurso permite exportar para três frameworks de teste populares:

- **Cypress** - Framework de testes web focado na experiência do desenvolvedor e na confiabilidade
- **Playwright** - Biblioteca de testes moderna com suporte a vários navegadores
- **Puppeteer** - Biblioteca de automação de navegador headless

#### Tipos de exportação

Você pode escolher entre dois tipos de exportação:

- **Events Only** - Gera apenas os comandos de ação, sem nenhuma estrutura de teste
- **Complete Test** - Cria um teste totalmente estruturado, com o código boilerplate apropriado

#### Seleção de eventos

A ferramenta de seleção na linha do tempo permite:

- Selecionar um intervalo específico de eventos para incluir na exportação
- Arrastar as alças para ajustar os pontos inicial e final
