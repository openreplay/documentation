Associe o ID de usuário interno à sessão que está sendo gravada seguindo os passos abaixo.

### Com NPM

Injete o userID na inicialização do tracker:

```js
tracker.configure({
  projectKey: PROJECT_KEY
});

tracker.start({
  userID: "john@doe.com",
  metadata: {
    balance: "10M",
    plan: "free"
  }
});
```

Se isso não for possível (o userID só é conhecido mais adiante no fluxo de navegação, ou seja, bem depois de o tracker iniciar), chame o método `setUserID` para identificar seus usuários. A identidade do usuário pode ser alterada a qualquer momento durante a sessão chamando `setUserID`. No entanto, o OpenReplay manterá apenas o último ID de usuário injetado.

```js
tracker.setUserID('john@doe.com'); // after tracker.start()
```

### Com o snippet JavaScript

Abaixo está um exemplo de como injetar o userID usando o snippet. Observe a variável/linha `startOpts` usada para injetar o userID.

```js
<!-- OpenReplay Tracking Code -->
<script>
var initOpts = { projectKey: "GxPpaDARdn2345fgt321" };
var startOpts = { userID: getUserID() }; // use startOpts variable to inject userID
(function(A,s,a,y,e,r){
  r=window.OpenReplay=[e,r,y,[s-1, e]];
  s=document.createElement('script');s.src=A;s.async=!a;
  ...
})("//static.openreplay.com/latest/openreplay.js", 1, 0, initOpts, startOpts);
</script>
```

Se isso não for possível (o userID só é conhecido mais adiante no fluxo de navegação, ou seja, bem depois de o tracker iniciar), chame então o método `setUserID` para identificar seus usuários. A identidade do usuário pode ser alterada a qualquer momento durante a sessão chamando `setUserID`. No entanto, o OpenReplay manterá apenas o último ID de usuário injetado.

```js
<!-- OpenReplay Tracking Code -->
<script>
var initOpts = { projectKey: "GxPpaDARdn2345fgt321" };
var startOpts = { userID: "" };
(function(A,s,a,y,e,r){
  r=window.OpenReplay=[e,r,y,[s-1, e]];
  s=document.createElement('script');s.src=A;s.async=!a;
  ...
})("//static.openreplay.com/latest/openreplay.js", 1, 0, initOpts, startOpts);
</script>
  ...
  OpenReplay.setUserID("john@doe.com"); // set the userID later in your code
  ...
```

### Com app iOS

Basta chamar `setUserID(String)` em qualquer ponto durante o seu replay.

```swift
import ORTracker

// ... your code

ORTracker.shared.setUserID(_ userID: String)
```
