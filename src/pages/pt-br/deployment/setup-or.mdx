Começar a usar o OpenReplay é simples. 

Se você quiser assistir a um tutorial rápido sobre como começar, use [este vídeo do YouTube](https://www.youtube.com/watch?v=EWbtMK3qK30); caso contrário, continue lendo para ver mais detalhes.

Há duas maneiras de colocar o OpenReplay em funcionamento: usando o script ou o pacote npm.

## Usando o script

Copie e cole o trecho de código diretamente no `</head>` do seu aplicativo web. O script pode ser encontrado no dashboard do OpenReplay em 'Preferences > Projects' e é exclusivo de cada projeto.

Se o seu site oferece suporte ao Google Tag Manager, você pode seguir o [guia passo a passo do GTM](/integrations/google-tag-manager).

## Usando o NPM

Primeiro, instale o pacote npm.

```bash
npm i @openreplay/tracker
```

Em seguida, inicialize o pacote a partir do ponto de entrada do seu código e inicie o tracker. Você deve definir a opção `projectKey` no construtor. O valor dela pode ser encontrado no seu dashboard do OpenReplay em 'Preferences > Projects'.

### Se o seu site é uma Single Page Application (SPA)

Você pode usar o tracker como uma instância singleton, que é a forma recomendada de usá-lo. 
Dessa forma, você pode acessar o tracker de qualquer lugar do seu aplicativo:

```js
import { tracker } from '@openreplay/tracker'

tracker.configure({
	projectKey: PROJECT_KEY,
  ingestPoint: "https://openreplay.mydomain.com/ingest", // when dealing with the self-hosted version of OpenReplay
})

tracker.start() // returns a promise with session info (sessionID, sessionHash, userUUID)
```

Ou você pode usar a classe `Tracker` diretamente para gerenciar a instância manualmente:

```js
import OpenReplay from '@openreplay/tracker';
//...
const tracker = new OpenReplay({
  projectKey: PROJECT_KEY,
  ingestPoint: "https://openreplay.mydomain.com/ingest" // only required if using the self-hosted version of OpenReplay
});

tracker.start();
```

### Se o seu aplicativo web usa Server-Side Rendering (SSR)

Siga o trecho abaixo se o seu aplicativo web usa Server-Side Rendering (SSR) (por exemplo, NextJS, NuxtJS). 
Garanta que o tracker seja executado em um ambiente de navegador e que `tracker.start()` seja chamado depois que o aplicativo for entregue ao cliente (por exemplo, em `useEffect` ou `componentDidMount`).

```js
import OpenReplay from '@openreplay/tracker/cjs';
//...
const tracker = new OpenReplay({
      projectKey: PROJECT_KEY
});
//...
function MyApp() {
  useEffect(() => { // use componentDidMount in case of React Class Component
    tracker.start();
  }, []);
}
```

Se quiser ir além na configuração do tracker, consulte o [JavaScript SDK](/sdk/constructor#initialization-options) para ver a lista de opções disponíveis.
