Ao atualizar a sua instância do OpenReplay, é essencial garantir que o seu tracker (e o plugin tracker-assist, se você o utiliza) seja compatível com a versão do backend.

## Tabela de compatibilidade

Use a tabela a seguir para determinar quais versões do tracker e do Assist usar com o seu backend:

| Versão do tracker | Versão mínima do backend | Versão mínima do Assist |
|:--------------:|:---------------:|:-------------:|
| 19.x.x | 1.28.0 | 11.x.x |
| 18.x.x | 1.27.0 | 11.x.x |
| 17.2.x | 1.26.0 | 11.x.x |
| 17.2.x | 1.25.0 | 11.x.x |
| 17.1.x | 1.24.0 | 11.x.x |
| 17.x.x | 1.23.0 | 11.x.x |
| 16.x.x | 1.22.0 | 11.x.x |
| 15.x.x | 1.21.0 | 10.x.x |
| 14.x.x | 1.20.0 | 10.x.x |

## Changelog do tracker

Para ver a lista completa de atualizações e alterações feitas no tracker do OpenReplay, consulte o [Tracker Changelog no GitHub](https://github.com/openreplay/openreplay/blob/dev/tracker/tracker/CHANGELOG.md).

## Tem dúvidas?

Se você encontrar qualquer problema durante o processo de atualização, fale com a gente no [Slack](https://slack.openreplay.com) e peça ajuda à nossa comunidade.
