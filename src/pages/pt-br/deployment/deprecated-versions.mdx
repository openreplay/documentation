Se você deseja atualizar a sua instância do OpenReplay para a versão mais recente, verifique se está executando uma versão igual ou superior à `v1.4.0`. Caso contrário, você está em uma versão obsoleta e deve primeiro atualizar para a `v1.4.0` antes de poder passar para qualquer versão mais recente (v1.8.0+).

## Atualizar o Backend (da v1.3.6 ou anterior) para a v1.4.0

Primeiro, verifique se você está na `v1.3.6` ou em uma versão anterior. Se for o caso, ignore os comandos abaixo e passe para a etapa 1). Se não, atualize a sua instalação do OpenReplay para a `v1.3.6`:
   
```bash 
# Copy/backup the current openreplay folder to _version-number
mv openreplay openreplay_v1.3.5
git clone https://github.com/openreplay/openreplay -b v1.3.6
cd openreplay/scripts/helm
# bash upgrade.sh <old openreplay path>
bash upgrade.sh ~/openreplay_v1.3.5
```

Quando estiver na `v1.3.6`, siga as etapas abaixo:

1. Copie/faça backup da pasta atual do openreplay para `_version-number`, como abaixo:
   
  ```bash 
  mv openreplay openreplay_v1.3.6
  ```

2. Clone a nova versão do OpenReplay. Neste exemplo, estamos atualizando para a v1.4.0:
   
  ```bash 
  git clone https://github.com/openreplay/openreplay -b v1.4.0
  ```

3. Execute o script abaixo para atualizar automaticamente o seu `vars.yaml` para o novo formato:
  
  ```bash
  cd openreplay/scripts/helmcharts
  ansible localhost -m template -a "src=vars_template.yaml dest=vars.yaml" -e @~/openreplay_v1.3.6/scripts/helm/vars.yaml
  ```

4. Atualize o OpenReplay:

  ```bash
  cd openreplay/scripts/helmcharts
  helm ls -n app | tail -n +2 | awk '{print $1}' | xargs -I{} helm uninstall {} -n app
  helm uninstall nginx-ingress -n nginx-ingress
  helm upgrade --install openreplay ./openreplay -n app -f vars.yaml --atomic --set forceMigration=true
  ```
  
5. Se você não estiver usando um load balancer e tiver gerado o seu certificado SSL por meio do script `certmanager.sh`:

  ```
  cd /var/lib/openreplay/openreplay/scripts/helmcharts && bash certmanager.sh
  ```

6. Atualize a variável `fromVersion` em `/openreplay/scripts/helmcharts/vars.yaml` para refletir a nova versão. Por exemplo, se você estiver passando da `v1.3.6` para a `v1.4.0`, atualize `fromVersion` como abaixo:
  
  ```yaml
  fromVersion: "v1.4.0"
  ```

> **Nota:** 
As alterações manuais feitas em qualquer arquivo de configuração de serviço (por exemplo, `openreplay/scripts/helm/app/<app>.yaml`) serão redefinidas. Portanto, se você tiver alguma personalização, como o uso de um [serviço externo de armazenamento de objetos](/configuration/external-storage) para as suas gravações, ou maior capacidade dos serviços (cpu/memória), aplique-as à nova versão (em `/openreplay/scripts/helmcharts/vars.yaml`) antes de executar o script de atualização (etapa 4).
