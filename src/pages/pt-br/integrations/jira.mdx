Como integrar o Jira Cloud com o OpenReplay.

## 1. Crie um novo token de API

1. Faça login no seu [token do JIRA](https://id.atlassian.com/manage/api-tokens).
2. Clique em *Create API token*.
3. Em label, digite "openreplay" e clique em *Create*.
4. Clique em *Copy to clipboard*.

## 2. Ative o JIRA Cloud no OpenReplay

1. Acesse o dashboard do OpenReplay, em 'Preferences > Integration'
2. Selecione Jira. Se ele não aparecer, é porque você deve ter ativado o GitHub (não é possível usar os dois ao mesmo tempo, portanto desative a integração com o GitHub primeiro).
3. Informe o seu `Username` e o `API token` e digite a URL da sua instância do Jira Cloud

Um botão 'Create Issue' passará a aparecer em todas as gravações, para que você possa criar e atribuir issues no Jira rapidamente.

## Tem dúvidas?

Se você encontrar algum problema, conecte-se ao nosso [Slack](https://slack.openreplay.com) e peça ajuda à nossa comunidade.
