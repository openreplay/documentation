Integre o GitHub com o OpenReplay e crie issues diretamente da página da gravação.

## Usando o OpenReplay de código aberto 

#### 1. Crie um token de acesso pessoal

1. Faça login no GitHub e acesse [Settings > Developers Settings > Personal access tokens](https://github.com/settings/tokens)
2. Clique em 'Generate a new token'
3. Selecione os escopos `repo:status`, `repo_deployment`,`public_repo`, `read:user` e `user:email`
4. Clique em 'Generate token' e copie o token

#### 2. Ative o GitHub no OpenReplay

1. Acesse o dashboard do OpenReplay e vá para 'Preferences > Integration'
2. Selecione GitHub. Se ele não aparecer, é porque você deve ter ativado o Jira (não é possível usar os dois ao mesmo tempo, portanto desative a integração com o Jira primeiro).
3. Cole o `token` gerado anteriormente

Um botão 'Create Issue' passará a aparecer em todas as gravações, para que você possa criar e atribuir issues no GitHub rapidamente.

## Usando o OpenReplay Cloud

Vá para 'Preferences > Integration' e clique em GitHub. Você será redirecionado ao GitHub para autenticação. É só isso que você precisa fazer. Um botão 'Create Issue' passará a aparecer em todas as gravações, para que você possa criar e atribuir issues no GitHub rapidamente.
