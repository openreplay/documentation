Os Heatmaps oferecem uma representação visual das interações dos usuários no seu site ou aplicação, destacando áreas de alta atividade, como cliques e movimentos do mouse. Eles ajudam você a identificar o que chama a atenção dos usuários, quais botões ou conteúdos passam totalmente despercebidos e quais áreas causam atrito.

## **Casos de uso** de Heatmaps

Usar Heatmaps pode ajudar você a responder muitas perguntas, como:

- Com quais elementos os usuários mais interagem na sua landing page?
- Os principais CTAs estão sendo ignorados?
- Onde os usuários clicam na sua barra de navegação?
- Os usuários estão tendo click rage em botões ou elementos específicos?
- Quais seções da sua página prendem a atenção dos usuários e quais são ignoradas?

## Primeiros passos com Heatmaps

#### Criar um novo Heatmap

Você pode acessar Heatmaps no menu Cards, na categoria "Product Analytics". Selecione "Heatmaps" para começar a analisar as interações dos usuários.

#### Anatomia básica do card Heatmaps

1. **Barra de menu:** Altere o layout de exibição, renomeie, exclua ou adicione o card do heatmap a um dashboard.
2. **Especificação da URL:** Insira a URL da página que você deseja analisar. Se tiver dúvidas, o sistema oferece sugestões com base nas páginas mais populares do seu site.
3. **Filtros:** Aplique filtros, como atributos do usuário ou características da sessão, para restringir os dados.
4. **Área do heatmap:** Veja os destaques dos cliques do mouse e dos click rages. Use o botão “Get New Session” para atualizar a captura de tela.
5. **Intervalo de tempo:** Ajuste o período de análise para as últimas 24 horas, os últimos 7 dias ou um intervalo personalizado.
6. **Lista de sessões:** Veja as sessões para acessar replays detalhados.

## Configurando um Heatmap

#### Insira a URL da página do seu Heatmap

Use o campo de URL para especificar a página que você deseja analisar. As opções incluem:

- **URL contains:** Exibe dados de todas as URLs que incluem o texto inserido (diferencia maiúsculas de minúsculas).
- **URL starts With:** Exibe resultados de todas as URLs que começam com o texto inserido.
- **URL ends With:** Exibe resultados de todas as URLs que terminam com o texto inserido.

#### Filtre os dados do seu Heatmap

Os filtros ajudam você a refinar os dados para obter insights mais acionáveis. Os filtros disponíveis incluem:
    - Atributos do usuário (por exemplo, User ID, userAnanymousId ).
    - Características da sessão (por exemplo, país, cidade, OS, Browser UTM Source,...  ).
    - Issues (por exemplo, click rage, dead click, bad request,...  ).


## Aproveite ao máximo os Heatmaps

1. Foque em páginas de alto tráfego para obter os insights mais acionáveis.
2. Use filtros para segmentar os dados por atributos do usuário ou parâmetros da sessão.
3. Combine os insights dos heatmaps com session replays para descobrir o “porquê” por trás das ações dos usuários.
