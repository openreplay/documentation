O tracker escuta o evento de mudança de valor (com debounce) e envia o valor resultante para o backend do OpenReplay.

## Adicionando inputs rastreados

O SDK exporta o `ORTrackedInput`, que você pode usar como componentes TextInput comuns.

```js
import OR from '@openreplay/react-native'

// ... your app UI

  <OR.ORTrackedInput
    style={styles.input}
    onChangeText={onChangeNumber}
    value={number}
    placeholder="important placeholder"
  />

// ...
```
