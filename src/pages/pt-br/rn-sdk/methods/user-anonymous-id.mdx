Associa um userID anônimo à sessão que está sendo gravada.

## Assinatura

```swift
ORTracker.userAnonymousID(userID: String)
```

## Parâmetros

- `userID: String`: O ID anônimo do usuário. É uma string e pode ser qualquer valor, desde que seja uma string e permita identificar de forma única um usuário dentro do seu sistema (por exemplo, e-mail, ID do banco de dados etc.).

## Valor de retorno

Este método não retorna nenhum valor; os resultados ficarão visíveis na plataforma OpenReplay.
