## Componentes de UI

As views sanitizadas ficarão desfocadas no replay resultante. Você pode adicionar qualquer componente de UI, e ele será removido automaticamente (para preservar memória) assim que não estiver mais na tela.

### ORSanitizedView

O SDK exporta o `ORSanitizedView`, que você pode usar para envolver seus componentes sensíveis e desfocá-los.

```js
import OR from '@openreplay/react-native'

// ... your app UI

  <OR.ORSanitizedView>
    <SensitiveComponent />
  </OR.ORSanitizedView>

// ...
```
