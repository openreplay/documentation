Se você quer adicionar o tracker ao seu aplicativo web e usa um framework que não suportamos ou apenas
VanillaJS, você pode adicionar diretamente o nosso snippet JavaScript.

## Obtendo o snippet

O snippet JavaScript de que você precisa é fornecido quando você configura o projeto no portal do OpenReplay.
Depois de adicionar o seu novo projeto, você verá algo como isto:

![Novo projeto pronto](/using-or/snippet/new-project-ready.png)

Quando vir isso, clique no botão "Complete Project Setup". 
Isso levará você a uma página em que o snippet JS é apresentado:


![Obtendo o snippet JS](/using-or/snippet/getting-snippet.png)

Agora, basta clicar na aba "Script" e você verá o snippet JavaScript propriamente dito:

![O snippet está visível](/using-or/snippet/snippet-visible.png)

Pegue o script e adicione-o diretamente dentro da sua tag `<head>`, e o tracker começará a funcionar automaticamente.

<Aside type="tip">
Lembre-se de que, se você alterar qualquer opção de gravação de dados na etapa 1 da captura de tela acima, o snippet final mudará.
Portanto, configure primeiro as suas opções de gravação e só depois copie o snippet.
</Aside>
