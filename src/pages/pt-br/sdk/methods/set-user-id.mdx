Este método permite definir um ID de usuário na sessão ativa no momento. Isso permite associar um usuário ao replay, o que possibilita filtrar e pesquisar as sessões de um usuário em particular.

## Assinatura
```js
setUserID(id: string): void
```

## Parâmetros

- `id: string`: O ID do usuário. É uma string e pode ser qualquer coisa, desde que seja uma string e permita identificar de forma única um usuário no seu sistema (por exemplo, e-mail, ID do banco de dados etc.).

## Valor de retorno

Este método não retorna nenhum valor; os resultados ficarão visíveis na plataforma OpenReplay.
