Se as informações padrão rastreadas pelo nosso tracker quando ocorre um erro de JS não forem suficientes, você pode usar este método. O método `handleError` reporta manualmente exceções capturadas, promises rejeitadas ou eventos de erro. Consulte [relatório de erros](/session-replay/error-reporting#manually-logging-exceptions) para mais detalhes.

## Assinatura

```js 
handleError: (e: Error | ErrorEvent | PromiseRejectionEvent, metadata?: Record<string, any>) => void
```

## Parâmetros

- `e: Error | ErrorEvent | PromiseRejectionEvent`: O objeto de erro capturado.
- `metadata: Record<string, any>`: **[Opcional]** Uma estrutura do tipo dicionário com todas as informações extras que você quer salvar associadas a este erro.

## Valor de retorno

Este método não retorna nenhum valor; as informações salvas podem ser vistas dentro da plataforma OpenReplay.
