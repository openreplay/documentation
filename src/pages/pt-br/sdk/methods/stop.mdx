Este método interrompe o tracker e a sessão ativa. Se você não usar este método, a sessão será encerrada automaticamente alguns minutos depois que você fechar a aba ou sair do seu site.

## Assinatura

```js
stop(): string | undefined
```

## Valor de retorno

Retorna o `sessionHash` da sessão interrompida.
