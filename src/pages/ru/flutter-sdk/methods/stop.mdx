Этот метод используется для остановки трекера. При остановке трекера запись сессии прекращается.

## Сигнатура

```dart
Future<void> OpenReplay.instance.stop()
```

`stop()` выполняет полное завершение: он останавливает все слушатели, сбрасывает и **отбрасывает** буферы и очищает сессию.

<Aside type="note">
	Вызывать этот метод при переходе приложения в фон не нужно. SDK сам отслеживает жизненный цикл приложения: при переходе в фон он приостанавливает захват и сбрасывает данные, а при возврате на передний план возобновляет его, сохраняя буферы.
</Aside>
