Этот метод позволяет вам сообщать о «функциональном событии». С помощью функциональных событий вы можете отмечать моменты в сессии пользователя, которые важны с функциональной точки зрения и которые наш трекер по умолчанию не может распознать и отметить самостоятельно. Примером функционального события может служить добавление пользователем товара в корзину покупок. Хотя наш трекер сможет записать это действие, он не сможет отметить его как значимое событие на временной шкале вашей сессии. Однако благодаря этому методу вы можете сделать это вручную.

Подробнее см. в разделе [пользовательские события](/product-analytics/custom-events#функциональные-события).

## Сигнатура

```dart
OpenReplay.instance.event(String name, [Object? payload])
```

## Параметры

- `name: String`: Имя события. Это имя можно использовать для фильтрации и поиска внутри платформы OpenReplay.
- `payload: Object?`: Содержимое события. Значение типа `String` отправляется как есть; всё остальное кодируется в JSON, а если это невозможно, используется `toString()`. Не указывайте его, чтобы отправить пустую полезную нагрузку.

## Пример

```dart
OpenReplay.instance.event('checkout_started', {'cart': 3, 'currency': 'EUR'});
OpenReplay.instance.event('promo_banner_dismissed');
```
