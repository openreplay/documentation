Este método te permite reportar un "evento funcional". A través de los eventos funcionales puedes señalar momentos dentro de la sesión del usuario que son relevantes desde un punto de vista funcional y que, por defecto, nuestro tracker no puede captar ni marcar por sí solo. Un ejemplo de evento funcional sería que el usuario añada un artículo al carrito de compras. Aunque nuestro tracker podrá registrar la acción, no sabría marcarla como un evento relevante dentro de la línea de tiempo de tu sesión. Sin embargo, gracias a este método, puedes hacerlo manualmente.

Consulta [eventos personalizados](/product-analytics/custom-events#eventos-funcionales) para más detalles.

## Firma

```dart
OpenReplay.instance.event(String name, [Object? payload])
```

## Parámetros

- `name: String`: El nombre del evento. Este nombre puede utilizarse para filtrar y buscar dentro de la plataforma de OpenReplay.
- `payload: Object?`: El contenido del evento. Un `String` se envía tal cual; cualquier otro valor se codifica en JSON y, si no es codificable, se recurre a `toString()`. Omítelo para enviar un payload vacío.

## Ejemplo

```dart
OpenReplay.instance.event('checkout_started', {'cart': 3, 'currency': 'EUR'});
OpenReplay.instance.event('promo_banner_dismissed');
```
