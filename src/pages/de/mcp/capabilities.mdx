Sobald Sie die MCP-App [eingerichtet](/mcp/setup) und sich angemeldet haben, können Sie Claude (oder einen anderen MCP-Host) bitten, Ihre OpenReplay-Daten in natürlicher Sprache abzufragen. Diese Seite listet auf, was das MCP derzeit bereitstellt, jeweils mit Beispiel-Prompts.

<Aside type="tip" title="Tipp" >
  Alle Prompts funktionieren, unabhängig davon, ob Sie Ihr Projekt über den **Namen** (z. B. *"MyApp"*) oder über die **Site-ID** (z. B. *"site 1"*) angeben. Wenn Sie keine Angabe machen, verwendet das MCP das zuletzt von Ihnen genannte Projekt.
</Aside>

## Sitzungen durchsuchen und filtern

Das MCP unterstützt dieselben Filter wie die OpenReplay-Oberfläche: Browser, Betriebssystem, Gerät, Land, URL-Pfade, Klicks, Eingaben, Netzwerkanfragen, Fehler, Metadaten, Benutzer-IDs und Dauer.

```
Show me 20 recent sessions in MyApp
```

```
Sessions from Chrome users in France or Tunisia
```

```
Sessions with failed requests to /api/users in MyApp
```

```
Sessions where the user visited the signup page then clicked "Subscribe"
```

```
Sessions longer than 20 minutes for user tahay@asayer.io
```

Das Ergebnis wird als interaktive Liste im Chat dargestellt, sodass Sie jede Sitzung anklicken können.

## Funnels

Funnels messen die Conversion über eine Abfolge von URLs, Klicks, Eingaben oder benutzerdefinierten Ereignissen hinweg. Der Absprung wird Schritt für Schritt angezeigt.

```
Show me the checkout funnel last week: /cart → /checkout → /confirm
```

```
Conversion from /pricing to /signup this month
```

```
Visited /pricing then clicked Subscribe
```

```
Page view /checkout followed by a JS exception
```

## Ein Session Replay ansehen

Replays werden in einem eingebetteten Player im Chat dargestellt. Sie können wie in der OpenReplay-Oberfläche spulen, pausieren und untersuchen.

```
Show me the replay of session 7891234567890
```

```
Replay the last session in the list above
```

## Alles kombinieren

Der eigentliche Mehrwert entsteht, wenn Sie Tools miteinander verknüpfen. Einige Beispiele:

- *"Finden Sie Sitzungen, in denen Benutzer diese Woche auf /checkout eine JS-Exception ausgelöst haben, zeigen Sie mir dann das Replay der neuesten und sagen Sie mir, was passiert ist."*
- *"Ziehen Sie den Funnel für /pricing → /signup → /dashboard heran und zeigen Sie mir dann für den Schritt mit dem größten Absprung 5 Sitzungen, die dort abgesprungen sind."*
- *"Stellen Sie die Zeitreihe der Sitzungen aus Frankreich in diesem Monat dar. Wenn es einen Peak gibt, suchen Sie einige Sitzungen von diesem Tag heraus und fassen Sie zusammen, was die Benutzer getan haben."*

Da Claude zwischen den Tool-Aufrufen über die Ergebnisse nachdenken kann, bleiben Sie auf der Gesprächsebene, statt zwischen Dashboards hin- und herzuspringen.
