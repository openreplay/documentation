Erfahren Sie, wie Sie Backend-Fehler aus [Datadog](https://www.datadoghq.com/) mit Session Replays von [OpenReplay](https://www.openreplay.com/) verknüpfen, um Ihre Überwachungs- und Debugging-Möglichkeiten zu erweitern.

## 1. Datadog-API-Schlüssel und Application Key generieren

1. Gehen Sie zu **[Datadog > Integrations > APIs](https://app.datadoghq.com/account/settings#api)** und generieren Sie den API-Schlüssel oder verwenden Sie den vorhandenen.
2. Klicken Sie auf derselben Seite auf **Application Keys** und generieren Sie einen neuen Application Key.

## 2. Datadog-Integration in OpenReplay konfigurieren
Führen Sie in Ihrem OpenReplay-Konto diese 3 Schritte aus, um die Korrelation der Session Replays mit den Datadog-Backend-Fehlern abzuschließen.

#### Datadog-Integration aktivieren
1. Gehen Sie in OpenReplay zu **Preferences > Integrations**.
2. Wählen Sie den Tab **Backend Logging**.
3. Wählen Sie das Projekt aus, für das Sie die Datadog-Integration aktivieren möchten: Suchen Sie die Datadog-Integrationskarte > klicken Sie darauf.

#### Datadog-Zugangsdaten eingeben
Geben Sie in der Seitenleiste der Datadog-Integration Folgendes ein:

1. Datadog-API-Schlüssel
2. Application Key

#### Verbindung prüfen
1. Klicken Sie auf **Add**, um die Verbindung zu testen

## 3. openReplaySession.id weitergeben

Um ein Datadog-Ereignis mit der aufgezeichneten Benutzersitzung zu verknüpfen, muss bei jeder Anfrage, die Sie verfolgen möchten, eine eindeutige Sitzungs-ID `openReplaySession.id` von Ihrem Frontend an Ihr Backend weitergegeben werden. Dies ist mit einem benutzerdefinierten HTTP-Header möglich.

#### Frontend: openReplaySession.id in API-Anfragen einbinden

```javascript
// JavaScript Example for for Single Page Applications (SPA):
const sessionId = tracker.getSessionID(); 

const headers = {
  'Content-Type': 'application/json',
};

if (sessionId) {
  headers['openReplaySession.id'] = sessionId;
}

// Make the API request
fetch('https://www.your-backend.com/api/endpoint', {
  method: 'GET', // or 'POST', 'PUT', etc.
  headers,
  // ...other options
})
  .then(response => {
    // Handle response
  })
  .catch(error => {
    // Handle error
  });

```
#### Backend: openReplaySession.id in Logs einbinden

Nachfolgend ein Beispiel in Python, das mit dem logging-Modul die openReplaySession.id automatisch in Ihre Logs aufnimmt.

```python
import logging
from flask import Flask, request, g

app = Flask(__name__)

# Configure the root logger
logging.basicConfig(level=logging.INFO)
logger = logging.getLogger()

# Create a custom logging filter
class OpenReplayFilter(logging.Filter):
    def filter(self, record):
        session_id = getattr(g, 'openreplay_session_id', None)
        if session_id:
            record.msg = f"[openReplaySession.id={session_id}] {record.msg}"
        return True

# Add the filter to the logger
logger.addFilter(OpenReplayFilter())

@app.before_request
def before_request():
    # Extract the session ID from headers and store it in the Flask `g` object
    g.openreplay_session_id = request.headers.get('openReplaySession.id')

@app.route('/api/endpoint')
def api_endpoint():
    # Your logic here

    # Log an event with the session ID automatically included
    logger.info("Endpoint accessed")

    return 'Success', 200

@app.errorhandler(Exception)
def handle_exception(e):
    # Log the error with the session ID automatically included
    logger.error(f"Error: {str(e)}")
    return 'Internal Server Error', 500

if __name__ == '__main__':
    app.run()
```
