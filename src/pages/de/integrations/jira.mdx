So integrieren Sie Jira Cloud in OpenReplay.

## 1. Neues API-Token erstellen

1. Rufen Sie Ihre [JIRA-Token-Seite](https://id.atlassian.com/manage/api-tokens) auf und melden Sie sich an.
2. Klicken Sie auf *Create API token*.
3. Geben Sie unter „Label“ den Wert „openreplay“ ein und klicken Sie auf *Create*.
4. Klicken Sie auf *Copy to clipboard*.

## 2. JIRA Cloud in OpenReplay aktivieren

1. Öffnen Sie Ihr OpenReplay-Dashboard und gehen Sie zu 'Preferences > Integration'
2. Wählen Sie Jira aus. Wird es nicht angezeigt, haben Sie vermutlich GitHub aktiviert (beide Integrationen können nicht gleichzeitig verwendet werden – deaktivieren Sie daher zuerst die GitHub-Integration).
3. Tragen Sie Ihren `Username` und Ihr `API token` ein und geben Sie anschließend die URL Ihrer Jira-Cloud-Instanz ein

Anschließend erscheint in allen Aufzeichnungen die Schaltfläche 'Create Issue', mit der Sie schnell Issues in Jira erstellen und zuweisen können.
