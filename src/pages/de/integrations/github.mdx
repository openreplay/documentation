Integrieren Sie GitHub in OpenReplay und erstellen Sie Issues direkt auf der Seite der Aufzeichnung.

## Open-Source-Version von OpenReplay verwenden 

#### 1. Persönliches Zugriffstoken erstellen

1. Melden Sie sich bei GitHub an und gehen Sie zu [Settings > Developers Settings > Personal access tokens](https://github.com/settings/tokens)
2. Klicken Sie auf 'Generate a new token'
3. Wählen Sie die Scopes `repo:status`, `repo_deployment`,`public_repo`, `read:user` und `user:email` aus
4. Klicken Sie auf 'Generate token' und kopieren Sie das Token

#### 2. GitHub in OpenReplay aktivieren

1. Öffnen Sie das OpenReplay-Dashboard und gehen Sie zu 'Preferences > Integration'
2. Wählen Sie GitHub aus. Wird es nicht angezeigt, haben Sie vermutlich Jira aktiviert (beide Integrationen können nicht gleichzeitig verwendet werden – deaktivieren Sie daher zuerst die Jira-Integration).
3. Fügen Sie das zuvor generierte `token` ein

Anschließend erscheint in allen Aufzeichnungen die Schaltfläche 'Create Issue', mit der Sie schnell Issues in GitHub erstellen und zuweisen können.

## OpenReplay Cloud verwenden

Gehen Sie zu 'Preferences > Integration' und klicken Sie auf GitHub. Sie werden zur Authentifizierung zu GitHub weitergeleitet. Mehr müssen Sie nicht tun. Anschließend erscheint in allen Aufzeichnungen die Schaltfläche 'Create Issue', mit der Sie schnell Issues in GitHub erstellen und zuweisen können.
