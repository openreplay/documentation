Kopieren Sie den Tracker-Code aus dem OpenReplay-Dashboard unter 'Preferences > Projects' und fügen Sie ihn ein. Der Code ist für jedes Projekt eindeutig.

![Tracking-Code](/static/GTM-5.JPG#center)

Rufen Sie anschließend Ihr Google-Tag-Manager-Konto auf und führen Sie die folgenden Schritte aus:

1. Klicken Sie auf *Add a new tag*

![Neuen Tag hinzufügen](/static/GTM-3.png#center)

2. Wählen Sie *Choose a tag type*, um die Einrichtung zu beginnen
3. Wählen Sie in der Liste *Custom HTML* aus und fügen Sie das kopierte Snippet in das Textfeld ein

![Custom HTML](/static/GTM-4.JPG#center)

4. Klicken Sie auf *Choose a trigger*, um Aktionen festzulegen, und wählen Sie **All Pages**

![Alle Seiten](/static/GTM-7.JPG#center)

5. Geben Sie dem Tag einen Namen und klicken Sie dann auf *Save*
6. Klicken Sie auf *Submit*, um Ihre Änderungen zu übermitteln

![Übermitteln](/static/submit.JPG#center)

7. Stellen Sie sicher, dass Ihre Live-Umgebung ausgewählt ist, und klicken Sie dann auf *Publish*

![Veröffentlichen](/static/GTM-10.png#center)
