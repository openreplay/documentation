Mit diesem Plugin können Sie `VueX`-Mutationen und -Zustände erfassen und später beim Abspielen von Sitzungsaufzeichnungen untersuchen. Das ist sehr hilfreich, um Probleme zu verstehen und zu beheben.

<Aside type="tip">
  Wir bieten außerdem ein ausführliches Tutorial dazu an, wie Sie mit dem VueX-Plugin den Zustand Ihrer Anwendung erfassen, wenn Sie diese Bibliothek verwenden. Sie finden es [hier](/tutorials/vuex).
</Aside>



## Installation

```bash
npm i @openreplay/tracker-vuex
```

## Verwendung

Initialisieren Sie das Paket `@openreplay/tracker` wie gewohnt und laden Sie das Plugin hinein. Tragen Sie anschließend das generierte Plugin in das Feld `plugins` Ihres Stores ein.

### Wenn Ihre Website eine Single Page Application (SPA) ist

```js
import Vuex from 'vuex'
import trackerVuex from '@openreplay/tracker-vuex';
import { tracker } from '@openreplay/tracker';

tracker.configure({
  projectKey: 'YOUR_PROJECT_KEY',
  ingestPoint: "https://openreplay.mydomain.com/ingest", // when dealing with the self-hosted version of OpenReplay
});
```

### Wenn Ihre Web-App serverseitig gerendert wird (SSR)

Orientieren Sie sich am folgenden Beispiel, wenn Ihre App SSR verwendet. 
Stellen Sie sicher, dass der Tracker in der Browserumgebung ausgeführt wird.
Wenn bei SSR Fehler auftreten, lesen Sie den Abschnitt [Fehlerbehebung](troubleshooting/js-errors).

```js
import Vuex from 'vuex'
import OpenReplay from '@openreplay/tracker/cjs';
import trackerVuex from '@openreplay/tracker-vuex/cjs';
//...
const tracker = new OpenReplay({
  projectKey: PROJECT_KEY,
  ingestPoint: "https://openreplay.mydomain.com/ingest", // when dealing with the self-hosted version of OpenReplay
  // ... options
});
```

#### Mit tracker-vuex ab Version 4.0.0

```js
// check list of available options below
const vuexPlugin = tracker.use(trackerVuex(<options>)); 

// add a name to your store, optional (will be randomly generated otherwise)
const storeTracker = vuexPlugin('STORE NAME') 

const store = createStore({
  state,
  mutations,
  plugins: [storeTracker]
})
```

#### Mit tracker-vuex vor Version 3.0.0

```js
// check list of available options below
const vuexPlugin = tracker.use(trackerVuex(<options>));  

tracker.start();

const store = new Vuex.Store({
  //...
  plugins: [vuexPlugin],
});
```

## Optionen

Mit Optionen können Sie das Verhalten des Plugins anpassen, um Ihre Daten zu bereinigen. Sie ähneln denen des Standard-Plugins `createLogger`.

```js
trackerVuex({
  filter (mutation, state) {
    // returns `true` if a mutation should be logged
    // `mutation` is a `{ type, payload }`
    return mutation.type !== "aBlacklistedMutation";
  },
  transformer (state) {
    // transforms the state before logging it.
    // for example return only a specific sub-tree
    return state.subTree;
  },
  mutationTransformer (mutation) {
    // mutations are logged in the format of `{ type, payload }`
    // we can format it any way we want.
    return mutation.type;
  },
})
```
