Mit dieser Methode legen Sie eine Benutzer-ID für die aktuell aktive Sitzung fest. So ordnen Sie dem Replay einen Benutzer zu und können Sitzungen gezielt nach einem bestimmten Benutzer filtern und durchsuchen.

## Signatur
```dart
OpenReplay.instance.setUserID(String userId)
```

## Parameter

- `userId: String`: Die ID des Benutzers. Dies ist ein String und kann beliebig sein, solange es ein String ist und Sie damit einen Benutzer in Ihrem System eindeutig identifizieren können (z. B. E-Mail-Adresse, Datenbank-ID usw.).

## Rückgabewert

Diese Methode gibt keine Werte zurück; die Ergebnisse sind in der OpenReplay-Plattform sichtbar.
