Ordnet der aufgezeichneten Sitzung eine anonyme Benutzer-ID zu.

## Signatur
```dart
OpenReplay.instance.userAnonymousID(String userId)
```

## Parameter

- `userId: String`: Die anonyme ID des Benutzers. Dies ist ein String und kann beliebig sein, solange es ein String ist und Sie damit einen Benutzer in Ihrem System eindeutig identifizieren können (z. B. E-Mail-Adresse, Datenbank-ID usw.).

## Rückgabewert

Diese Methode gibt keine Werte zurück; die Ergebnisse sind in der OpenReplay-Plattform sichtbar.
