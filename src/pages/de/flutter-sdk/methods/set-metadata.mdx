Mit dieser Methode legen Sie den Wert eines der Metadatenfelder fest, die auf der OpenReplay-Plattform konfiguriert sind.

<Aside type="note">
	Sie können diese Methode beliebig oft aufrufen. Beachten Sie jedoch: Wenn Sie dasselbe `key`-Attribut verwenden, wird der zuletzt übergebene Wert in der Plattform gespeichert. Alle vorherigen Werte gehen verloren.
</Aside>

Weitere Details finden Sie unter [Metadaten](/session-replay/metadata).

## Signatur
```dart
OpenReplay.instance.setMetadata(String key, String value)
```

## Parameter

- `key: String`: Der Metadatenschlüssel, der gespeichert werden soll.
- `value: String`: Der Wert, der als Metadatum gespeichert werden soll.

## Rückgabewert

Diese Methode gibt keine Werte zurück. Die Informationen werden direkt als Teil des Replays gespeichert und sind in der OpenReplay-Plattform einsehbar.
