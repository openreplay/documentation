Mit dieser Methode melden Sie ein „funktionales Ereignis“. Über funktionale Ereignisse können Sie Momente in der Sitzung des Benutzers markieren, die aus funktionaler Sicht relevant sind und die unser Tracker standardmäßig nicht von sich aus erkennen und kennzeichnen kann. Ein Beispiel für ein funktionales Ereignis wäre, dass der Benutzer einen Artikel in den Warenkorb legt. Unser Tracker kann die Aktion zwar aufzeichnen, weiß aber nicht, dass er sie als relevantes Ereignis in der Zeitleiste Ihrer Sitzung kennzeichnen soll. Mit dieser Methode können Sie das jedoch manuell tun.

Weitere Details finden Sie unter [benutzerdefinierte Events](/product-analytics/data-management).

## Signatur

```dart
OpenReplay.instance.event(String name, [Object? payload])
```

## Parameter

- `name: String`: Der Name des Ereignisses. Dieser Name kann innerhalb der OpenReplay-Plattform zum Filtern und Suchen verwendet werden.
- `payload: Object?`: Der Inhalt des Ereignisses. Ein `String` wird unverändert gesendet; alles andere wird als JSON kodiert, mit Rückfall auf `toString()`, falls es sich nicht kodieren lässt. Lassen Sie den Parameter weg, um eine leere Payload zu senden.

## Beispiel

```dart
OpenReplay.instance.event('checkout_started', {'cart': 3, 'currency': 'EUR'});
OpenReplay.instance.event('promo_banner_dismissed');
```
