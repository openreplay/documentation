Bringen Sie mit unserer Co-Browsing-Funktion in OpenReplay die Schnelligkeit und Direktheit von persönlichem Support und Onboarding auf Ihre digitale Plattform.


<Aside type="tip" title="Wer kann diese Funktion nutzen?">
    - Verfügbar in <a href="https://openreplay.com/pricing/#dedicated" class="text-blue-700 underline"><strong>allen Tarifen</strong></a>.
    - Kann entsprechend der <a href="https://docs.openreplay.com/en/deployment/roles-and-access/" class="text-blue-700 underline">definierten Rollen und Zugriffe</a> angepasst werden (Enterprise Edition)
</Aside>

<Aside type="caution" title="So aktivieren Sie Co-Browsing">
  Um die Funktion Cobrowse zu nutzen, fügen Sie Ihrem Setup das [**Assist plugin**](https://docs.openreplay.com/en/plugins/assist/) hinzu. Anschließend können Sie Co-Browsing mit jedem aktiven Benutzer starten, was eine schnellere Lösung von Support-Anfragen und ein reibungsloseres Onboarding ermöglicht.
</Aside>


## An einer aktiven Sitzung teilnehmen

Sie können ganz einfach bestimmte Online-Benutzer finden, die auf Ihrer Website möglicherweise Unterstützung benötigen.

1. Wechseln Sie zur Ansicht Cobrowse.
2. Sortieren Sie Live-Sitzungen und wenden Sie vordefinierte Metadaten an, um Benutzer zu finden.
3. Klicken Sie auf die Wiedergabe-Schaltfläche, um die Aktivität eines Online-Benutzers in Ihrer App zu überwachen.

##  Konsolenaktivitäten überwachen

Sie können die Konsolenaktivitäten von Benutzern in Echtzeit überwachen und auftretende Fehler, Warnungen oder Informationen erkennen.

1. Spielen Sie eine Online-Benutzersitzung ab.
2. Klicken Sie unten auf die Konsole.

  <img src="/images/products/cobrowse/cobrowse_console.png" alt="cobrowse_console" style={{ width: '600px', height: 'auto' }} />
</div>


##  Benutzer per Videoanruf kontaktieren

Starten Sie einen Videoanruf, um Kunden zu unterstützen oder einzuarbeiten, während sie in Ihrer Anwendung navigieren.

1. Spielen Sie eine Online-Benutzersitzung ab
2. Klicken Sie auf die Anruf-Schaltfläche und bestätigen Sie, dass Sie den Benutzer anrufen möchten.

<div style={{ display: 'flex', justifyContent: 'center', alignItems: 'center' }}>
  <img src="/images/products/cobrowse/cobrowse_video_call.png" alt="cobrowse_video_call" style={{ width: '600px', height: 'auto' }} />
</div>

<Aside type="tip" >
   Sie können jederzeit Ihre Kamera ausgeschaltet lassen und nur einen Audioanruf führen.
</Aside>

##  Aktivität aufzeichnen

Wenn Sie bestimmte Benutzeraktivitäten für eine spätere Überprüfung oder für das Onboarding aufzeichnen möchten, können Live-Sitzungen im Videoformat erfasst werden.

1. Spielen Sie eine Online-Benutzersitzung ab
2. Klicken Sie auf die Anruf-Schaltfläche und bestätigen Sie, dass Sie den Benutzer anrufen möchten.

##  Fernsteuerung

Um Ihren Kunden optimal zu unterstützen oder einzuarbeiten, können Sie ihn per Fernsteuerung direkt zu seinem Ziel führen.

1. Spielen Sie eine Online-Benutzersitzung ab
2. Klicken Sie auf die Fernsteuerung und warten Sie, bis der Benutzer dem Fernzugriff zustimmt.
3. Sobald der Benutzer der Fernsteuerung zugestimmt hat, können Sie Anmerkungen verwenden, um Elemente hervorzuheben oder direkt auf dem Bildschirm des Benutzers zu zeichnen.

##  Mehrere Live-Sitzungen

1. Spielen Sie eine Online-Benutzersitzung ab
2. Klicken Sie unten auf die Schaltfläche '+', um bis zu vier Live-Sitzungen zu überwachen.
