Wenn Sie Ihre OpenReplay-Instanz auf die neueste Version aktualisieren möchten, stellen Sie sicher, dass Sie eine Version ab `v1.4.0` (einschließlich) verwenden. Andernfalls nutzen Sie eine veraltete Version und müssen zuerst auf `v1.4.0` aktualisieren, bevor Sie auf eine neuere Version (v1.8.0+) wechseln können.

## Backend (von v1.3.6 oder früher) auf v1.4.0 aktualisieren

Stellen Sie zunächst sicher, dass Sie `v1.3.6` oder eine frühere Version verwenden. Ist das bereits der Fall, überspringen Sie die folgenden Befehle und fahren Sie mit Schritt 1) fort. Falls nicht, aktualisieren Sie Ihre OpenReplay-Installation auf `v1.3.6`:
   
```bash 
# Copy/backup the current openreplay folder to _version-number
mv openreplay openreplay_v1.3.5
git clone https://github.com/openreplay/openreplay -b v1.3.6
cd openreplay/scripts/helm
# bash upgrade.sh <old openreplay path>
bash upgrade.sh ~/openreplay_v1.3.5
```

Sobald Sie `v1.3.6` verwenden, fahren Sie mit den folgenden Schritten fort:

1. Kopieren bzw. sichern Sie den aktuellen openreplay-Ordner unter `_version-number`, wie unten gezeigt:
   
  ```bash 
  mv openreplay openreplay_v1.3.6
  ```

2. Klonen Sie die neue OpenReplay-Version. In diesem Beispiel aktualisieren wir auf v1.4.0:
   
  ```bash 
  git clone https://github.com/openreplay/openreplay -b v1.4.0
  ```

3. Führen Sie das folgende Skript aus, um Ihre `vars.yaml` automatisch in das neue Format zu überführen:
  
  ```bash
  cd openreplay/scripts/helmcharts
  ansible localhost -m template -a "src=vars_template.yaml dest=vars.yaml" -e @~/openreplay_v1.3.6/scripts/helm/vars.yaml
  ```

4. Aktualisieren Sie OpenReplay:

  ```bash
  cd openreplay/scripts/helmcharts
  helm ls -n app | tail -n +2 | awk '{print $1}' | xargs -I{} helm uninstall {} -n app
  helm uninstall nginx-ingress -n nginx-ingress
  helm upgrade --install openreplay ./openreplay -n app -f vars.yaml --atomic --set forceMigration=true
  ```
  
5. Wenn Sie keinen Load Balancer verwenden und Ihr SSL-Zertifikat über das Skript `certmanager.sh` erzeugt haben:

  ```
  cd /var/lib/openreplay/openreplay/scripts/helmcharts && bash certmanager.sh
  ```

6. Aktualisieren Sie die Variable `fromVersion` in `/openreplay/scripts/helmcharts/vars.yaml`, sodass sie die neue Version widerspiegelt. Wenn Sie beispielsweise von `v1.3.6` auf `v1.4.0` wechseln, setzen Sie `fromVersion` wie folgt:
  
  ```yaml
  fromVersion: "v1.4.0"
  ```

> **Hinweis:** 
Manuelle Überschreibungen in einer Konfigurationsdatei eines Dienstes (z. B. `openreplay/scripts/helm/app/<app>.yaml`) werden zurückgesetzt. Wenn Sie eigene Anpassungen haben, etwa die Verwendung eines [externen Object-Storage-Dienstes](/configuration/external-storage) für Ihre Aufzeichnungen oder eine höhere Dienstkapazität (CPU/Arbeitsspeicher), übernehmen Sie diese deshalb in die neue Version (in `/openreplay/scripts/helmcharts/vars.yaml`), bevor Sie das Upgrade-Skript ausführen (Schritt 4).

Wenn bei den oben beschriebenen Schritten Probleme auftreten, wenden Sie sich an [Slack](https://slack.openreplay.com) und holen Sie sich Hilfe von unserer Community.
