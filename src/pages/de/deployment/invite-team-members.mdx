Mit OpenReplay können Sie Teammitglieder bei Bedarf einladen oder entfernen. Dieser Artikel beschreibt die Schritte zur Verwaltung Ihrer Teammitglieder.

## Teammitglieder einladen

So laden Sie Teammitglieder ein:

1. Öffnen Sie im OpenReplay-Dashboard **Preferences > Team**.
2. Klicken Sie auf die Schaltfläche **Add Team Member**.
3. Geben Sie die Daten des Benutzers ein:
   - **Full Name**
   - **Email Address**
4. (Optional) Aktivieren Sie Admin Privileges, wenn der Benutzer Zugriff auf die Team- und Projektverwaltung benötigt.
5. (Nur Enterprise Edition) Weisen Sie eine Rolle zu, um seinen Zugriff auf Projekte und Funktionen festzulegen.
6. Klicken Sie auf **Invite**.

<div class="or-aside note">

1. **Für Benutzer selbst gehosteter Instanzen**: Die erste Registrierung ist während der Einrichtung auf einen Benutzer beschränkt. Weitere Benutzer müssen eingeladen werden. E-Mail-Einladungen setzen eine SMTP-Konfiguration voraus – ohne sie geben Sie die Einladungslinks manuell weiter. Siehe unsere [SMTP-Anleitung](/configuration/configure-smtp).

2. **Für Cloud-Benutzer (Serverless oder Dedicated)**: Der Ersteller des Kontos hat die Rolle **Owner** mit Admin-Rechten. Neue Mitglieder treten als normale Members bei, können aber **Admin Privileges** erhalten. Alle eingeladenen Teammitglieder erhalten beim Hinzufügen automatisch E-Mail-Einladungen

</div>

## Teammitglieder entfernen

So entfernen Sie ein Teammitglied:

1. Öffnen Sie im OpenReplay-Dashboard **Preferences > Team**.
2. Suchen Sie den Benutzer in der Teamliste.
3. Klicken Sie neben seinem Namen auf das Symbol **Edit**.
4. Klicken Sie auf das Symbol **Delete**.
