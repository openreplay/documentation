Mit Rollen und Zugriff können Administratoren spezifische Berechtigungen für Projekte und Funktionen festlegen. 

> **Hinweis:** Diese Funktion ist nur in der **[Enterprise Edition](https://openreplay.com/enterprise.html)** verfügbar.

### Rolle hinzufügen

1. Öffnen Sie im OpenReplay-Dashboard **Preferences > Roles and Access**
2. Klicken Sie auf die Schaltfläche **Add**
3. Definieren Sie die Rolle:
   - **Title**: Name der Rolle (z. B. Developer)
   - **Project Access**: Wählen Sie die zugänglichen Projekte aus
   - **Feature Access**: Wählen Sie die verfügbaren Funktionen aus
4. Klicken Sie auf **Add**

### Rolle bearbeiten
1. Öffnen Sie **Preferences > Roles and Access**
2. Suchen Sie die Rolle, die Sie bearbeiten möchten
3. Klicken Sie auf das Symbol **Edit**
4. Aktualisieren Sie die Zugriffseinstellungen
5. Klicken Sie auf **Update**

> **Hinweis:** Die Rolle **Owner** kann nicht geändert werden.

### Rolle löschen
1. Öffnen Sie **Preferences > Roles and Access**
2. Suchen Sie die Rolle, die Sie bearbeiten möchten
3. Klicken Sie auf das Symbol **Edit**
4. Klicken Sie auf das Symbol **Delete**
5. Klicken Sie auf **Proceed**, um das Löschen zu bestätigen
