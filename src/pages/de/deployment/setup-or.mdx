Der Einstieg in OpenReplay ist unkompliziert. 

Wenn Sie sich ein kurzes Tutorial zum Einstieg ansehen möchten, nutzen Sie [dieses YouTube-Video](https://www.youtube.com/watch?v=EWbtMK3qK30). Andernfalls lesen Sie einfach weiter, um mehr Details zu erfahren.

Es gibt zwei Möglichkeiten, OpenReplay in Betrieb zu nehmen: über das Skript oder über das npm-Paket.

## Das Skript verwenden

Kopieren Sie das Code-Snippet direkt in das `</head>` Ihrer Web-App. Das Skript finden Sie im OpenReplay-Dashboard unter 'Preferences > Projects'; es ist für jedes Projekt individuell.

Wenn Ihre Website Google Tag Manager unterstützt, können Sie der [GTM-Schritt-für-Schritt-Anleitung](/integrations/google-tag-manager) folgen.

## NPM verwenden

Installieren Sie zunächst das npm-Paket.

```bash
npm i @openreplay/tracker
```

Initialisieren Sie das Paket anschließend im Einstiegspunkt Ihrer Codebasis und starten Sie den Tracker. Sie müssen die Option `projectKey` im Konstruktor setzen. Ihren Wert finden Sie in Ihrem OpenReplay-Dashboard unter 'Preferences > Projects'.

### Wenn Ihre Website eine Single Page Application (SPA) ist

Sie können den Tracker als Singleton-Instanz verwenden, was die empfohlene Vorgehensweise ist. 
So können Sie von überall in Ihrer App auf den Tracker zugreifen:

```js
import { tracker } from '@openreplay/tracker'

tracker.configure({
	projectKey: PROJECT_KEY,
  ingestPoint: "https://openreplay.mydomain.com/ingest", // when dealing with the self-hosted version of OpenReplay
})

tracker.start() // returns a promise with session info (sessionID, sessionHash, userUUID)
```

Oder Sie verwenden die Klasse `Tracker` direkt, um ihre Instanz manuell zu verwalten:

```js
import OpenReplay from '@openreplay/tracker';
//...
const tracker = new OpenReplay({
  projectKey: PROJECT_KEY,
  ingestPoint: "https://openreplay.mydomain.com/ingest" // only required if using the self-hosted version of OpenReplay
});

tracker.start();
```

### Wenn Ihre Web-App serverseitig gerendert wird (SSR)

Verwenden Sie das folgende Snippet, wenn Ihre Web-App serverseitig gerendert wird (SSR) (z. B. NextJS, NuxtJS). 
Stellen Sie sicher, dass der Tracker in einer Browserumgebung läuft und `tracker.start()` aufgerufen wird, sobald die App an den Client ausgeliefert wurde (z. B. in `useEffect` oder `componentDidMount`).

```js
import OpenReplay from '@openreplay/tracker/cjs';
//...
const tracker = new OpenReplay({
      projectKey: PROJECT_KEY
});
//...
function MyApp() {
  useEffect(() => { // use componentDidMount in case of React Class Component
    tracker.start();
  }, []);
}
```

Wenn Sie den Tracker noch weiter konfigurieren möchten, finden Sie im [JavaScript SDK](/sdk/constructor#initialization-options) die Liste der verfügbaren Optionen.

## Nächste Schritte

Nachdem Sie den Tracker installiert und Ihre Web-App bereitgestellt haben, sollten Sitzungsaufzeichnungen innerhalb weniger Minuten erscheinen. Gut gemacht!
