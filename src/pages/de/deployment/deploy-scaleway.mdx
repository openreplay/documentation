Der OpenReplay-Stack lässt sich auf einer einzelnen Instanz installieren, und Scaleway Elements ist dafür bestens geeignet. So gehen Sie vor.

## Eine Instanz starten

1. Öffnen Sie das Scaleway Dashboard
2. Navigieren Sie zu 'Compute > Instances' und klicken Sie auf 'Create an instance'
3. Wählen Sie Ihre bevorzugte Availability Zone
4. Wählen Sie ein Image. In dieser Anleitung verwenden wir *Ubuntu Server 24.04 LTS*
5. Wählen Sie Ihren Instanztyp. Die Mindestspezifikationen sind `2 vCPUs, 8 GB of RAM, 50 GB of storage` auf einer x86-Architektur, andernfalls starten die OpenReplay-Backend-Dienste schlicht nicht. Wir empfehlen daher **mindestens** `DEV1-L` (oder ein Äquivalent), das für ein geringes bis mittleres Aufkommen ausreicht. Wenn Sie viel Traffic erwarten, sollten Sie von hier aus skalieren.
6. Volumes hinzufügen: Legen Sie die Größe auf mindestens 50 GB fest (lokaler Speicher oder Block Storage)
7. Geben Sie Ihrer Instanz einen schönen Namen (z. B. openreplay)
8. SSH Keys: Stellen Sie sicher, dass Ihrem Projekt bereits ein Schlüssel zugeordnet ist, damit Sie sich mit Ihrer Instanz verbinden können
9. Klicken Sie auf 'Create a new instance'

> **Hinweis:** Die SMTP-Ports (25, 465, 587) sind bei Scaleway standardmäßig gesperrt. Ihre OpenReplay-Instanz kann keine E-Mails versenden, solange Sie SMTP nicht in der Konfiguration Ihrer Sicherheitsgruppe aktivieren. Eine Anleitung dazu finden Sie in diesem [kurzen Tutorial](https://www.scaleway.com/en/faq/why-can-i-not-send-any-email/).

## OpenReplay bereitstellen

1. Stellen Sie sicher, dass Ihre Instanz den Status `Started` hat, und verbinden Sie sich dann mit ihr:

```bash
## From your terminal
SSH_KEY=~/Downloads/openreplay-key.pem #! wherever you've saved the SSH key
INSTANCE_IP=REPLACE_WITH_INSTANCE_PUBLIC_IP
chmod 400 $SSH_KEY
ssh -i $SSH_KEY root@$INSTANCE_IP
```

2. Installieren Sie OpenReplay, indem Sie die Domain angeben, unter der es laufen soll (z. B. DOMAIN_NAME=openreplay.mycompany.com):

```bash
sudo wget https://raw.githubusercontent.com/openreplay/openreplay/main/scripts/helmcharts/openreplay-cli -O /bin/openreplay 
sudo chmod +x /bin/openreplay
openreplay -i DOMAIN_NAME
```

## TLS/SSL konfigurieren

OpenReplay verarbeitet sensible Benutzerdaten und setzt daher HTTPS voraus. Das ist zwingend erforderlich, sonst würde der Tracker schlicht keine Aufzeichnung starten. Dasselbe gilt für das Dashboard: Ohne HTTPS können Sie keine Benutzersitzungen wiedergeben.

Sie müssen daher ein eigenes SSL-Zertifikat mitbringen (oder erzeugen).

1. Öffnen Sie zunächst 'Network' > 'DNS' (oder Ihren anderen DNS-Anbieter) und legen Sie einen `A Record` an. Verwenden Sie die Domain, die Sie zuvor im Installationsschritt angegeben haben, und lassen Sie sie über die öffentliche IP-Adresse auf die Instanz zeigen (diese finden Sie unter 'Compute' > 'Instances').

2. Wenn Sie ein eigenes Zertifikat mitbringen, erstellen Sie mit dem folgenden Befehl ein SSL-Secret: `kubectl create secret tls openreplay-ssl -n app --key="private_key_file.pem" --cert="certificate.crt"`.

> **Hinweis:** Wenn Sie kein Zertifikat haben, erzeugen Sie mit Let's Encrypt ein sich automatisch erneuerndes Zertifikat für Ihre Subdomain (die bei der Installation angegebene). Verbinden Sie sich dazu einfach mit der OpenReplay-Instanz, führen Sie `cd /var/lib/openreplay/openreplay/scripts/helmcharts && bash certmanager.sh` aus und folgen Sie den Schritten.

3. Wenn Sie die Weiterleitung von HTTP auf HTTPS aktivieren möchten (empfohlen), entfernen Sie in `/var/lib/openreplay/vars.yaml` die Kommentarzeichen vor dem folgenden Block im Abschnitt `ingress-nginx`:
   
```yaml
ingress-nginx: &ingress-nginx
  controller:
    config:
      ssl-redirect: true
      force-ssl-redirect: true
```

Beachten Sie, dass unser `ingress-nginx` standardmäßig auf den Ports `80|443` läuft. Das lässt sich bei Bedarf jedoch einfach in `vars.yaml` ändern:

```yaml
ingress-nginx: &ingress-nginx
  controller:
    service:
      ports:
        http: 80
        https: 443
```

4. Installieren Sie abschließend OpenReplay NGINX neu:

```bash
openreplay -R
```

Damit ist alles erledigt: OpenReplay sollte nun unter Ihrer Subdomain erreichbar sein. Sie können ein Konto erstellen, indem Sie die Seite `/signup` aufrufen (z. B. openreplay.mycompany.com/signup).
