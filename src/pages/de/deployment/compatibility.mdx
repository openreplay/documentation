Wenn Sie Ihre OpenReplay-Instanz aktualisieren, ist es wichtig sicherzustellen, dass Ihr Tracker (und das tracker-assist-Plugin, falls Sie es verwenden) mit der Backend-Version kompatibel ist.

## Kompatibilitätstabelle

Anhand der folgenden Tabelle können Sie bestimmen, welche Tracker- und Assist-Versionen Sie mit Ihrem Backend verwenden sollten:

| Tracker-Version | Mindestversion des Backends | Mindestversion von Assist |
|:--------------:|:---------------:|:-------------:|
| 19.x.x | 1.28.0 | 11.x.x |
| 18.x.x | 1.27.0 | 11.x.x |
| 17.2.x | 1.26.0 | 11.x.x |
| 17.2.x | 1.25.0 | 11.x.x |
| 17.1.x | 1.24.0 | 11.x.x |
| 17.x.x | 1.23.0 | 11.x.x |
| 16.x.x | 1.22.0 | 11.x.x |
| 15.x.x | 1.21.0 | 10.x.x |
| 14.x.x | 1.20.0 | 10.x.x |

## Tracker-Changelog

Eine vollständige Liste der Aktualisierungen und Änderungen am OpenReplay-Tracker finden Sie im [Tracker Changelog auf GitHub](https://github.com/openreplay/openreplay/blob/dev/tracker/tracker/CHANGELOG.md).
