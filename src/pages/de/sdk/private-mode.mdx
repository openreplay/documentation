## Privater Modus

Der **Private Modus** ist eine neue Einstellung, die verhindert, dass sämtlicher Text und sensible Daten aufgezeichnet werden. Wenn sie aktiviert ist, erfasst der OpenReplay-Tracker keinen sichtbaren Text, keine Netzwerkdaten und keine Konsolenprotokolle. Alles wird bereits an der Quelle verschleiert – so verlässt nichts Sensibles den Browser.

Das ist nützlich, wenn Sie volle Einblicke in das UI-Verhalten haben möchten, die Inhalte und Daten Ihrer Benutzer aber vollständig privat bleiben sollen.

## So aktivieren Sie den Privaten Modus

Sie können den Privaten Modus auf Tracker-Ebene aktivieren, wenn Sie OpenReplay initialisieren.

#### Mit NPM

```js
import { tracker } from '@openreplay/tracker'

tracker.configure({
    projectKey: PROJECT_KEY,
    privateMode: true
})
tracker.start();
```

Wenn `privateMode` auf `true` gesetzt ist, wird Folgendes verschleiert:

- Der gesamte sichtbare Text auf der Seite  
- `alt`-Attribute von Bildern  
- `placeholder`-Werte in Eingabefeldern  
- Beschriftungstexte

## Wann Sie ihn verwenden sollten

Verwenden Sie `privateMode`, wenn:

- Sie den vollständigen Datenschutz Ihrer Benutzer sicherstellen müssen
- Sie OpenReplay in einer **Cloud-Umgebung** testen, aber **später selbst hosten** möchten und **keine echten Daten nach außen senden dürfen**
- Sie in regulierten Branchen arbeiten, in denen **Datenschutz an erster Stelle steht**
