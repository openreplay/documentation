Mit dieser Methode können Sie eine Benutzer-ID für die aktuell aktive Sitzung festlegen. So ordnen Sie dem Replay einen Benutzer zu und können Sitzungen gezielt nach einem bestimmten Benutzer filtern und durchsuchen.

## Signatur
```js
setUserID(id: string): void
```

## Parameter

- `id: string`: Die ID des Benutzers. Sie ist ein String und kann beliebig gewählt werden, solange es ein String ist und Sie damit einen Benutzer in Ihrem System eindeutig identifizieren können (z. B. E-Mail-Adresse, Datenbank-ID usw.).

## Rückgabewert

Diese Methode gibt keine Werte zurück; die Ergebnisse sind in der OpenReplay-Plattform sichtbar.
