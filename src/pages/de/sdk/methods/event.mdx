Mit dieser Methode können Sie ein „funktionales Ereignis“ melden. Über funktionale Ereignisse können Sie Momente in der Sitzung des Benutzers kennzeichnen, die aus funktionaler Sicht relevant sind und die unser Tracker standardmäßig nicht von selbst erkennen und markieren kann. Ein Beispiel für ein funktionales Ereignis wäre, dass der Benutzer einen Artikel in den Warenkorb legt. Der Tracker kann die Aktion zwar aufzeichnen, weiß aber nicht, dass er sie in der Timeline Ihrer Sitzung als relevantes Ereignis markieren soll. Mit dieser Methode können Sie das jedoch manuell tun.

<Aside type="tip">
  Wir haben außerdem ein ausführliches Tutorial zum Senden von Custom Events, das Sie sich [hier](/tutorials/custom-events) ansehen können.
</Aside>

Weitere Details finden Sie unter [Custom Events](/product-analytics/data-management).

## Signatur

```js 
event(key: string, payload?: any, issue?: boolean): void
```

## Parameter

- `key: string`: Der Name des Schlüssels, unter dem die Information gespeichert wird. Dieser Schlüssel kann in der OpenReplay-Plattform zum Filtern und Suchen verwendet werden.
- `payload: any`: Der Inhalt des Ereignisses. Das können beliebige serialisierbare Daten sein.
- `issue: boolean` : Gibt an, ob es sich um ein funktionales Ereignis (bei `false`) oder um ein „technisches Ereignis“ (bei `true`) handelt. Standardmäßig ist der Wert `false`.
