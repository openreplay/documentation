Mit dieser Methode können Sie die URL der aktiven Sitzung abrufen. Die URL verweist auf das OpenReplay-Dashboard. Die Methode ist nützlich, wenn Sie OpenReplay in Ihren eigenen Stack integrieren möchten.

## Signatur

```js
getSessionURL({ withCurrentTime?: boolean }): string | undefined
```

## Parameter

- `withCurrentTime: boolean`: Optionaler Parameter, standardmäßig `false`. Bei `true` enthält die URL den Zeitstempel des Moments im Replay, in dem die Methode aufgerufen wurde.

## Rückgabewert

Diese Methode gibt die URL der aktiven Sitzung zurück, die auf der OpenReplay-Plattform wiedergegeben werden soll. Optional kann die URL den Zeitstempel des Moments enthalten, in dem die Methode aufgerufen wird, sodass Sie direkt an diese Stelle im Replay springen.
