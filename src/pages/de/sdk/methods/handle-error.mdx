Wenn die Informationen, die unser Tracker bei einem JS-Fehler standardmäßig erfasst, nicht ausreichen, können Sie diese Methode verwenden. Die Methode `handleError` meldet abgefangene Exceptions, abgelehnte Promises oder Fehlerereignisse manuell. Weitere Details finden Sie unter [Fehlerberichte](/session-replay/error-reporting#manually-logging-exceptions).

## Signatur

```js 
handleError: (e: Error | ErrorEvent | PromiseRejectionEvent, metadata?: Record<string, any>) => void
```

## Parameter

- `e: Error | ErrorEvent | PromiseRejectionEvent`: Das tatsächlich abgefangene Fehlerobjekt.
- `metadata: Record<string, any>`: **[Optional]** Eine Dictionary-ähnliche Struktur mit allen zusätzlichen Informationen, die Sie zu diesem Fehler speichern möchten.

## Rückgabewert

Diese Methode gibt keine Werte zurück; die gespeicherten Informationen sind in der OpenReplay-Plattform einsehbar.
