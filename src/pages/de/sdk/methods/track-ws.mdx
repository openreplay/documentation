Mit dieser Methode können Sie einzelne WebSocket-Kanäle und die Richtung der Nachrichten (eingehend/ausgehend) tracken.

## Signatur

```ts 
trackWs: (channelName: string) => (msgType: string, data: string, dir: 'up' | 'down') => void
```

## Parameter

- `channelName: string`: Name des WS-Kanals.

## Rückgabewert

Gibt einen Hook zurück, der auf WS-Nachrichten angewendet wird und als Parameter den Nachrichtentyp (oder -namen), die Daten und die Nachrichtenrichtung (up/down === gesendet/empfangen) erwartet.
