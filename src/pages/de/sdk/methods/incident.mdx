Mit dieser Methode können Sie ein wichtiges Ereignis oder einen Vorfall während der Sitzung eines Benutzers markieren. Incidents dienen in der Regel dazu, bedeutsame Vorkommnisse hervorzuheben, etwa Fehler, Abstürze oder andere bemerkenswerte Ereignisse, die Aufmerksamkeit erfordern. Wenn Sie solche Vorfälle markieren, können Sie sie im Session Replay leicht erkennen und analysieren.

## Signatur

```js
// call incident function and pass label, startTime, and endTime (label and endTime are optional)
incident({ label: 'incident', startTime: Date.now() - 1000, endTime: Date.now() })
```

## Parameter

- `label: string`: Der Name des markierten Ereignisses.
- `startTime: number`: Zeitstempel für den Beginn des Ereignisses.
- `endTime: number` : Zeitstempel für das Ende des Ereignisses.
