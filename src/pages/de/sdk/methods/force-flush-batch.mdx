Zwingt den Tracker, den aktuellen Nachrichtenstapel sofort zu senden, ohne auf dessen Abschluss zu warten. Nützlich, wenn Sie den Tab bzw. das Fenster nach einer Sitzung schließen müssen. Diese Methode sendet außerdem eine Nachricht an den Webworker, der daraufhin eine Netzwerkanfrage mit dem aktuellen Nachrichtenstapel startet.

## Signatur

```ts
forceFlushBatch(): void
```
