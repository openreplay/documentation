Der Tracker lauscht auf Ereignisse, bei denen Ansichten auf dem Bildschirm des Telefons erscheinen oder verschwinden.

## Erfasste Ansichten hinzufügen

Das SDK exportiert `ORAnalyticsView`, mit dem Sie wichtige Ansichten bzw. Komponenten markieren können.

```js
import OR from '@openreplay/react-native'

// ... your app UI

  <OR.ORAnalyticsView
    screenName="Pay confirmation page"
    viewName="New fancy button"
  >
    <ImportantRedButton />
  </OR.ORAnalyticsView>

// ...
```
