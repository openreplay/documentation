Mit dieser Methode können Sie eine Benutzer-ID für die aktuell aktive Sitzung festlegen. So ordnen Sie dem Replay einen Benutzer zu und können Sitzungen eines bestimmten Benutzers filtern und durchsuchen.

## Signatur

```js
import OR from '@openreplay/react-native'

// ...
OR.tracker.setUserID('id')
```


## Parameter

- `userID: String`: Die ID des Benutzers. Das ist ein String und kann beliebig sein, solange es ein String ist und Sie damit einen Benutzer in Ihrem System eindeutig identifizieren können (z. B. E-Mail-Adresse, Datenbank-ID usw.).

## Rückgabewert

Diese Methode gibt keine Werte zurück. Die Ergebnisse sind in der OpenReplay-Plattform sichtbar.
