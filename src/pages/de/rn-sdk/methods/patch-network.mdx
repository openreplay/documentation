Diese Methode patcht die XHR- und Fetch-APIs, um Netzwerkanfragen abzufangen.

## Signatur

```js
import OR from '@openreplay/react-native'

OR.patchNetwork(
    global,
		(url) => url.includes('openreplaydomain'),
    { mode: 'fetch' }
)
```

## Parameter

- `context: globalThis`: aktueller Kontext der App (aus dem fetch/xhr bezogen werden)
- `isServiceURL: (url: string) => boolean`: Funktion, die prüft, ob die aktuelle Anfrage erfasst (false) oder übersprungen (true) werden soll
- `options: Partial<Options>`: Options-Objekt

## Optionen

- `ignoreHeaders: Array<string> | boolean`: zu ignorierende Header (Standard: `['cookie', 'set-cookie', 'authorization']`)
- `capturePayload: boolean`: ob die Payload der Anfrage erfasst werden soll (Standard: `false`)
- `sanitizer: data: RequestResponseData) => RequestResponseData`: Funktion, die Anfrage und Antwort bereinigt (Standard: `undefined`)
- `mode: 'fetch' | 'xhr' | 'all'`: welche API gepatcht werden soll (Standard: `'fetch'`)

> Hinweis: React-Native-Fetch verwendet (zum Zeitpunkt der Erstellung) intern XHR, sodass die Verwendung von „all“ zu doppelten Anfragen in der Aufzeichnung führen kann
