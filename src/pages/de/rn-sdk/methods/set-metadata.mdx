Mit dieser Methode können Sie den Wert eines der in der OpenReplay-Plattform konfigurierten Metadatenfelder festlegen.

<Aside type="note">
	Sie können diese Methode beliebig oft aufrufen. Beachten Sie jedoch: Wenn Sie dasselbe `key`-Attribut verwenden, wird der zuletzt übergebene Wert in der Plattform gespeichert. Alle vorherigen Werte gehen verloren.
</Aside>

Weitere Details finden Sie unter [Metadaten](/session-replay/metadata).

## Signatur
```js
import OR from '@openreplay/react-native'

// ...
OR.tracker.metadata('key', 'value')
```

## Parameter

- `key: string`: Der zu speichernde Metadatenschlüssel.
- `value: string`: Der Wert, der als Metadaten gespeichert werden soll.

## Rückgabewert

Diese Methode gibt keine Werte zurück. Die Information wird direkt als Teil des Replays gespeichert und ist in der OpenReplay-Plattform einsehbar.
