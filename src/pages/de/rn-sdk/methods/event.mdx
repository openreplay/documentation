Mit dieser Methode können Sie ein „funktionales Ereignis“ melden. Über funktionale Ereignisse können Sie Momente innerhalb der Sitzung des Benutzers kennzeichnen, die aus funktionaler Sicht relevant sind und die unser Tracker standardmäßig nicht von selbst erkennen und markieren kann. Ein Beispiel für ein funktionales Ereignis wäre, dass der Benutzer einen Artikel in den Warenkorb legt. Unser Tracker kann diese Aktion zwar aufzeichnen, würde aber nicht wissen, dass er sie als relevantes Ereignis in der Zeitleiste Ihrer Sitzung markieren soll. Dank dieser Methode können Sie das jedoch manuell tun.

Weitere Details finden Sie unter [Custom Events](/product-analytics/data-management).

## Signatur

```js
import OR from '@openreplay/react-native'

OR.tracker.event("name", JSON.stringify({ key: "value" }))
```

## Parameter

- `key: string`: Der Name des Schlüssels, unter dem die Information gespeichert wird. Dieser Schlüssel kann innerhalb der OpenReplay-Plattform zum Filtern und Suchen verwendet werden.
- `payload: string`: Der Inhalt des Ereignisses. Das können beliebige als String kodierte (JSON-)Daten sein.
