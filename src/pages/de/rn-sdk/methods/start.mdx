Mit dieser Methode starten Sie den Tracker. Mit dem Start des Trackers beginnt die Aufzeichnung der Sitzung.

## Signatur

```swift
import OR from '@openreplay/react-native'

OR.tracker.startSession(options)
```

## Initialisierungsoptionen

Standardmäßig sind alle Optionen auf `true` gesetzt:
- `crashes: Bool` Aktiviert Crashlytics.
- `analytics: Bool` Aktiviert das Analytics-Tracking markierter Ansichten.
- `performances: Bool` Aktiviert den Performance-Listener
- `logs: Bool` Aktiviert den Logs-Listener
- `screen: Bool` Aktiviert den Screen Recorder

Mit den Optionen lassen sich bestimmte Funktionen deaktivieren; andernfalls können Sie das leere Objekt (`{}`) übergeben
