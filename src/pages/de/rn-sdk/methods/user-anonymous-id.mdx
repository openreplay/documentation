Ordnet der aufgezeichneten Sitzung eine anonyme userID zu.

## Signatur

```swift
ORTracker.userAnonymousID(userID: String)
```

## Parameter

- `userID: String`: Die anonyme ID des Benutzers. Das ist ein String und kann beliebig sein, solange es ein String ist und Sie damit einen Benutzer in Ihrem System eindeutig identifizieren können (z. B. E-Mail-Adresse, Datenbank-ID usw.).

## Rückgabewert

Diese Methode gibt keine Werte zurück. Die Ergebnisse sind in der OpenReplay-Plattform sichtbar.
