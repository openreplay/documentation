Der Tracker lauscht auf Änderungen des Werts (mit Debouncing) und sendet den resultierenden Wert an das OpenReplay-Backend.

## Erfasste Eingaben hinzufügen

Das SDK exportiert `ORTrackedInput`, das Sie wie normale TextInput-Komponenten verwenden können.

```js
import OR from '@openreplay/react-native'

// ... your app UI

  <OR.ORTrackedInput
    style={styles.input}
    onChangeText={onChangeNumber}
    value={number}
    placeholder="important placeholder"
  />

// ...
```
