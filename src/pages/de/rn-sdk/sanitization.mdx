## UI-Komponenten

Bereinigte Views werden im resultierenden Replay verwischt. Sie können jede beliebige UI-Komponente hinzufügen. Sie wird automatisch entfernt (um Speicher zu sparen), sobald sie nicht mehr auf dem Bildschirm ist.

### ORSanitizedView

Das SDK exportiert `ORSanitizedView`, mit dem Sie Ihre sensiblen Komponenten umschließen können, um sie zu verwischen.

```js
import OR from '@openreplay/react-native'

// ... your app UI

  <OR.ORSanitizedView>
    <SensitiveComponent />
  </OR.ORSanitizedView>

// ...
```
