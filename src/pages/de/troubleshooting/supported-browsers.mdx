metaTitle: "Unterstützte Browser"
metaDescription: "Liste der Browser, die mit OpenReplay für die Sitzungsaufzeichnung kompatibel sind."
---

OpenReplay wird in den folgenden Browsern unterstützt:
- Google Chrome 41+
- Firefox 17+
- Microsoft Edge 12+
- Internet Explorer 11+
- Safari 9+
- Safari on iOS 9+
- Opera 28+
- Opera Mobile 62+

Wenn Sie eine Sitzung in einem nicht unterstützten Browser aufzeichnen, löst das SDK eine Ausnahme aus.

## Haben Sie Fragen?
Wenn Sie weitere Fragen zur Browserkompatibilität haben, melden Sie sich gerne bei uns auf [Slack](https://slack.openreplay.com) .
