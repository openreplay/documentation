Der Tracker lauscht auf Ereignisse, die auftreten, wenn Views ein- oder ausgeblendet werden.

## Erfasste Views hinzufügen

### 

Verwenden Sie `.observeView(title:viewName:)`, um Eingabeereignisse zu beobachten,

- `title: String` - Titel des Bildschirms oder der Funktion
- `viewName: String` - Name der Tracker-View

```kotlin

TextField("Input", text: $text)
 .observeView(title: "Screen title", viewName: "test input name")
```
