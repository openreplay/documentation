Mit dieser Methode können Sie den Wert eines der auf der OpenReplay-Plattform konfigurierten Metadatenfelder festlegen.

<Aside type="note">
	Sie können diese Methode beliebig oft aufrufen. Beachten Sie jedoch: Wenn Sie dasselbe Attribut `key` verwenden, wird der zuletzt übergebene Wert in der Plattform gespeichert. Alle vorherigen Werte gehen verloren.
</Aside>

Weitere Details finden Sie unter [Metadaten](/session-replay/metadata). 

## Signatur
```kotlin
OpenReplay.setMetadata(key: String, value: String)
```

## Parameter

- `key: string`: Der zu speichernde Metadatenschlüssel. 
- `value: string`: Der Wert, der als Metadaten gespeichert werden soll.

## Rückgabewert

Diese Methode gibt keine Werte zurück. Die Informationen werden direkt als Teil des Replays gespeichert und sind in der OpenReplay-Plattform einsehbar.
