Ordnen Sie der aufgezeichneten Sitzung eine anonyme userID zu.

## Signatur
```kotlin
OpenReplay.userAnonymousID(userID: String)
```

## Parameter

- `userID: String`: Die anonyme ID des Benutzers. Sie ist ein String und kann beliebig sein, solange sie ein String ist und es Ihnen erlaubt, einen Benutzer in Ihrem System eindeutig zu identifizieren (z. B. E-Mail-Adresse, Datenbank-ID usw.).

## Rückgabewert

Diese Methode gibt keine Werte zurück, die Ergebnisse sind in der OpenReplay-Plattform sichtbar.
