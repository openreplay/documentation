Mit dieser Methode können Sie der aktuell aktiven Sitzung eine Benutzer-ID zuweisen. So können Sie einen Benutzer dem Replay zuordnen und Sitzungen gezielt für einen bestimmten Benutzer filtern und durchsuchen.

## Signatur
```swift
OpenReplay.setUserID(userID: String)
```

## Parameter

- `userID: String`: Die ID des Benutzers. Sie ist ein String und kann beliebig sein, solange sie ein String ist und es Ihnen erlaubt, einen Benutzer in Ihrem System eindeutig zu identifizieren (z. B. E-Mail-Adresse, Datenbank-ID usw.).

## Rückgabewert

Diese Methode gibt keine Werte zurück, die Ergebnisse sind in der OpenReplay-Plattform sichtbar.
