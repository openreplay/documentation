Mit dieser Methode können Sie ein „funktionales Ereignis“ melden. Über funktionale Ereignisse können Sie Momente innerhalb der Sitzung eines Benutzers kennzeichnen, die aus funktionaler Sicht relevant sind und die unser Tracker standardmäßig nicht selbstständig erkennen und markieren kann. Ein Beispiel für ein funktionales Ereignis wäre, dass der Benutzer einen Artikel in den Warenkorb legt. Unser Tracker kann diese Aktion zwar aufzeichnen, würde sie aber nicht als relevantes Ereignis in der Zeitleiste Ihrer Sitzung markieren. Mit dieser Methode können Sie das jedoch manuell tun.

Weitere Details finden Sie unter [Custom Events](/product-analytics/data-management).

## Signatur

```kotlin
data class User(val name: String, val age: Int)

OpenReplay.event("Test Event", User("John", 25))
```

## Parameter

- `key: string`: Der Name des Schlüssels, unter dem die Information gespeichert wird. Dieser Schlüssel kann innerhalb der OpenReplay-Plattform zum Filtern und Suchen verwendet werden.
- `payload: Encodable`: Der Inhalt des Ereignisses. Das können beliebige kodierbare (JSON-)Daten sein.
