Mit dieser Methode legen Sie den Wert eines der Metadatenfelder fest, die auf der OpenReplay-Plattform konfiguriert sind.

<Aside type="note">
	Sie können diese Methode beliebig oft aufrufen. Beachten Sie jedoch: Wenn Sie dasselbe Attribut `key` verwenden, wird der zuletzt übergebene Wert auf der Plattform gespeichert. Alle vorherigen Werte gehen verloren.
</Aside>

Weitere Details finden Sie unter [Metadaten](/session-replay/metadata). 

## Signatur
```swift
ORTracker.shared.setMetadata(key: String, value: String)
```

## Parameter

- `key: string`: Der zu speichernde Metadatenschlüssel. 
- `value: string`: Der als Metadaten zu speichernde Wert.

## Rückgabewert

Diese Methode gibt keine Werte zurück. Die Informationen werden direkt als Teil des Replays gespeichert und sind auf der OpenReplay-Plattform einsehbar.
