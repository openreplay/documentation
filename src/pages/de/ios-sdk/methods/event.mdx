Mit dieser Methode melden Sie ein „funktionales Ereignis“. Über funktionale Ereignisse können Sie Momente innerhalb der Benutzersitzung markieren, die aus funktionaler Sicht relevant sind und die unser Tracker standardmäßig nicht von selbst erkennen und kennzeichnen kann. Ein Beispiel für ein funktionales Ereignis wäre, dass der Benutzer einen Artikel in den Warenkorb legt. Unser Tracker kann die Aktion zwar aufzeichnen, würde sie aber nicht als relevantes Ereignis in der Timeline Ihrer Sitzung kennzeichnen. Mit dieser Methode können Sie das jedoch manuell tun.

Weitere Details finden Sie unter [Custom Events](/product-analytics/data-management).

## Signatur

```swift
ORTracker.shared.event(name: String, payload: Encodable?)
```

## Parameter

- `key: string`: Der Name des Schlüssels, unter dem die Informationen gespeichert werden. Dieser Schlüssel kann auf der OpenReplay-Plattform zum Filtern und Suchen verwendet werden.
- `payload: Encodable`: Der Inhalt des Ereignisses. Das können beliebige kodierbare (JSON-)Daten sein.
