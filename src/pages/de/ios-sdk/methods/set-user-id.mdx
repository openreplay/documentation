Mit dieser Methode legen Sie eine Benutzer-ID für die aktuell aktive Sitzung fest. So können Sie einen Benutzer dem Replay zuordnen und Sitzungen eines bestimmten Benutzers filtern und durchsuchen.

## Signatur
```swift
ORTracker.shared.setUserID(_ userID: String)
```

## Parameter

- `userID: String`: Die ID des Benutzers. Dies ist ein String und kann beliebig sein, solange sie ein String ist und Sie damit einen Benutzer in Ihrem System eindeutig identifizieren können (z. B. E-Mail-Adresse, Datenbank-ID usw.).

## Rückgabewert

Diese Methode gibt keine Werte zurück; die Ergebnisse sind auf der OpenReplay-Plattform sichtbar.
