Ordnen Sie der aufgezeichneten Sitzung eine anonyme userID zu.

## Signatur
```swift
ORTracker.shared.userAnonymousID(_ userID: String)
```

## Parameter

- `userID: String`: Die anonyme ID des Benutzers. Dies ist ein String und kann beliebig sein, solange sie ein String ist und Sie damit einen Benutzer in Ihrem System eindeutig identifizieren können (z. B. E-Mail-Adresse, Datenbank-ID usw.).

## Rückgabewert

Diese Methode gibt keine Werte zurück; die Ergebnisse sind auf der OpenReplay-Plattform sichtbar.
