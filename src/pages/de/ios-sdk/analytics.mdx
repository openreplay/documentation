Der Tracker überwacht die Ereignisse, wenn Ansichten ein- bzw. ausgeblendet werden.

## Erfasste Ansichten hinzufügen

### SwiftUI

Verwenden Sie `.observeView(title:viewName:)`, um Eingabeereignisse zu beobachten,

- `title: String` - Titel des Bildschirms oder der Funktion
- `viewName: String` - Name der Tracker-Ansicht

```swift
import ORTracker

TextField("Input", text: $text)
 .observeView(title: "Screen title", viewName: "test input name")
```

### UIKit
```swift
import ORTracker

Analytics.shared.addObservedView(view: inputEl, title: "Screen title", viewName: "test input name")
```
