Der Tracker überwacht Wertänderungsereignisse (mit Debouncing) und sendet den resultierenden Wert an das OpenReplay-Backend.

## Erfasste Eingaben hinzufügen

### SwiftUI

Verwenden Sie `.observeInput(text:label:masked)`, um Eingabeereignisse zu beobachten,

- `text: String` - Textwert der Eingabe
- `label: String` - Label für die aufgezeichnete Eingabe
- `masked: Bool` - bei `true` zeichnet der Tracker nur das Eingabeereignis selbst auf, nicht den Wert; vergessen Sie nicht, `.sensitive` hinzuzufügen, um die Eingabe in der Aufzeichnung unkenntlich zu machen.

```swift
import ORTracker

TextField("Input", text: $text)
.observeInput(text: $text, label: "tracker input #1", masked: Bool)

```

### UIKit

UIKit verwendet den Platzhalter als Label und sender.isSecureTextEntry, um die Eingabe zu maskieren

```swift
import ORTracker

Analytics.shared.addObservedInput(inputEl)
```
