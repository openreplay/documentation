Die App **OpenReplay MCP** verbindet Ihre OpenReplay-Instanz mit einem MCP-fähigen Chat-Host (Claude Desktop, Claude Code, ChatGPT, Codex), sodass Sie Product Analytics und Session Replays in natürlicher Sprache erkunden können. Fordern Sie ein Diagramm an, analysieren Sie einen Funnel im Detail, finden Sie eine Sitzung und öffnen Sie anschließend ihr Replay – alles direkt im Chat.

Die App funktioniert sowohl mit **OpenReplay Cloud** als auch mit **selbst gehosteten** Instanzen.

<Aside type="tip" title="Das erhalten Sie" >
  - Durchsuchen Sie Sitzungen mit denselben Filtern, die Sie auch in der OpenReplay-Oberfläche verwenden.
  - Stellen Sie Zeitreihen, Funnels, Benutzer-Journeys, Web Vitals und Top-of-X-Aufschlüsselungen direkt im Chat dar.
  - Sehen Sie sich Session Replays direkt im Chat an.
  - Verknüpfen Sie alles miteinander: Sitzungen suchen → eine Sitzung auswählen → Replay öffnen → Claude bitten, es zusammenzufassen.
</Aside>

## Kompatibilität

Die App spricht Standard-MCP über stdio und funktioniert daher mit:

- **Claude Desktop** (macOS, Windows)
- **Claude Code**
- **ChatGPT** (über den MCP-Connector)
- **Codex**
- Jeder andere Host, der MCP unterstützt
