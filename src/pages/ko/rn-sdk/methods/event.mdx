이 메서드를 사용하면 "기능 이벤트(functional event)"를 보고할 수 있습니다. 기능 이벤트를 통해 사용자 세션 내에서 기능적 관점에서 의미 있지만, 기본적으로 트래커가 스스로 감지해 표시할 수 없는 순간을 알릴 수 있습니다. 기능 이벤트의 예로는 사용자가 장바구니에 상품을 담는 동작이 있습니다. 트래커는 이 동작을 기록할 수는 있지만, 이를 세션 타임라인에서 의미 있는 이벤트로 표시해야 한다는 것은 알지 못합니다. 하지만 이 메서드를 사용하면 직접 표시할 수 있습니다.

자세한 내용은 [커스텀 이벤트](/product-analytics/data-management)를 참고하세요.

## 시그니처

```js
import OR from '@openreplay/react-native'

OR.tracker.event("name", JSON.stringify({ key: "value" }))
```

## 매개변수

- `key: string`: 정보가 저장될 키의 이름입니다. 이 키는 OpenReplay 플랫폼 내에서 필터링과 검색에 사용할 수 있습니다.
- `payload: string`: 이벤트의 내용입니다. 문자열로 인코딩된(JSON) 데이터라면 무엇이든 사용할 수 있습니다.
