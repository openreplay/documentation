## UI 컴포넌트

정제된 뷰는 생성되는 리플레이에서 흐리게 처리됩니다. 어떤 UI 컴포넌트든 추가할 수 있으며, 화면에서 사라지는 즉시 (메모리를 절약하기 위해) 자동으로 제거됩니다.

### ORSanitizedView

SDK는 `ORSanitizedView`를 내보내며, 민감한 컴포넌트를 이것으로 감싸 흐리게 처리할 수 있습니다.

```js
import OR from '@openreplay/react-native'

// ... your app UI

  <OR.ORSanitizedView>
    <SensitiveComponent />
  </OR.ORSanitizedView>

// ...
```
