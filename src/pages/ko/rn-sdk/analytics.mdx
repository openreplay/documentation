트래커는 휴대폰 화면에서 뷰가 나타나거나 사라지는 이벤트를 수신합니다.

## 추적할 뷰 추가하기

SDK는 `ORAnalyticsView`를 내보내며, 이를 사용해 중요한 뷰/컴포넌트를 표시할 수 있습니다.

```js
import OR from '@openreplay/react-native'

// ... your app UI

  <OR.ORAnalyticsView
    screenName="Pay confirmation page"
    viewName="New fancy button"
  >
    <ImportantRedButton />
  </OR.ORAnalyticsView>

// ...
```
