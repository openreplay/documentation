트래커는 값 변경 이벤트(디바운스 적용)를 수신하고 그 결과 값을 OpenReplay 백엔드로 전송합니다.

## 추적할 입력 추가하기

SDK는 `ORTrackedInput`을 내보내며, 이를 일반 TextInput 컴포넌트처럼 사용할 수 있습니다.

```js
import OR from '@openreplay/react-native'

// ... your app UI

  <OR.ORTrackedInput
    style={styles.input}
    onChangeText={onChangeNumber}
    value={number}
    placeholder="important placeholder"
  />

// ...
```
