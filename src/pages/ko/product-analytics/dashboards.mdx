OpenReplay의 대시보드는 제품의 성능과 사용자 경험을 모니터링, 분석, 최적화하는 중앙 허브 역할을 합니다. 문제를 디버깅하든, 사용자 행동을 추적하든, 성능을 측정하든, 대시보드는 데이터에 기반한 의사 결정에 필요한 인사이트를 제공합니다.

OpenReplay 대시보드는 팀의 모든 구성원에게 필요한 핵심 인사이트를 한곳에 모아 줍니다.

- **개발자용:** JavaScript 오류, 느린 네트워크 요청, 성능 문제와 같은 기술적 문제를 실시간으로 추적합니다.
- **제품 관리자용:** 사용자 행동을 분석하고, 전환 퍼널을 모니터링하며, 사용자가 제품에서 거치는 경로를 파악합니다.
- **웹사이트 성능을 분석하는 팀용:** 가장 많이 방문한 페이지, 트래픽 소스, 사용자 인구 통계 등 주요 지표를 추적합니다.

## 대시보드 및 사용 가능한 카드 개요 

대시보드를 만들면 처음에는 빈 상태로 시작되며, 원하는 대로 커스터마이징할 수 있습니다. 대시보드는 **카드**로 구성되며, 각 카드에는 특정 지표 또는 데이터 집합이 표시됩니다. 필요에 따라 카드를 추가, 제거하거나 이동하여 대시보드를 구성할 수 있습니다.

카드는 크게 세 가지 범주로 나뉩니다.

#### 제품 분석(Product analytics)  

*제품 분석*은 제품 내 사용자 참여와 행동을 추적하고 분석하는 데 도움이 됩니다.

| **카드**    | **설명**                                                   |
|-------------------|------------------------------------------------------------------|
| **Trends**        | 시간에 따른 세션 추세 모니터링                                |
| **Funnels**       | 핵심 단계에 걸친 사용자 진행 상황을 시각화하고 이탈 지점을 파악하여 전환율 개선               |
| **Journeys**      | 사용자가 제품에서 거치는 경로 파악            |
| **Heatmaps**      | 사용자 상호작용이 집중되는 지점과 패턴 시각화              |

#### 모니터(Monitors)  

*모니터*는 사용자 경험에 영향을 주는 기술적 성능 문제를 파악하고 해결하는 데 도움이 됩니다.

| **카드**           | **설명**                                                    |
|--------------------------|-------------------------------------------------------------------|
| **JS Errors**            | 사용자 경험에 영향을 주는 JavaScript 오류 추적             |
| **Top Network Requests** | 자주 요청되는 네트워크 리소스 파악                    |
| **4xx/5xx Requests**     | 성능 문제를 일으키는 클라이언트 및 서버 오류 모니터링           |
| **Slow Network Requests**| 느린 응답으로 인한 지연 지점 정확히 파악                          |

#### 웹 분석(Web Analytics)

*웹 분석*은 사용자 인구 통계, 트래픽 소스, 트래픽 패턴에 대한 인사이트를 제공합니다.


| **카드**               | **설명**                                                   |
|------------------------------|------------------------------------------------------------------|
| **Top Pages**               | 사이트에서 가장 많이 방문한 페이지 파악                      |
| **Top Browsers**            | 사용자가 가장 많이 사용하는 브라우저 확인                        |
| **Top Referrers**           | 트래픽이 어디에서 유입되는지 파악                          |
| **Top Users**               | 상호작용이 가장 많은 사용자 찾기                             |
| **Top Countries** | 위치별 오디언스 분석              |
| **Top Devices** | 디바이스 유형별 오디언스 분석             |



## 첫 대시보드 만들기

1단계: Dashboards로 이동한 다음 **Create dashboard** 버튼을 클릭합니다.

2단계: 세 가지 범주 중 하나를 선택합니다. 추가할 카드 유형을 선택하여 **처음부터 시작**하거나, **Add existing Card**를 클릭하여 기존 카드를 재사용합니다.

3단계: **Create Card**를 클릭하여 대시보드에 추가합니다.

4단계: 다른 카드를 추가하려면 기존 카드 옆의 "+" 버튼을 클릭합니다.

## 일반적인 사용 사례  

대시보드는 유연하여 다양한 목적에 맞게 조정할 수 있습니다. 

다음은 몇 가지 예시입니다.  

- **사용자 행동 분석:** Trends와 Journeys를 사용하여 사용자가 제품과 상호작용하는 방식을 파악합니다.  
- **문제 식별:** JS Errors, 4xx/5xx Requests, Slow Network Requests를 모니터링하여 성능 문제를 해결합니다.  
- **트래픽 이해:** Top Pages, Referrers, 사용자 인구 통계를 추적하여 잘 되고 있는 부분과 개선이 필요한 부분을 확인합니다.  

마케팅 캠페인 모니터링이나 기술 성능 추적 등 특정 목표별로 별도의 대시보드를 만드세요. 대시보드는 시스템을 보는 여러 관점 역할을 하며, 지금 어떤 일이 일어나고 있는지 통합된 요약으로 제공합니다.
