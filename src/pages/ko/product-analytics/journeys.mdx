**Journeys**는 사용자가 제품 안에서 어떻게 이동하는지 분석하고 이해하는 데 도움이 됩니다. 가장 흔한 사용자 흐름을 살펴보든, 예상치 못한 행동을 찾아내든, 주요 접점에서의 이탈을 분석하든, **Journeys**를 통해 사용자가 거치는 경로를 시각화하고 사용자 경험에 대한 더 깊은 인사이트를 얻을 수 있습니다.

## Journeys 활용 사례

**Journeys**는 다음과 같은 중요한 질문에 답하는 데 도움이 됩니다.

- 특정 페이지에 도착한 뒤 사용자가 가장 흔히 거치는 경로는 무엇인가요?
- 사용자는 결제 페이지에 도달하기 전에 어떻게 이동하나요?
- 사용자가 이탈하기 전에 일반적으로 거치는 단계는 무엇인가요?
- 높은 전환이나 이탈로 이어지는 예상치 못한 경로가 있나요?
- 모바일 사용자는 데스크톱 사용자와 어떻게 다르게 이동하나요?


## Journeys 시작하기

#### 새 Journey 만들기

**Cards** 메뉴의 "Product Analytics" 카테고리에서 **Journeys**에 접근할 수 있습니다. "Journeys"를 선택하면 사용자 경로를 설정하고 분석할 수 있습니다.

#### Journeys의 기본 구성

1. **메뉴 바:** 표시 레이아웃을 변경하거나, Journey 카드의 이름을 바꾸거나, 삭제하거나, 대시보드에 추가합니다.
2. **차트 영역:** 가장 흔한 사용자 경로를 시각화합니다.
3. **기간:** 특정 추세를 분석하도록 기간을 조정합니다.
4. **이벤트 및 필터:** 방문한 URL을 지정하여 시작점과 종료점을 정의합니다. 필터를 적용하여 사용자 및 세션 속성과 메타데이터를 기준으로 분석을 정교하게 다듬을 수 있습니다.
5. **세션 목록:** 선택한 Journey와 일치하는 사용자 세션 목록을 확인합니다.

## Journey 보기 사용자 지정

#### 기간 조정

- 사전 설정 옵션: 지난 24시간, 지난 7일, 지난 30일의 데이터를 분석합니다.
- 사용자 지정 범위: 필요에 따라 특정 기간을 직접 지정합니다.

#### 이벤트와 필터

- 방문한 URL 경로를 지정하여 시작점 또는 종료점을 정의합니다.
- 특정 페이지나 클릭을 제외하여 표시되는 경로를 정교하게 다듬습니다.
- 전역 필터를 적용하여 특정 사용자 세그먼트나 세션 특성에 집중합니다.

#### 인터랙티브 기능

- Group minor paths: 이 토글을 켜면 노이즈를 줄이고 주요 사용자 흐름에 집중할 수 있습니다.
- 세션 목록: 특정 Journey와 일치하는 세션을 확인하고 살펴봅니다.

**참고:** 이탈한 세션에 대한 드릴다운은 아직 지원되지 않습니다.

## Journeys를 최대한 활용하기

- 비즈니스 목표에 부합하는 명확하고 실행 가능한 진입점과 종료점을 정의하세요.
- 필터와 제외 조건을 사용하여 분석을 정교하게 다듬고 의미 있는 경로에 집중하세요.
- 세션 목록을 활용해 개별 여정을 살펴보고 더 깊은 인사이트를 얻으세요.
