**Funnels**는 사용자가 제품의 핵심 단계를 어떻게 거쳐 가는지 분석하고 이해할 수 있도록 설계되었습니다. 가입 흐름, 결제 프로세스, 온보딩 완료 등 무엇을 추적하든 퍼널을 통해 사용자 여정을 시각화하고 사용자가 이탈하는 지점을 정확히 찾아낼 수 있습니다.

## 퍼널 활용 사례

**Funnels**는 다음과 같은 중요한 질문에 답하는 데 도움이 됩니다.

- 결제 프로세스의 각 단계를 완료하는 사용자는 몇 명인가요?
- 온보딩 중 사용자는 어디에서 이탈하나요?
- 가입 프로세스에서 X 단계와 Y 단계 사이의 이탈률은 얼마인가요?
- 온보딩 프로세스의 어느 단계에서 이탈이 가장 많이 발생하나요?
- 모바일 사용자는 데스크톱 사용자와 비교해 특정 단계에서 더 많이 이탈하나요?

## Funnels 시작하기

#### 새 퍼널 만들기

Cards 메뉴의 "Product Analytics" 카테고리에서 Funnels에 접근할 수 있습니다. "Funnels"를 선택하면 퍼널 단계를 설정하고 분석할 수 있습니다.

#### 퍼널의 기본 구성

1. **메뉴 바:** 표시 레이아웃을 변경하거나, 퍼널 카드의 이름을 바꾸거나, 삭제하거나, 대시보드에 추가합니다.
2. **차트 영역:** 전체 전환, 단계 간 전환, 단계를 건너뛴 사용자를 시각화합니다. 전체 퍼널에 걸친 총 전환과 이탈한 전환을 확인할 수 있습니다.
3. **기간:** 특정 추세를 분석하도록 기간을 조정합니다.
4. **이벤트 및 필터:** 클릭, 방문한 URL, 입력과 같은 사용자 동작을 조합하여 각 퍼널 단계의 이벤트를 정의합니다. 필터는 정의한 모든 이벤트에 적용됩니다.
5. **세션 목록:** 회색으로 표시된 영역을 클릭하면 특정 단계에서 이탈한 사용자의 세션을 볼 수 있으며, 리플레이를 재생하여 근본 원인을 파악할 수 있습니다.

## 퍼널 시각화: 차트 유형

1. **퍼널 막대 차트:** 단계별 진행 상황과 이탈을 시각화하는 데 가장 적합합니다.
2. **퍼널 열 차트:** 전환과 이탈을 세로 방향으로 보여 줍니다.
3. **지표:** 전체 전환율을 강조하여 표시합니다.
4. **테이블:** 총 세션 수 또는 사용자 수, 전체 전환율을 포함해 각 단계의 상세 수치를 표시합니다.

## 퍼널 보기 사용자 지정

#### 기간 조정

- **사전 설정 옵션:** 지난 24시간, 지난 7일, 지난 30일의 데이터를 분석합니다.
- **사용자 지정 범위:** 필요에 따라 특정 기간을 직접 지정합니다.

## 고급 기능

#### 이벤트와 필터

- 클릭, 텍스트 입력, 방문한 URL, 태그가 지정된 요소 등 여러 이벤트를 조합하여 퍼널 단계를 정의합니다.
- 모든 이벤트에 필터를 적용하여 사용자 속성(예: User ID, userAnanymousId) 또는 세션 특성(예: 지속 시간, 리퍼러, 국가, 도시, OS, 브라우저 UTM Source 등)에 집중할 수 있습니다.

#### 인터랙티브 기능

- **세션 드릴다운:** 퍼널 차트에서 회색으로 표시된 영역을 클릭하면 특정 단계에서 이탈한 사용자의 세션을 볼 수 있습니다. 세션 리플레이를 재생하여 문제를 파악하고 이탈의 근본 원인을 찾아내세요.
- **전환 지표:** 전체 퍼널의 총 전환율, 단계별 전환, 이탈한 전환을 시각화합니다.

#### 내보내기 옵션

- 퍼널 시각화를 이미지로 저장하여 팀이나 이해관계자와 손쉽게 공유할 수 있습니다.

## Funnels를 최대한 활용하기

- 비즈니스 목표에 부합하는 명확하고 실행 가능한 퍼널 단계를 정의하세요.
- 필터와 이벤트를 조합하여 특정 사용자 세그먼트나 행동에 집중하세요.
- 세션 리플레이를 활용해 이탈의 맥락을 파악하고 근본 원인을 찾아내세요.
