Jira Cloud를 OpenReplay와 통합하는 방법을 설명합니다.

## 1. 새 API 토큰 만들기

1. [JIRA 토큰](https://id.atlassian.com/manage/api-tokens) 페이지에 로그인합니다.
2. *Create API token*을 클릭합니다.
3. 레이블에 "openreplay"를 입력하고 *Create*를 클릭합니다.
4. *Copy to clipboard*를 클릭합니다.

## 2. OpenReplay에서 JIRA Cloud 활성화

1. OpenReplay 대시보드에서 'Preferences > Integration'으로 이동합니다.
2. Jira를 선택합니다. 보이지 않는다면 GitHub가 활성화되어 있기 때문일 수 있습니다(두 통합을 동시에 사용할 수 없으므로 먼저 GitHub 통합을 비활성화하세요).
3. `Username`과 `API token`을 입력한 다음 Jira Cloud 인스턴스의 URL을 입력합니다.

이제 모든 녹화에 'Create Issue' 버튼이 표시되어 Jira에서 이슈를 빠르게 생성하고 담당자를 지정할 수 있습니다.
