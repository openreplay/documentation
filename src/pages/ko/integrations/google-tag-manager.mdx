OpenReplay 대시보드의 'Preferences > Projects'에서 트래커 코드를 복사합니다. 이 코드는 프로젝트마다 고유합니다.

![트래킹 코드](/static/GTM-5.JPG#center)

그런 다음 Google Tag Manager 계정으로 이동하여 아래 단계를 따르세요.

1. *Add a new tag*를 클릭합니다.

![새 태그 추가](/static/GTM-3.png#center)

2. *Choose a tag type*을 클릭하여 설정을 시작합니다.
3. 목록에서 *Custom HTML*을 선택한 다음 복사한 스니펫을 텍스트 필드에 붙여넣습니다.

![커스텀 HTML](/static/GTM-4.JPG#center)

4. *Choose a trigger*를 클릭하여 트리거를 설정하고 **All Pages**를 선택합니다.

![모든 페이지](/static/GTM-7.JPG#center)

5. 태그 이름을 지정한 다음 *Save*를 클릭합니다.
6. 변경 사항을 *Submit*합니다.

![제출](/static/submit.JPG#center)

7. 라이브 환경이 선택되어 있는지 확인한 다음 *Publish*를 클릭합니다.

![게시](/static/GTM-10.png#center)
