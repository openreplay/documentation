GitHub를 OpenReplay와 통합하면 녹화 페이지에서 바로 이슈를 만들 수 있습니다.

## 오픈 소스 OpenReplay 사용

#### 1. 개인 액세스 토큰 만들기

1. GitHub에 로그인한 다음 [Settings > Developers Settings > Personal access tokens](https://github.com/settings/tokens)로 이동합니다.
2. 'Generate a new token'을 클릭합니다.
3. `repo:status`, `repo_deployment`, `public_repo`, `read:user`, `user:email` 스코프를 선택합니다.
4. 'Generate token'을 클릭한 다음 토큰을 복사합니다.

#### 2. OpenReplay에서 GitHub 활성화

1. OpenReplay 대시보드에서 'Preferences > Integration'으로 이동합니다.
2. GitHub를 선택합니다. 보이지 않는다면 Jira가 활성화되어 있기 때문일 수 있습니다(두 통합을 동시에 사용할 수 없으므로 먼저 Jira 통합을 비활성화하세요).
3. 앞서 생성한 `token`을 붙여넣습니다.

이제 모든 녹화에 'Create Issue' 버튼이 표시되어 GitHub에서 이슈를 빠르게 생성하고 담당자를 지정할 수 있습니다.

## OpenReplay Cloud 사용

'Preferences > Integration'으로 이동하여 GitHub를 클릭합니다. 인증을 위해 GitHub로 리디렉션됩니다. 해야 할 일은 이것이 전부입니다. 이제 모든 녹화에 'Create Issue' 버튼이 표시되어 GitHub에서 이슈를 빠르게 생성하고 담당자를 지정할 수 있습니다.
