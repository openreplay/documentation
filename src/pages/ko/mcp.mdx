**OpenReplay MCP** 앱은 OpenReplay 인스턴스를 MCP를 지원하는 채팅 호스트(Claude Desktop, Claude Code, ChatGPT, Codex)에 연결하여 일상적인 언어로 제품 분석과 세션 리플레이를 탐색할 수 있게 해 줍니다. 차트를 요청하고, 퍼널을 자세히 살펴보고, 세션을 찾은 다음 리플레이를 여는 모든 과정을 채팅 안에서 진행할 수 있습니다.

**OpenReplay Cloud**와 **셀프 호스팅** 인스턴스 모두에서 작동합니다.

<Aside type="tip" title="제공 기능" >
  - OpenReplay UI에서 사용하는 것과 동일한 필터로 세션을 검색합니다.
  - 시계열, 퍼널, 사용자 여정, 웹 바이탈, 상위 항목(top-of-X) 분석을 인라인으로 렌더링합니다.
  - 채팅에서 바로 세션 리플레이를 시청합니다.
  - 이 모든 것을 연결해 사용할 수도 있습니다. 검색 → 세션 선택 → 리플레이 열기 → Claude에게 요약 요청
</Aside>

## 호환성

이 앱은 stdio를 통한 표준 MCP를 사용하므로 다음 환경에서 작동합니다.

- **Claude Desktop** (macOS, Windows)
- **Claude Code**
- **ChatGPT** (MCP 커넥터 사용)
- **Codex**
- MCP를 지원하는 그 밖의 모든 호스트
