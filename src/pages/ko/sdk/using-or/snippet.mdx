OpenReplay가 지원하지 않는 프레임워크를 사용하거나 VanillaJS를 사용하는 웹 애플리케이션에 트래커를 추가하려면
JavaScript 스니펫을 직접 추가하면 됩니다.

## 스니펫 가져오기

필요한 JavaScript 스니펫은 OpenReplay 포털에서 프로젝트를 설정할 때 제공됩니다.
새 프로젝트를 추가하면 다음과 같은 화면이 표시됩니다.

![새 프로젝트 준비 완료](/using-or/snippet/new-project-ready.png)

이 화면이 표시되면 "Complete Project Setup" 버튼을 클릭하세요.
그러면 JS 스니펫이 표시되는 페이지로 이동합니다.


![JS 스니펫 가져오기](/using-or/snippet/getting-snippet.png)

이제 "Script" 탭을 클릭하면 실제 JavaScript 스니펫이 표시됩니다.

![스니펫이 표시된 화면](/using-or/snippet/snippet-visible.png)

스크립트를 복사하여 `<head>` 태그 안에 직접 추가하면 트래커가 자동으로 동작하기 시작합니다.

<Aside type="tip">
위 스크린샷의 1단계에서 데이터 녹화 옵션을 변경하면 최종 스니펫도 달라진다는 점에 유의하세요.
따라서 먼저 녹화 옵션을 설정한 다음 실제 스니펫을 복사하세요.
</Aside>
