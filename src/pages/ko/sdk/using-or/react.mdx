React 애플리케이션에서 트래커를 동작시키는 일은 꽤 간단합니다.

## 트래킹 코드 추가하기

SPA(Single Page Application)를 만든다고 가정하면, 진입점에 다음 코드를 추가하기만 하면 됩니다.

```jsx
import { tracker } from '@openreplay/tracker';

tracker.configure({
  projectKey: "<your project key>", 
  ingestPoint: "https://openreplay.mydomain.com/ingest" // only required if using the self-hosted version of OpenReplay
});

function YourMainComponent({props}) {
    //some code here...

    useEffect(() => {
        tracker.start();
    }, [])

    return //....
}
```

또는 `Tracker` 클래스를 직접 사용하여 인스턴스를 수동으로 관리할 수도 있습니다.

```jsx
import Tracker from '@openreplay/tracker';

const tracker = new Tracker({
  projectKey: "<your project key>",  
  ingestPoint: "https://openreplay.mydomain.com/ingest" // only required if using the self-hosted version of OpenReplay
});

function YourMainComponent({props}) {
    //some code here...

    useEffect(() => {
        tracker.start();
    }, [])

    return //....
}
```

즉, 스크립트 시작 부분에서 트래커를 인스턴스화하고, 페이지가 로드되면 `useEffect` 훅으로 트래커를 시작할 수 있습니다.

<Aside type="tip">
새 프로젝트를 만들 때 CDN에서 트래커의 [JS 스니펫 버전](/sdk/using-or/snippet#getting-the-snippet)을 바로 받을 수 있지만, 이 코드는 지나치게 기본적이어서 커스터마이징하거나 추가 플러그인을 붙이기가 더 어렵습니다.
</Aside>

### 코드에서 "projectKey" 처리하기

보안을 위해 `projectKey`를 애플리케이션 코드에 직접 하드코딩하지 마세요. 대신 설정 파일이나 환경 시스템에 저장하세요.

프로젝트 구성에 따라 사용할 수 있는 방법이 여러 가지 있습니다.
- **환경 변수**: Create React App을 사용한다면 [환경 변수에 대한 기본 지원](https://create-react-app.dev/docs/adding-custom-environment-variables/)을 활용하세요
- **설정 파일**: 버전 관리에서 제외한 전용 설정 파일을 사용하세요
- **환경 관리**: `dotenv` 같은 도구를 사용하면 환경별로 서로 다른 키를 관리하는 데 도움이 됩니다

다음은 예시입니다.
```javascript
// Access the key from environment variables
const openReplayKey = process.env.REACT_APP_OPENREPLAY_KEY;
```
