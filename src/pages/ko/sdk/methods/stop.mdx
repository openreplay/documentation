이 메서드는 트래커와 활성 세션을 중지합니다. 이 메서드를 사용하지 않으면 탭을 닫거나 사이트를 벗어난 후 몇 분 뒤에 세션이 자동으로 중지됩니다.

## 시그니처

```js
stop(): string | undefined
```

## 반환값

중지된 세션의 `sessionHash`를 반환합니다.
