이 메서드를 사용하면 개별 WebSocket 채널과 메시지의 방향(수신/송신)을 추적할 수 있습니다.

## 시그니처

```ts 
trackWs: (channelName: string) => (msgType: string, data: string, dir: 'up' | 'down') => void
```

## 매개변수

- `channelName: string`: WS 채널의 이름입니다.

## 반환값

ws 메시지에 적용하는 훅을 반환하며, 이 훅은 메시지 유형(또는 이름), 데이터, 메시지 방향(up/down === 송신/수신)을 매개변수로 받습니다.
