이 메서드를 사용하면 "기능 이벤트(functional event)"를 보고할 수 있습니다. 기능 이벤트를 통해 사용자 세션 중 기능적 관점에서 의미가 있지만 트래커가 기본적으로 스스로 감지하여 표시할 수 없는 순간을 알릴 수 있습니다. 예를 들어 사용자가 장바구니에 상품을 담는 동작이 기능 이벤트입니다. 트래커는 이 동작을 기록할 수는 있지만, 세션 타임라인에서 의미 있는 이벤트로 표시해야 한다는 것은 알지 못합니다. 하지만 이 메서드를 사용하면 직접 표시할 수 있습니다.

<Aside type="tip">
  사용자 지정 이벤트를 전송하는 방법에 대한 자세한 튜토리얼도 준비되어 있으니 [여기](/tutorials/custom-events)에서 확인해 보세요.
</Aside>

자세한 내용은 [사용자 지정 이벤트](/product-analytics/data-management)를 참고하세요.

## 시그니처

```js 
event(key: string, payload?: any, issue?: boolean): void
```

## 매개변수

- `key: string`: 정보가 저장될 키의 이름입니다. 이 키는 OpenReplay 플랫폼 내에서 필터링과 검색에 사용할 수 있습니다.
- `payload: any`: 이벤트의 내용입니다. 직렬화 가능한 모든 데이터가 될 수 있습니다.
- `issue: boolean`: 기능 이벤트(`false`로 설정한 경우)인지 "기술 이벤트(technical event)"(`true`로 설정한 경우)인지를 나타냅니다. 기본값은 `false`입니다.
