이 메서드를 사용하면 OpenReplay 플랫폼에 구성된 메타데이터 필드 중 하나의 값을 설정할 수 있습니다.

<Aside type="note">
이 메서드는 원하는 만큼 여러 번 호출할 수 있지만, 같은 `key` 속성을 사용하면 마지막으로 전달한 값이 플랫폼에 저장된다는 점에 유의하세요. 이전 값은 모두 사라집니다.
</Aside>

자세한 내용은 [메타데이터](/session-replay/metadata)를 참고하세요.

## 시그니처
```js
setMetadata(key: string, value: string): void
```

## 매개변수

- `key: string`: 저장할 메타데이터 키입니다.
- `value: string`: 메타데이터로 저장할 값입니다.

## 반환값

이 메서드는 값을 반환하지 않습니다. 정보는 리플레이의 일부로 바로 저장되며 OpenReplay 플랫폼 내에서 확인할 수 있습니다.
