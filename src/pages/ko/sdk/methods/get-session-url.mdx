이 메서드를 사용하면 활성 세션의 URL을 가져올 수 있습니다. 이 URL은 OpenReplay 대시보드를 가리키며, OpenReplay를 자체 스택에 통합하려는 경우에 유용합니다.

## 시그니처

```js
getSessionURL({ withCurrentTime?: boolean }): string | undefined
```

## 매개변수

- `withCurrentTime: boolean`: 선택 매개변수이며 기본값은 `false`입니다. `true`이면 메서드를 호출한 시점에 해당하는 리플레이 내 타임스탬프가 URL에 포함됩니다.

## 반환값

이 메서드는 OpenReplay 플랫폼에서 재생할 활성 세션의 URL을 반환합니다. 선택적으로 URL에 메서드를 호출한 시점의 타임스탬프를 포함하여 리플레이에서 해당 위치로 바로 이동하게 할 수 있습니다.
