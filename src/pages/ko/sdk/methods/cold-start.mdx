실제 세션을 시작하지 않고 메시지 버퍼링을 시작합니다. 버퍼에는 기록된 이벤트 중 최근 30초 분량이 유지됩니다. `start()`를 호출하거나 조건부 트리거를 통해 세션을 활성화할 수 있습니다.

## 시그니처

```ts
coldStart(startOpts?: Partial<StartOptions>, isConditional?: boolean): Promise<void>
```

### 매개변수
`startOpts`를 사용하면 녹화의 여러 측면을 사용자 지정할 수 있습니다:
- `userID: string`: `userID`를 수동으로 설정하여 세션 간에 사용자를 추적할 때 사용합니다. 원하는 어떤 문자열 값이든 사용할 수 있습니다.
- `metadata: Record<string, string>`: 메타데이터 값을 수동으로 설정합니다. 자세한 내용은 [메타데이터 섹션](/session-replay/metadata)을 확인하세요.
- `forceNew: boolean`: 페이지를 새로 고친 후에도 새 세션을 강제로 시작할 때 사용합니다. 기본값은 `false`이므로 새로 고침 후에도 세션이 유지됩니다.
- `sessionHash: string`: 고정 세션(sticky session)에 사용합니다. 멀티 사이트 애플리케이션이 있거나 사용자를 외부(예: 결제 게이트웨이)로 리디렉션했다가 다시 사이트로 돌아오게 해야 할 때 유용합니다.
- `isConditional`: 세션을 자동으로 시작하기 전에 트래커가 트리거 조건이 충족되기를 기다릴지 여부를 결정합니다.

> 참고: 조건부 녹화는 Cloud 및 Enterprise Edition에서만 지원됩니다.

### 반환값

이 메서드는 값을 반환하지 않습니다.
