트래커가 JS 오류 발생 시 기본적으로 추적하는 정보로 충분하지 않다면 이 메서드를 사용할 수 있습니다. `handleError` 메서드는 포착된 예외, 거부된 프로미스 또는 오류 이벤트를 수동으로 보고합니다. 자세한 내용은 [오류 보고](/session-replay/error-reporting#manually-logging-exceptions)를 참고하세요.

## 시그니처

```js 
handleError: (e: Error | ErrorEvent | PromiseRejectionEvent, metadata?: Record<string, any>) => void
```

## 매개변수

- `e: Error | ErrorEvent | PromiseRejectionEvent`: 포착된 실제 오류 객체입니다.
- `metadata: Record<string, any>`: **[선택 사항]** 이 오류와 연결하여 저장하려는 모든 추가 정보를 담은 딕셔너리 형태의 구조입니다.

## 반환값

이 메서드는 값을 반환하지 않으며, 저장된 정보는 OpenReplay 플랫폼 내에서 확인할 수 있습니다.
