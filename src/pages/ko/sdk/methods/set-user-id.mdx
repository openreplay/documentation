이 메서드를 사용하면 현재 활성 세션에 사용자 ID를 설정할 수 있습니다. 이를 통해 사용자를 리플레이와 연결하여 특정 사용자의 세션을 필터링하고 검색할 수 있습니다.

## 시그니처
```js
setUserID(id: string): void
```

## 매개변수

- `id: string`: 사용자의 ID입니다. 문자열이기만 하면 무엇이든 될 수 있으며, 시스템 내에서 사용자를 고유하게 식별할 수 있는 값(예: 이메일, 데이터베이스 ID 등)이면 됩니다.

## 반환값

이 메서드는 값을 반환하지 않으며, 결과는 OpenReplay 플랫폼에서 확인할 수 있습니다.
