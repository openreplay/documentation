## 타이밍 정보 누락

CORS가 적용되면, 서버의 액세스 정책이 값을 공유하도록 허용하지 않는 한 많은 타이밍 속성 값이 0으로 반환됩니다. 이를 허용하려면 리소스를 제공하는 서버가 제한된 타임스탬프 값을 가져올 수 있는 출처를 지정한 `Timing-Allow-Origin` HTTP 응답 헤더를 보내야 합니다.

메인 페이지를 제공하는 도메인과 다른 도메인에서 로드되는 리소스처럼 교차 출처 리소스에서 특히 중요합니다. `Timing-Allow-Origin` 헤더가 올바르게 설정되지 않으면 OpenReplay는 해당 리소스의 타이밍 정보를 기록할 수 없습니다.

예를 들어 https://application.example.com 이 https://data.example.com 의 백엔드를 요청할 때 리소스 타이밍 정보를 볼 수 있도록 하려면, 백엔드가 다음 헤더를 포함해야 합니다.

```http
Timing-Allow-Origin: https://application.example.com
```
