이 메서드를 사용하면 "기능 이벤트(functional event)"를 보고할 수 있습니다. 기능 이벤트를 통해 사용자 세션 중 기능적 관점에서 의미 있는 순간을 표시할 수 있으며, 이러한 순간은 기본적으로 트래커가 스스로 감지하고 표시할 수 없습니다. 기능 이벤트의 예로는 사용자가 장바구니에 상품을 추가하는 동작이 있습니다. 트래커는 이 동작을 녹화할 수는 있지만, 세션 타임라인에서 의미 있는 이벤트로 표시해야 한다는 사실은 알지 못합니다. 하지만 이 메서드를 사용하면 직접 표시할 수 있습니다.

자세한 내용은 [커스텀 이벤트](/product-analytics/data-management)를 참고하세요.

## 시그니처

```kotlin
data class User(val name: String, val age: Int)

OpenReplay.event("Test Event", User("John", 25))
```

## 매개변수

- `key: string`: 정보가 저장될 키의 이름입니다. 이 키는 OpenReplay 플랫폼에서 필터링과 검색에 사용할 수 있습니다.
- `payload: Encodable`: 이벤트의 내용입니다. 인코딩 가능한(JSON) 데이터라면 무엇이든 사용할 수 있습니다.
