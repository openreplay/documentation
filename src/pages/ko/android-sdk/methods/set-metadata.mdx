이 메서드를 사용하면 OpenReplay 플랫폼에 구성된 메타데이터 필드 중 하나의 값을 설정할 수 있습니다.

<Aside type="note">
	이 메서드는 원하는 만큼 호출할 수 있지만, 동일한 `key` 속성을 사용하면 마지막으로 전달한 값이 플랫폼에 저장되고 이전 값은 모두 사라진다는 점에 유의하세요.
</Aside>

자세한 내용은 [메타데이터](/session-replay/metadata)를 참고하세요. 

## 시그니처
```kotlin
OpenReplay.setMetadata(key: String, value: String)
```

## 매개변수

- `key: string`: 저장할 메타데이터 키입니다. 
- `value: string`: 메타데이터로 저장할 값입니다.

## 반환 값

이 메서드는 값을 반환하지 않습니다. 정보는 리플레이의 일부로 직접 저장되며 OpenReplay 플랫폼 내에서 확인할 수 있습니다.
