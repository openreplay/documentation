이 메서드는 트래커를 시작하는 데 사용됩니다. 트래커를 시작하면 세션 녹화가 시작됩니다.

## 시그니처

```kotlin
OpenReplay.start(applicationContext: Context, projectKey: String, options: OROptions)
	```

### 초기화 옵션

사용 가능한 옵션:

- `crashes: Bool` 크래시 리포트 수집(crashlytics)을 활성화합니다.
- `analytics: Bool` 뷰에 대한 분석을 활성화합니다.
- `performances: Bool` 성능 리스너를 활성화합니다.
- `logs: Bool` 로그 리스너를 활성화합니다.
- `screen: Bool` 화면 녹화기를 활성화합니다.
- `wifiOnly: Bool` 사용자가 Wi-Fi에 연결된 경우에만 트래커가 시작되도록 합니다.

기본값: 모두 `true`
