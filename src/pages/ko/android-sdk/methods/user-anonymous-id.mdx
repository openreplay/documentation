녹화 중인 세션에 익명 userID를 연결합니다.

## 시그니처
```kotlin
OpenReplay.userAnonymousID(userID: String)
```

## 매개변수

- `userID: String`: 사용자의 익명 ID입니다. 문자열이며, 시스템 내에서 사용자를 고유하게 식별할 수 있는 값이라면 무엇이든 가능합니다(예: 이메일, 데이터베이스 ID 등).

## 반환 값

이 메서드는 값을 반환하지 않으며, 결과는 OpenReplay 플랫폼에서 확인할 수 있습니다.
