트래커는 뷰가 나타나거나 사라지는 이벤트를 감지합니다.

## 추적할 뷰 추가하기

### 

`.observeView(title:viewName:)`을 사용하여 입력 이벤트를 관찰합니다.

- `title: String` - 화면 또는 기능의 제목
- `viewName: String` - 트래커 뷰의 이름

```kotlin

TextField("Input", text: $text)
 .observeView(title: "Screen title", viewName: "test input name")
```
