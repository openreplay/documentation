OpenReplay 인스턴스를 최신 버전으로 업그레이드하려면 `v1.4.0` 이상 버전을 실행 중인지 확인하세요. 그렇지 않다면 지원이 중단된 버전을 사용 중인 것이므로, 최신 버전(v1.8.0 이상)으로 올리기 전에 먼저 `v1.4.0`으로 업그레이드해야 합니다.

## 백엔드 업그레이드(v1.3.6 이하에서 v1.4.0으로)

먼저 `v1.3.6` 이하 버전인지 확인하세요. 이미 그렇다면 아래 명령은 건너뛰고 1) 단계로 이동하세요. 그렇지 않다면 OpenReplay 설치를 `v1.3.6`으로 업데이트합니다:
   
```bash 
# Copy/backup the current openreplay folder to _version-number
mv openreplay openreplay_v1.3.5
git clone https://github.com/openreplay/openreplay -b v1.3.6
cd openreplay/scripts/helm
# bash upgrade.sh <old openreplay path>
bash upgrade.sh ~/openreplay_v1.3.5
```

`v1.3.6`이 되면 다음 단계를 진행합니다:

1. 현재 openreplay 폴더를 다음과 같이 `_version-number`로 복사/백업합니다:
   
  ```bash 
  mv openreplay openreplay_v1.3.6
  ```

2. 새 OpenReplay 버전을 클론합니다. 이 예시에서는 v1.4.0으로 업그레이드합니다:
   
  ```bash 
  git clone https://github.com/openreplay/openreplay -b v1.4.0
  ```

3. 다음 스크립트를 실행하여 `vars.yaml`을 새 형식으로 자동 업그레이드합니다:
  
  ```bash
  cd openreplay/scripts/helmcharts
  ansible localhost -m template -a "src=vars_template.yaml dest=vars.yaml" -e @~/openreplay_v1.3.6/scripts/helm/vars.yaml
  ```

4. OpenReplay를 업그레이드합니다:

  ```bash
  cd openreplay/scripts/helmcharts
  helm ls -n app | tail -n +2 | awk '{print $1}' | xargs -I{} helm uninstall {} -n app
  helm uninstall nginx-ingress -n nginx-ingress
  helm upgrade --install openreplay ./openreplay -n app -f vars.yaml --atomic --set forceMigration=true
  ```
  
5. 로드 밸런서를 사용하지 않고 `certmanager.sh` 스크립트로 SSL 인증서를 생성한 경우:

  ```
  cd /var/lib/openreplay/openreplay/scripts/helmcharts && bash certmanager.sh
  ```

6. `/openreplay/scripts/helmcharts/vars.yaml`의 `fromVersion` 변수를 새 버전에 맞게 업데이트합니다. 예를 들어 `v1.3.6`에서 `v1.4.0`으로 이동하는 경우 `fromVersion`을 다음과 같이 업데이트합니다:
  
  ```yaml
  fromVersion: "v1.4.0"
  ```

> **참고:** 
서비스 구성 파일(예: `openreplay/scripts/helm/app/<app>.yaml`)에 직접 적용한 수정 사항은 초기화됩니다. 따라서 녹화용 [외부 오브젝트 스토리지 서비스](/configuration/external-storage) 사용이나 서비스 용량(CPU/메모리) 증설 같은 사용자 지정 설정이 있다면, 업그레이드 스크립트를 실행하기(4단계) 전에 새 버전(`/openreplay/scripts/helmcharts/vars.yaml`)에 반드시 적용하세요.
