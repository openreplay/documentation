</Aside>

OpenReplay 스택은 Docker Compose를 사용하여 한 대의 머신에 설치할 수 있습니다. 

## 사전 요구 사항

1. Ubuntu 20.04 LTS(LTS 버전 권장)
2. 머신에 퍼블릭 IP가 할당되어 있어야 합니다. 즉, 서버가 인터넷에서 접근 가능해야 합니다.
3. IP 주소에 연결된 도메인 이름이 있어야 합니다.
4. 인스턴스 유형을 선택합니다. 최소 사양은 x86 아키텍처 기준 `2 vCPUs, 8 GB of RAM, 50 GB of storage`이며, 이보다 낮으면 OpenReplay 백엔드 서비스가 시작되지 않습니다. 따라서 **최소** `t3.large`(또는 동급) 이상을 권장하며, 이는 낮거나 중간 정도의 트래픽에는 충분합니다. 트래픽이 많을 것으로 예상된다면 여기서부터 확장하세요.

## OpenReplay 배포

```bash
## From your terminal
SSH_KEY=~/Downloads/openreplay-key.pem #! wherever you've saved the SSH key
INSTANCE_IP=REPLACE_WITH_INSTANCE_PUBLIC_IP
chmod 400 $SSH_KEY
ssh -i $SSH_KEY ubuntu@$INSTANCE_IP
```

2. OpenReplay가 실행될 도메인을 지정하여 설치합니다(예: DOMAIN_NAME=openreplay.mycompany.com):

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/openreplay/openreplay/main/scripts/docker-compose/docker-install.sh)"
```

이제 설정이 모두 끝났습니다. 처음에 생성한 도메인에서 OpenReplay에 안전하게 접속할 수 있을 것입니다. `/signup` 페이지(예: openreplay.mycompany.com/signup)에 접속하여 계정을 만들 수 있습니다.
