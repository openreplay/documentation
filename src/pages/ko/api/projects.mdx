## 프로젝트 생성

`name`과 선택 사항인 `platform`을 지정하여 새 프로젝트를 생성합니다.

### 메서드
`POST`

### URL
`/public/projects`

### 페이로드

| 이름     | 유형   | 설명                                                         |
|----------|--------|--------------------------------------------------------------|
| name     | string | 프로젝트 이름(필수, 최대 200자)                              |
| platform | string | 프로젝트 플랫폼: `web`(기본값) 또는 `ios`                    |

### 요청 헤더

`Authorization: Bearer {YOUR_ORGANIZATION_API_KEY}`

### 상태 코드

`200`: 프로젝트가 생성되어 본문에 반환됨  
`400`: 잘못된 본문, 이름 누락/너무 김, 알 수 없는 플랫폼 또는 이미 존재하는 이름

### 요청 예시

```shell
curl -X POST \
  {BASE_URL}/public/projects \
  -H 'content-type: application/json' \
  -H 'Authorization: Bearer {YOUR_ORGANIZATION_API_KEY}' \
  --data-raw '{
    "name": "MyFirstProject",
    "platform": "web"
  }'
```

## 프로젝트 목록 조회

현재 테넌트의 모든 프로젝트를 반환합니다.

### 메서드
`GET`

### URL
`/public/projects`

### 요청 헤더

`Authorization: Bearer {YOUR_ORGANIZATION_API_KEY}`

### 요청 예시

```shell
curl -X GET \
  {BASE_URL}/public/projects \
  -H 'Authorization: Bearer {YOUR_ORGANIZATION_API_KEY}'
```

### 응답 예시

```json
{
  "data": [
    {
      "projectId": 42,
      "name": "MyFirstProject",
      "projectKey": "QsLA07Oa5sqTfwnNaFwS",
      "tenantId": 1,
      "platform": "web"
    },
    {
      "projectId": 43,
      "name": "MobileApp",
      "projectKey": "9cACFRuQVidq0sqS7Bny",
      "tenantId": 1,
      "platform": "ios"
    }
  ]
}
```

## 프로젝트 조회

지정한 프로젝트의 상세 정보를 반환합니다.

### 메서드
`GET`

### URL
`/public/projects/:projectKey`

### 매개변수

| 이름       | 유형   | 설명                         |
|------------|--------|------------------------------|
| projectKey | string | 프로젝트 키(필수)            |

### 요청 헤더

`Authorization: Bearer {YOUR_ORGANIZATION_API_KEY}`

### 상태 코드

`200`: 본문에 반환됨  
`404`: 프로젝트를 찾을 수 없음

### 요청 예시

```shell
curl -X GET \
  {BASE_URL}/public/projects/7ePSXFuQVidq9pqS6Xyn \
  -H 'Authorization: Bearer {YOUR_ORGANIZATION_API_KEY}'
```

### 응답 예시

```json
{
  "data": {
    "projectId": 42,
    "name": "MyFirstProject",
    "projectKey": "7ePSXFuQVidq9pqS6Xyn",
    "tenantId": 1,
    "platform": "web"
  }
}
```
