트래커는 뷰가 나타나고 사라지는 이벤트를 수신합니다.

## 추적할 뷰 추가

### SwiftUI

`.observeView(title:viewName:)`를 사용하여 입력 이벤트를 관찰합니다.

- `title: String` - 화면 또는 기능 제목
- `viewName: String` - 트래커 뷰의 이름

```swift
import ORTracker

TextField("Input", text: $text)
 .observeView(title: "Screen title", viewName: "test input name")
```

### UIKit
```swift
import ORTracker

Analytics.shared.addObservedView(view: inputEl, title: "Screen title", viewName: "test input name")
```
