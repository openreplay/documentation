트래커는 값 변경 이벤트를 (디바운스하여) 수신하고 그 결과 값을 OpenReplay 백엔드로 전송합니다.

## 추적할 입력 추가

### SwiftUI

`.observeInput(text:label:masked)`를 사용하여 입력 이벤트를 관찰합니다.

- `text: String` - 입력의 텍스트 값
- `label: String` - 녹화되는 입력의 레이블
- `masked: Bool` - `true`이면 트래커는 값이 아닌 입력 이벤트 자체만 기록합니다. 녹화에서 입력을 블러 처리하려면 `.sensitive`를 추가하는 것을 잊지 마세요.

```swift
import ORTracker

TextField("Input", text: $text)
.observeInput(text: $text, label: "tracker input #1", masked: Bool)

```

### UIKit

UIKit은 placeholder를 레이블로 사용하고 sender.isSecureTextEntry로 입력을 마스킹합니다.

```swift
import ORTracker

Analytics.shared.addObservedInput(inputEl)
```
