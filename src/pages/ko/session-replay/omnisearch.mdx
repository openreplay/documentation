## 이벤트 이해하기

OmniSearch의 **Events**는 세션 중에 발생하는 사용자 상호작용과 시스템 동작을 나타냅니다. 

이벤트는 크게 두 가지 범주로 나뉩니다. **Events**(**Autocaptured:** 사용자 상호작용 자동 추적, **Custom events:** SDK로 전송)와 **DevTools events**(기술적 모니터링 및 디버깅)입니다. 

###  이벤트
| **이벤트 이름**  | **설명** |
| --- | --- |
| Click | 사용자 클릭 기록 |
| Text Input | 필드에 입력된 텍스트 추적 |
| Visited URL | 방문한 페이지 기록 |
| Tagged Element | 사용자 지정 태그가 지정된 요소 추적 |
| Custom Events | 사용자 정의 이벤트. SDK를 사용하여 전송 |


### DevTools 이벤트

|  **이벤트 이름**  | **설명** |
| --- | --- |
| Network Request | 네트워크 활동 모니터링 |
| GraphQL | GraphQL 쿼리 및 응답 기록 |
| State Action | 애플리케이션의 상태 변경 추적 |
| Error Message | 콘솔에 출력된 오류 메시지 수집 |
| Average CPU Load | 평균 CPU 사용량 측정 |
| Average Memory Usage | 평균 메모리 사용량 추적 |

## 필터 이해하기

OmniSearch의 **Filters**는 특정 조건으로 세션 리플레이를 좁혀 가장 관련성 높은 사용자 세션에 집중할 수 있게 해 줍니다. 이벤트와 함께 사용하면 세션 데이터 전반에서 정밀한 검색을 수행할 수 있습니다. 

필터는 크게 네 가지 범주로 구성됩니다.

### 사용자 필터

|  **필터 이름**  | **설명** |
| --- | --- |
| User ID | 고유 식별자로 특정 사용자 필터링 |
| Anonymous User ID | 로그인 정보가 없는 사용자의 세션 필터링 |

### 세션 필터

|  **필터 이름**  | **설명** |
| --- | --- |
| Country | 국가별 세션 필터링 |
| City | 도시별 세션 필터링 |
| State/Province | 주(州) 또는 도별 세션 필터링 |
| Operating System (OS) | 사용된 운영 체제별 세션 필터링 |
| Browser | 브라우저 종류별 세션 필터링 |
| Device | 사용자 기기별 세션 필터링 |
| Platform | 플랫폼 종류별 세션 필터링 |
| Version ID | 애플리케이션 버전별 세션 필터링 |
| Referrer | 유입 URL 기준 세션 필터링 |
| Duration | 지속 시간별 세션 리플레이 필터링 |
| UTM Source | UTM 소스 파라미터별 세션 필터링 |
| UTM Medium | UTM 미디엄 파라미터별 세션 필터링 |
| UTM Campaign | UTM 캠페인 파라미터별 세션 필터링 |

### 이슈 필터

|  **필터 이름**  | **설명** |
| --- | --- |
| Rage Click, Dead Click, Excessive Scrolling, Mouse Thrashing | 반복 클릭, 작동하지 않는 버튼이나 링크, 과도한 스크롤, 불규칙한 마우스 움직임 등으로 사용자가 불편을 겪은 세션 식별…. |
| Bad Request | HTTP 400 오류가 발생한 세션 식별 |
| Missing Resource | 리소스가 누락된 세션 탐색 |
| CPU Issues | CPU 사용량이 높은 세션 식별 |
| Slow Resource | 로딩이 느린 리소스가 있는 세션 식별 |
| Slow Page Load | 페이지 로드 시간이 느린 세션 식별 |
| Crash | 앱 또는 페이지가 충돌한 세션 식별 |
| Errors | 애플리케이션 오류가 발생한 세션 식별 |

### 메타데이터 필터

|  **필터 이름**  | **설명** |
| --- | --- |
| Metadata key | 사용자 정의 메타데이터로 세션 필터링. 정의되지 않은 경우 메타데이터를 추가하는 방법은 [여기](/tutorials/metadata)를 참고하세요 |
