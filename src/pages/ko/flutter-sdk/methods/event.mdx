이 메서드를 사용하면 '기능 이벤트(functional event)'를 보고할 수 있습니다. 기능 이벤트를 사용하면 기능적 관점에서 의미가 있지만 트래커가 기본적으로 스스로 감지하여 표시할 수 없는 사용자 세션 내의 순간을 알릴 수 있습니다. 기능 이벤트의 예로는 사용자가 장바구니에 상품을 담는 동작을 들 수 있습니다. 트래커는 이 동작을 기록할 수는 있지만, 이것을 세션 타임라인에서 중요한 이벤트로 표시해야 한다는 것까지는 알지 못합니다. 하지만 이 메서드를 사용하면 직접 표시할 수 있습니다.

자세한 내용은 [사용자 정의 이벤트](/product-analytics/data-management)를 참고하세요.

## 시그니처

```dart
OpenReplay.instance.event(String name, [Object? payload])
```

## 매개변수

- `name: String`: 이벤트의 이름입니다. 이 이름은 OpenReplay 플랫폼 내에서 필터링과 검색에 사용할 수 있습니다.
- `payload: Object?`: 이벤트의 내용입니다. `String`은 그대로 전송되고, 그 밖의 값은 JSON으로 인코딩되며 인코딩할 수 없으면 `toString()`으로 대체됩니다. 생략하면 빈 페이로드가 전송됩니다.

## 예제

```dart
OpenReplay.instance.event('checkout_started', {'cart': 3, 'currency': 'EUR'});
OpenReplay.instance.event('promo_banner_dismissed');
```
