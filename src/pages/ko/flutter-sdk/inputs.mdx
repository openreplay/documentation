텍스트 필드는 자동으로 관찰되지 않습니다. Flutter에는 UIKit의 responder chain에 해당하는 것이 없어 연결할 지점이 없기 때문입니다. 관심 있는 컨트롤러에 트래커를 연결하면 값 변경을 (디바운스하여) 감지하고, 그 결과 값을 OpenReplay 백엔드로 전송합니다.

## 추적할 입력 추가

`observeInput(controller, label:, masked:)`를 사용합니다.

- `controller: TextEditingController` — 관찰할 컨트롤러
- `label: String` — 기록되는 입력의 레이블
- `masked: bool` — `true`이면 트래커는 입력 이벤트를 기록하되 값 대신 `****`를 전송합니다. 기본값: `false`.

이 함수는 리스너를 제거하는 콜백을 반환하므로 `dispose()`에 연결하세요.

```dart
import 'package:openreplay/openreplay.dart';

class _LoginFormState extends State<LoginForm> {
  final _email = TextEditingController();
  late final VoidCallback _stopObserving;

  @override
  void initState() {
    super.initState();
    _stopObserving = OpenReplay.instance.observeInput(_email, label: 'Email');
  }

  @override
  void dispose() {
    _stopObserving();
    _email.dispose();
    super.dispose();
  }
}
```

<Aside type="note">
	`masked: true`는 이벤트 스트림에서만 값을 숨깁니다. 녹화된 화면에서는 필드가 여전히 보이므로, 화면에서도 숨기려면 [`ORSanitizedView`](/flutter-sdk/sanitization)로 감싸세요.
</Aside>
