Démarre la capture du trafic HTTP de `dart:io`. Cela installe un `HttpOverrides`, chaîné à ceux déjà présents, de sorte que la capture couvre directement `HttpClient` ainsi que l'`IOClient` de `package:http` et l'adaptateur par défaut de Dio.

## Signature

```dart
OpenReplay.instance.patchNetwork([ORNetworkOptions options = const ORNetworkOptions()])
OpenReplay.instance.unpatchNetwork()
```

`patchNetwork()` est idempotente. `unpatchNetwork()` arrête la capture et restaure les overrides précédents.

## Exemple

```dart
OpenReplay.instance.patchNetwork(ORNetworkOptions(
  capturePayload: true,
  sanitizer: (record) {
    record.url = record.url.replaceAll(RegExp(r'token=[^&]+'), 'token=***');
    return record; // return null to drop the call entirely
  },
));
```

Consultez les [options réseau](/flutter-sdk/network) pour tous les champs d'`ORNetworkOptions`.

<Aside type="note">
	Un adaptateur Dio personnalisé contourne `HttpOverrides`. Dans ce cas, ajoutez votre propre intercepteur et appelez `OpenReplay.instance.networkRequest(...)` depuis celui-ci.
</Aside>
