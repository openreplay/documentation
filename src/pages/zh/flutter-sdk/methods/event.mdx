此方法允许你上报一个“功能性事件”。通过功能性事件，你可以标记用户会话中那些在功能层面具有意义、但我们的跟踪器默认无法自行捕获和标记的时刻。功能性事件的一个例子是用户将某件商品加入购物车。虽然我们的跟踪器能够记录该操作，但它并不知道要将其标记为会话时间线中的相关事件。不过，借助此方法，你可以手动完成这一标记。

更多详情请参阅[自定义事件](/product-analytics/custom-events#功能性事件)。

## 签名

```dart
OpenReplay.instance.event(String name, [Object? payload])
```

## 参数

- `name: String`：事件的名称。该名称可在 OpenReplay 平台内用于过滤和搜索。
- `payload: Object?`：事件的内容。`String` 会按原样发送；其他任何类型都会进行 JSON 编码，如果无法编码，则回退为 `toString()`。省略该参数则发送空负载。

## 示例

```dart
OpenReplay.instance.event('checkout_started', {'cart': 3, 'currency': 'EUR'});
OpenReplay.instance.event('promo_banner_dismissed');
```
