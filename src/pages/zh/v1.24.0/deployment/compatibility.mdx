升级 OpenReplay 实例时，务必确保你的 tracker（以及 tracker-assist 插件，如果你正在使用它）与后端版本兼容。

## 兼容性对照表

使用下表来确定应与你的后端搭配使用的 tracker 和 assist 版本：

| 后端版本 | Tracker 版本 | Assist 版本 |
|:---------------:|:--------------:|:-------------:|
| 1.28.0 | 19.x.x | 11.x.x |
| 1.27.0 | 18.x.x | 11.x.x |
| 1.26.0 | 17.2.x | 11.x.x |
| 1.25.0 | 17.2.x | 11.x.x |
| 1.24.0 | 17.1.x | 11.x.x |
| 1.23.0 | 17.x.x | 11.x.x |
| 1.22.0 | 16.x.x | 11.x.x |
| 1.21.0 | 15.x.x | 10.x.x |
| 1.20.0 | 14.x.x | 10.x.x |
| 1.19.0 | 14.x.x | 9.x.x |
| 1.18.0 | 13.x.x | 9.x.x |
| 1.17.0 | 12.x.x | 8.x.x |

## Tracker 更新日志

如需查看 OpenReplay tracker 的完整更新和变更列表，可以查阅 [GitHub 上的 Tracker 更新日志](https://github.com/openreplay/openreplay/blob/dev/tracker/tracker/CHANGELOG.md)。

## 有疑问？

如果你在升级过程中遇到任何问题，请通过 [Slack](https://slack.openreplay.com) 联系我们，或访问我们的[论坛](https://forum.openreplay.com)，从我们的社区获取帮助。
